# 章标题

## 本章罗盘

- **问题**：读者带着什么具体问题进入本章。
- **交付**：本章先做出什么最小可见结果。
- **边界**：哪些结论不适用于哪些型号、条件或场景。
- **依据锚点**：手册章节号、来源 ID 与对应旧章节号。

## 先做出来

最小可运行步骤与预期观察结果。

## 机制

寄存器、时序、数据结构或内核源码的逐层解释。

## 测量与证据

波形、寄存器读回、日志或仪器读数，以及如何判断“真的会了”。

## 失败分支

常见误判、最短排查路径与迁移边界。

## 离开检查

读者离开本章前应能回答的问题。
