状态：所有实施验收均为 `NOT_RUN`。本文件中的数字是拟定验收目标，不是测量结果。

## 2. 自动测试层

### 2.1 主机 C 测试

控制核心不得依赖 HAL。至少覆盖：

| ID | 输入场景 | 独立断言 |
| --- | --- | --- |
| H01 | 正/反向计数、两个方向跨回绕、恰好半模差 | 符号与增量正确；不可消歧时失效 |
| H02 | 初次采样、dt=0/过大、异常跳变、漏周期 | 不产生伪大速度，不将无效速度交给 PI |
| H03 | 多组 CPR、倍频/减速比、时间窗 | 与手算向量一致，错误口径能被检测 |
| H04 | PI 零误差、阶跃、正负饱和、误差反向、超调导致相反符号输出 | 条件积分与脱离饱和行为符合约定；PI 不越过已锁定方向的输出区间 |
| H05 | STOP、FAULT、反转与模式切换 | 输出关闭/限制、积分归零、旧命令不复活 |
| H06 | 目标斜坡、最大值/最小值、NaN/Inf/非法参数 | 每步变化有界；非法输入无输出副作用 |
| H07 | 命令超时边界、时钟回绕、新旧 seq/会话 | 过期或重复数据不续租；STOP 始终有效 |
| H08 | 长行、半帧、未知命令、破校验、粘包 | 有界恢复，不越界，不 ARM，不刷新租约 |
| H09 | 遥测满队列、错误长度、缺序、字节序 | 控制继续执行；丢帧可见；解码可恢复 |
| H10 | 同周期 STOP/SET、FAULT/CLEAR、反转超时 | 高优先事件胜出；故障不能自动恢复运行 |

协议 golden vectors 与指标计算参考数据作为小型固定 fixture 提交。指标分析器至少测试：正常阶跃、未稳定、超调、负方向、零目标、缺样/非单调时间、没有扰动时间点和哈希不符。错误输入必须报失败/无效，不自动填零生成“通过”。

### 2.2 仿真与编译边界

可用简单电机模型帮助理解 PI，但明确模型参数、假设和模拟标识。仿真验证算法趋势，不能替代电平、桥真值表、热、回灌、实际转速与机械停止证据。Wokwi/Renode 是否支持所选编码器和驱动模型要另查；V1 不依赖未确认的外设模型。

ARM 编译覆盖三个 preset；检查链接 map、栈/缓冲预算、项目代码警告。编译成功只能证明构建边界，不能给 AC04/AC07/AC12 填 PASS。

## 3. 真板测试前的冻结条件

1. AC02 的静态硬件资料完整；电源限流和物理断能路径已验证；机械装置固定，旋转部件没有松脱件。
2. 空载信号与上电默认态已测量，才接电机；先低占空比，后做完整运行。
3. `hardware_id`、`firmware_sha`、补丁哈希、参数哈希和验收阈值版本固定。所有测试使用同一套基线，变化后重跑受影响项目。
4. 冻结 `rpm_min`、`rpm_max`、负载范围、驱动/电源/电机温度与电流限值、所有故障检测窗口、反转参数。没有测温手段时不得声称热稳定通过。
5. 负载扰动使用可重复、有限且经过预算的装置，记录施加和撤除时刻。不得用手抓转轴或临时长时间堵转作为标准步骤。电气短路/真实过流不作为初学者常规故障注入；使用逻辑/信号注入验证软件分支，硬件保护测试另有受控方法。

## 4. 真板验收目标

以下以 T=10 ms 为初始设计。P0/P2 可依据分辨率与装置能力修改，但必须在正式采样前记录版本和理由；不允许失败后只放宽阈值保留原曲线。

| ID | 测试 | 初始通过目标 | 测量方法 |
| --- | --- | --- | --- |
| B01 | 上电/复位/下载/看门狗复位 | 全程无意外使能；每类至少重复 5 次 | STBY、PWM、方向波形与复位原因 |
| B02 | PWM 与停止真值表 | 三档占空比与频率误差在时钟/仪器预算内；目标 ≤1%；0/100% 端点单独验证 | 先断动力的逻辑测量，再验证工作状态 |
| B03 | 编码器标定 | 手转输出轴 10 圈，计数误差在起止位置误差对应范围；给出精确判据；方向一致 | 位置标记、累计计数、A/B 波形 |
| B04 | 独立转速核对 | 中/高两个点，偏差 ≤max(参考转速的 3%, q_rpm, 仪器不确定度) | 原始计数重算 + 独立测速，不拿同一估计值自证 |
| B05 | 速度阶跃 | 稳态均值误差 ≤5%；超调 ≤阶跃幅值的 15%；进入误差带时间 ≤2 s | 低→中、中→高和负方向各 3 次 |
| B06 | 负载施加/撤除 | 记录扰动量；≤2 s 回到目标 ±5% 带并保持至少 1 s；无持续饱和 | 重复夹具、负载事件时间戳与速度/输出曲线，各 3 次 |
| B07 | 饱和与恢复 | 限幅不越界，积分不继续向饱和方向累积；回到可达目标后 ≤2 s 恢复到 ±5% 带 | 受控降低软件输出上限触发饱和，避免实际过载 |
| B08 | 正反转换向 | 方向改变前满足停稳/保持时间；信号失效和超时不换向；PI 超调不触发直接反向驱动 | 波形与状态/速度连续时间轴，重复 3 次 |
| B09 | 命令租约失效 | 距最后有效指令 >500 ms 后最迟 1 个 T 内撤销使能；重复/坏帧不能续租 | 主机停止发送、重复 seq/坏帧注入 + STBY 测量 |
| B10 | 反馈异常/无进展 | 失效反馈不送 PI；撤销使能符合对应冻结窗口，首因可查 | 使用受控信号注入或断开反馈；不带危险负载 |
| B11 | 时序与看门狗 | WCET≤2 ms、周期偏差≤1 ms、漏周期=0；挂死能在冻结看门狗边界内复位 | GPIO/时钟记录；受控测试构建注入，不作为默认固件功能 |
| B12 | 连续运行 10 分钟 | 无意外复位、无截止期遗漏、无遥测丢样；温度、电流和供电均在冻结范围内 | 完整日志、独立温度/供电记录；注明仅是教学持续运行门 |
| B13 | 清故障与重连 | CLEAR 后仍关闭，重新 ARM+SET 才运行；旧缓存命令不能启动 | 重连/复位/旧会话重放日志与使能波形 |

B03 的具体计数容差必须在测前按标记/定位误差冻结，不能仅写“基本一致”。B02 所谓时钟预算必须包含实际参考时钟误差；若 1% 与硬件方案不相容，P0 更换或明确修订。

## 5. 指标定义

- 正式阶跃从静止或已稳定速度起步，每段保留至少 1 s 前置记录和 5 s 后置记录。目标值位于 P0 锁定的可运行区间，不能用零速百分比作为误差分母。
- 稳态均值误差：最后 1 s 测量转速均值与目标之差的绝对值除以目标绝对值。还要报告这 1 s 的标准差、峰峰值和饱和占比，避免均值抵消振荡。
- 稳定时间：从 SET 被控制任务接受的时刻起，首次进入目标 ±5% 带且连续保持至少 1 s 的时间。包括目标斜坡耗时，同时报告“斜坡结束后的稳定时间”，不通过改变起点美化结果。
- 超调：沿阶跃方向越过最终目标的最大量，除以目标变化的绝对幅值。负方向按符号归一化，零幅阶跃不计算百分比。
- 扰动恢复：从有证据的加载/卸载时刻起到重新满足误差带保持条件的时间；负载过程不能只凭操作者口述定时。
- 低速分辨率要求先满足 design 中 q_rpm≤2%×rpm_min；正式性能评价保存原始和滤波速度，分别报告结果，不能只展示大延迟滤波后的曲线。
- 饱和恢复测试以允许输出内的控制实验为主，禁止用“目标不可达持续顶满”代替受控测试。全程报告 duty、积分和限幅位。
- 任何时序缺口、丢帧或无效样本导致对应测量窗口无效，重新采样。三次重复全部单独展示，汇总给最差值，不挑最好的一条。

## 6. 证据包

实验协议放 `labs/motor-dc-speed/README.md`，小型结果索引可入库；大体积原始数据保存到明确的本地或发布制品位置。不能只引用测试者机器上的绝对路径而不提供可取得的发布包。

```text
run-<UTC时间>-<短版本>/
  metadata.json           # 设备、版本、参数、阈值与环境
  commands.jsonl          # 发送/接受时间、seq、会话与事件
  telemetry.bin           # 原始设备帧
  samples.csv             # 解码后的全量控制样本
  events.jsonl            # 负载/故障/操作，含计时关联与误差
  instruments/            # 示波器原始导出、独立测速、温度/电源记录
  photos/                 # 实际装置、测点、接线与丝印
  analysis.json           # 各指标、有效性、阈值、PASS/FAIL
  report.md               # B01–B13 与 AC 对照，未测项
  SHA256SUMS              # 对以上文件的哈希，不包含自身
```

`metadata.json` 至少含 schema_version、run_id、UTC 起始时间、单调时钟口径、硬件 ID/修订、板卡与电机/驱动/编码器型号、CPR 和减速比、供电/限流/负载、仪器精度、固件 SHA/dirty/patch hash、构建与依赖版本、实际参数与哈希、门槛版本、测试者、环境温度、测试类型（hardware/simulation/host）。

主机与设备时间轴通过握手或共同测量事件对齐，记录误差界限。软件日志的“发出停止命令”时间不能替代物理 STBY 变低时间。哈希校验、字段完整性、时间单调性和阈值版本不匹配时，分析器应拒绝生成通过结论。

## 7. 发布与回归边界

开发候选允许构建与主机测试完成而真实实验待测，但对外必须标明范围。V1“完整实战”要求 AC01–AC12 所有适用条件通过。硬件门缺失时可以继续独立文稿/主机任务，不能关闭 V1。

控制代码、时钟、编译优化、板卡、驱动、电机、编码器、关键参数变化时，重新执行影响范围内的硬件门；新增板型不能继承旧板的 PASS。纯排版修改只重跑相关书籍与链接检查，保留原实验归属。规格改变后旧报告保留原版本，不覆盖成新参数的证明。
