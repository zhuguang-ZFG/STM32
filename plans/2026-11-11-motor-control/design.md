## 1. 硬件基线与冻结门

主线候选为 STM32F103C8T6 开发板、TB6612FNG 驱动模块、带 A/B 正交编码器的小功率有刷直流减速电机。选型以现有教学基线为出发点，不代表用户已有这些实物，也不是采购清单。

P0 形成 `examples/motor-dc-speed/boards/f103c8-tb6612/hardware.md` 和机器配置 `board.json`，必须填写以下字段，未填齐不得将接线图标记为可直接上电：

| 对象 | 必填内容 | 冻结依据 |
| --- | --- | --- |
| 控制板 | PCB/MCU 型号和修订、晶振、时钟树、存储器、调试口、原理图 | 实物丝印、板图、数据手册 |
| 驱动模块 | 芯片和模块版本、逻辑/动力供电范围、输入门限、连续/峰值条件、散热、STBY 默认态 | 厂商数据手册与模块原理图；检查板载拉电阻 |
| 电机 | 订货号、额定电压、空载/额定/堵转数据、额定速度、减速比、允许负载 | 厂商规格；缺失值标记未知，不靠堵转长时间试出 |
| 编码器 | 所在轴、每相每圈脉冲定义、译码倍频、输出形式/电平、实际 CPR | 手册 + 手转计数 + 波形 |
| 电源/线束 | 电压、限流值、反灌处理、接头极性、线径、保护元件、去耦 | 电流与能量预算、器件资料、实测 |
| 测量/机构 | 仪器与量程、转速参考、固定夹具、负载方法、接触与停止操作 | 实验装置照片和记录 |

电机选型须给驱动电流与热余量；若启动/堵转电流或回灌超出模块与电源能力，替换电机或驱动，不能靠减小软件占空比宣称硬件风险已消失。基础工程没有电流传感器，不能提供实测电流闭环或声称软件过流保护。电源限流、驱动硬件保护和物理断能路径应各自说明覆盖范围。

RAM/Flash 按 C8 实际规格锁定，不借用更大容量。初始资源预算为 Flash 不超过 56 KiB、静态 RAM 不超过 12 KiB、至少 2 KiB 栈保留；最终 map 与栈水位证明剩余空间，含环形队列和中断嵌套。运行态不使用动态内存。预算不满足时审查模块和缓冲，不把链接器目标悄悄改成另一芯片。

## 4. 数据流和执行时序

控制路径：串口接收 → 主循环校验命令 → 有界邮箱 → 定时 ISR 取快照 → 读取编码器 → 估速 → 状态机/PI → 写桥输出 → 写遥测队列。主循环负责编码、传输与统计，不拥有直接改变桥输出的普通运行接口。

- 设计初值：PWM 20 kHz、控制周期 T=10 ms。它们是待核验起点；最终值写入板级配置和实验元数据。
- 仅当定时器输入确认为 72 MHz、使用对应边沿对齐模式时，PWM 示例才采用 PSC=0、ARR=3599。APB 分频影响定时器时钟，必须由时钟树和测量共同确认。
- 占空比输入使用有符号千分数 `[-1000,1000]`，方向与幅值分开。100% 输出对应 CCR 端点必须按选定模式实现并测试，不能把 CCR=ARR 无条件写成严格 100%。日常运行限制 `duty_limit_permille < 1000`，具体上限 P0 冻结。
- 周期 ISR 不读阻塞总线、不等待串口、不打印、不分配内存。HAL 调用审查其阻塞路径。每周期记录入口时间和执行时间，测量 GPIO 给独立证据。
- 目标执行时间 ≤2 ms、周期偏差 ≤1 ms；无截止期越界和丢周期。前者是预算，后者是正常运行硬门；超过 T 触发截止期故障。所有统计使用单调时钟并处理计时回绕。
- 串口接收/主循环与 ISR 的复合数据通过短临界区或双缓冲交换，不把 `volatile` 当作一致性保证。遥测队列满时丢遥测并累加计数，不能阻塞控制；验收运行要求丢帧计数为 0。
- IWDG 只在新的控制心跳与主循环健康状态均成立时喂狗。最终超时按实际 LSI 范围核验；看门狗复位后 STBY 仍为关闭，必须重新 ARM。主循环无条件喂狗不通过审查。

## 5. 桥输出和停止语义

桥接口接收运行模式和带符号幅值。驱动表至少覆盖 `DISABLE`、`DRIVE_FORWARD`、`DRIVE_REVERSE`、`COAST`、`SHORT_BRAKE`，逐项写出 STBY、AIN1、AIN2、PWMA 及输出状态，引用实际版本的真值表。

默认 STOP 和软件故障进入经核验的高阻释放状态，同时清积分并取消目标。`COAST` 与 `DISABLE` 在外部表现可能相似，但状态和后续允许行为独立；短接制动需要专用指令/配置和电源/热预算，V1 默认不开启。

直接从正转切负转被禁止。收到反向命令立即进入 `REVERSING`：先保持原方向并将目标/输出幅值按斜坡降至零，再撤销驱动并等待停稳，连续满足 `abs(rpm) <= reverse_zero_rpm` 与 `reverse_hold_ms` 后才改变方向并从零升速。该状态的降速、等待、重新起动三个子阶段必须在日志中可区分；STOP/FAULT 随时抢占并立即请求关闭，不等待斜坡。阈值与保持时间在 P0/P2 冻结；若反馈无效或 `reverse_timeout_ms` 到期，进入 FAULT。静止确认不能只看一帧零增量。

软件撤销驱动不保证机械瞬间停止。物理断能开关独立于命令解析和主循环；对其作用范围进行测量，不称为通过认证的急停系统。

## 6. 编码器和估速合同

统一参数 `counts_per_output_rev` 表示**当前译码模式下，输出轴完整一圈累计的计数**。若来自传感器每相周期数 P、译码倍率 Q 和减速比 G，则候选计算为 `N=P×Q×G`，但必须确认手册 P 的定义和编码器所在轴；已经是译码后的 CPR 不能再乘 Q。

每周期用真实时间间隔 dt 计算：

```text
rpm_raw = 60 × delta_count / (counts_per_output_rev × dt_seconds)
q_rpm   = 60 / (counts_per_output_rev × nominal_period_seconds)
rpm_filtered[k] = rpm_filtered[k-1] + alpha × (rpm_raw[k] - rpm_filtered[k-1])
```

初始滤波允许 alpha=1（不过滤）。若降低 alpha，记录截止特性/延迟并重新调参，不能把滤波后的平滑当作真实速度精度改善。

计数器宽度 w 冻结后，用模 `2^w` 差分恢复有符号增量，前提为一个采样间隔内绝对位移严格小于 `2^(w-1)`。实现使用足够宽的无符号/有符号运算，不依赖超范围强转的偶然结果；恰好半圈的差值判为不可消歧。必须测试正反回绕、最大速度、漏周期和长暂停。

首次采样仅建立基线；停止/复位后的旧基线不可直接生成速度。最大速度跳变、dt 异常和超出计数边界均置反馈无效并记录原因。无脉冲只能标记“反馈缺失或停转疑似”，不能单凭零计数区分断线和真实静止。

低速工作范围由 q_rpm 限制。冻结最小闭环转速时，要求 q_rpm ≤该转速的 2%；若做不到，调整编码器、采样窗或引入经验证的周期测量方案，并重新评估控制延迟，不能只增大允许误差。

## 7. PI 计算与参数

主线使用浮点 PI；F103 的执行预算以实测为准，不能假定有硬件浮点支持。误差单位 rpm，输出单位为归一化占空比：

```text
e[k]     = target_rpm_ramped[k] - measured_rpm[k]
I_try    = I[k-1] + Ki × e[k] × dt
u_try    = Kp × e[k] + I_try
u        = clamp(u_try, u_min_for_direction, u_max_for_direction)
```

Kp 单位为占空比/rpm，Ki 为占空比/(rpm·s)。已锁定正方向时有效输出区间为 `[0,+u_limit]`，负方向为 `[-u_limit,0]`；只有反转状态机确认停稳后才切换这个区间。超调产生相反符号的 PI 请求时，执行零输出的释放策略，不直接反向驱动；桥输出层再做一次方向约束，不能绕过状态机形成主动反向制动。

条件积分规则：输出不饱和时接受 I_try；触及当前方向区间上界且 e<0、或触及下界且 e>0 时允许积分朝脱离饱和方向变化；其余冻结积分。积分自身也有限界；抗饱和必须使用最终执行区间，不能只检查对称幅值限幅而遗漏零端约束。实现后用独立数值向量验证，测试不能重复调用同一公式作为“期望值”。

目标先经过以 rpm/s 表示的斜坡限制，再送 PI。输出在转向逻辑后映射到桥，零目标进入停止分支，不在零速附近维持积分顶住电机。STOP、故障、重新 ARM、控制模式切换和反转换向阶段清积分与相关滤波历史；起动重新建立有效采样。

参数包括 `Kp`、`Ki`、`I_limit`、`duty_limit`、`target_limit_rpm`、`ramp_rpm_per_s`、`alpha`、反转和故障阈值。仅在 DISABLED 状态可更新参数，校验范围与有限性，拒绝 NaN/Inf 和不合法 dt。V1 不写入 Flash；重启恢复版本化默认值，运行参数哈希写进日志。

## 8. 状态与故障优先级

| 当前状态 | 事件/前置条件 | 下一状态及输出 |
| --- | --- | --- |
| BOOT | 完成基本初始化与自检 | DISABLED，驱动保持关闭 |
| DISABLED | 新 ARM，会话有效、配置完整、故障已清、静止条件满足 | ARMED，目标为零，驱动关闭 |
| ARMED | 合法非零 SET，能力允许 | RUN_OPEN 或 RUN_SPEED，按斜坡起动 |
| RUN_OPEN / RUN_SPEED | 反向目标 | REVERSING，执行停稳协议 |
| REVERSING | 降速到零、撤销驱动后停稳且保持时间满足，命令租约有效 | 对应 RUN，重置状态后升速 |
| ARMED / RUN / REVERSING | STOP | DISABLED，撤销驱动、清目标和积分 |
| 任意可运行状态 | 锁存故障 | FAULT，立即请求关闭，保存首因和后续故障位 |
| FAULT | CLEAR 且故障条件解除、目标为零、静止确认 | DISABLED；必须新的 ARM 和 SET 才能转动 |

同周期多个事件：硬件关断/复位 > 软件故障 > STOP > 参数与运动指令。故障前命令不保留到清故障后的自动运行。

| 故障 ID | 触发条件 | 动作与证据 |
| --- | --- | --- |
| F01 COMMAND_TIMEOUT | ARMED/RUN/REVERSING 无新鲜合法运动命令或心跳超过 500 ms 初值 | 最迟下一个控制周期撤销使能；记录最后有效 seq/时间 |
| F02 FEEDBACK_INVALID | 不可信 dt、超物理上限增量、不可消歧回绕 | 不把失效速度送 PI；关闭并记录原始计数 |
| F03 NO_FEEDBACK_OR_STALL | 启动宽限期后，足够驱动/目标下连续无有效进展 | 关闭；明确无法单靠该检测区分断线/堵转 |
| F04 CONTROL_DEADLINE | 控制执行超周期、检测到漏周期 | 关闭并记入口/耗时；完全挂死由独立看门狗兜底 |
| F05 REVERSAL_TIMEOUT | 反转不能在限定时间内可靠确认停稳 | 关闭，禁止盲切方向 |
| F06 INVALID_CONFIG | 校准/电平/时序所需参数缺失或非法 | 禁止 ARM，不让“默认参数”绕过硬件冻结 |

F03 的 `startup_grace_ms`、`no_feedback_ms`、最低有效占空比与目标阈值必须来自开环试验并记录最大检测延迟；它不是短路/过流保护。过流/欠压若无传感器或驱动故障输出，只能列为外部硬件覆盖和观察项，不伪造可读故障位。

## 9. 命令与遥测

串口初始方向为 115200、8N1，最终由实测和带宽预算冻结。接收采用有界缓冲，单条 ASCII 行最大 96 字节；超长行丢弃到换行，半帧超时不刷新租约。

拟定命令语义为 HELLO、ARM、SET_DUTY、SET_RPM、HEARTBEAT、STOP、CLEAR、CONFIG、STATUS。除 HELLO/STOP/STATUS 外，命令带当前会话标识和严格递增 seq；会话来自本次 HELLO 协商，复位/断开后清空旧邮箱。重复、倒序、未知命令和非法参数明确 NACK，不刷新命令租约；seq 耗尽时重新建立会话。STOP 始终撤销使能且幂等，不能因会话不匹配拒绝停止。CONFIG 仅 DISABLED 可用。协议详细语法与正反例在 P1 先写入工程 README，再实现。

遥测采用带版本、长度、类型、序列号和校验的定长/有界二进制帧；主机工具解码为 CSV/JSONL。单个控制样本帧预算 ≤64 字节，100 Hz 时 ≤6.4 kB/s，保留 ACK/状态余量；实际按 8N1 字节预算核算。帧错、缺序、断连和丢队列均计数。格式偏移、大小端、浮点表示、校验算法和测试向量在 P1 冻结，不能凭默认 C struct 对齐直接发送。

必须能够还原：单调时间、样本 seq、目标原值与斜坡值、原始计数增量、原始/滤波转速、PI 积分与限幅状态、输出幅值/方向、运行状态、故障位、控制耗时、丢样计数。若一帧容纳不下，拆分关联记录并重算带宽，不能静默删除验收字段。元数据保留完整 CPR、时钟、滤波、控制增益、阈值与硬件身份。
