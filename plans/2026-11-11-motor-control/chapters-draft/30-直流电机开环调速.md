# 30 直流电机开环调速：占空比、斜坡与停止语义

> 占空比决定驱动给电机通电的时间比例，不直接决定转速。把 50% 当成“半速”，是开环调速最常见的错觉。

## 进入问题

占空比设成 50%，为什么速度不是最高速度的一半？

因为占空比控制的是**驱动施加电压的时间比例**，近似平均电压；转速由平均电压、电机参数（电阻、反电动势常数、减速比）和负载转矩一起决定。空载时 50% 可能接近半速，带上负载会明显偏低；低速段还有静摩擦门槛——占空比太低时电机只嗡嗡响不转。开环的真实含义是：**你给的是电压激励，转速是电机自己定的**。测量它、闭环修正它，是第 32 章的事。

## 最小胜利（M30-A：三档占空比与波形）

**目标**：限流电源下，低占空比起转，逐步加到中、高两档，每档用万用表/示波器确认 PWM 频率与占空比，同时读出遥测里的驱动模式。

1. 完成 M29-A/B（逻辑侧检查与限流试转门槛）。
2. 主机串口连接（USART1，115200 8N1），发 `HELLO`，按协议握手建立会话。
3. 发 `ARM`：固件释放 STBY，驱动进入待命。
4. 发 `SET_DUTY 200`（20%），观察电机是否起转；记录 `STATUS` 回读。
5. 依次 `SET_DUTY 400`、`SET_DUTY 700`，每档记录遥测 `SAMPLE` 帧中的占空比与状态字。
6. 发 `STOP`，确认驱动撤销使能。

**预期证据**：三档转速单调上升；PWM 频率 20 kHz（第 29 章门限内）；`STOP` 后遥测显示驱动模式回到关闭。只展示波形或模拟日志不算转动证据——必须记录电源限流值与每次试转时长。

> 状态：M30-A/B/C 待实物到货并过硬件门后执行；当前为候选步骤。

## 核心机制

### 可复算的 PWM 配置

本工程冻结值（`boards/f103c8-tb6612/board_config.h`，CANDIDATE）：

| 项 | 值 | 复算 |
| --- | --- | --- |
| TIM3 时钟 | 72 MHz（PSC=0 不分频） | 8 MHz HSE × PLL9 |
| ARR | 3599 | 72 MHz / 20 kHz − 1 |
| CCR | duty‰ × 3600 / 1000 | 50% → 1800；100% → 3600，**须大于 ARR** |
| PWM 模式 | 边沿对齐模式 1 | CNT < CCR 期间有效 |

端点语义：CCR=0 输出恒无效电平（对高有效配置即 0%）；**CCR>ARR 输出恒有效（100%）**——CCR=ARR 时仍有一格无效（3599/3600 ≈ 99.97%），这是 PWM1「CNT < CCR」定义的边界，程序里要满压必须写 CCR=3600。两个端点都允许，程序里用它们表达“撤销驱动”和“全压”。

为什么选 20 kHz：高于可闻频段（电机与电源的啸叫）、远低于 TB6612 的 100 kHz 上限、ARR 仍在 16 位内。换时钟树必须重算 ARR/PSC 并重新核对这三条。

### 带符号占空比：方向与幅值分离

固件内部统一用**带符号占空比**（−1000…+1000，‰）：符号是方向，绝对值是幅值。映射到引脚只有一处（`motor_bridge.c`）：符号决定 AIN1/AIN2 谁高谁低，幅值决定 CCR。上层任何命令、PI 输出、斜坡都走这个表示——避免“方向寄存器”和“幅值寄存器”两处状态不一致的 bug。

两个限幅在符号化之前已经生效：输出限幅 |u| ≤ duty_limit（默认 900‰，params_valid 会拒绝 ≥1000 的配置），积分限幅 |I| ≤ i_limit（默认 500‰）。第 32 章会看到这两个数为什么必须分开。

### 斜坡与停止策略

占空比不是命令一到就跳变的。冻结默认行为：

- 开环模式下占空比按 **±50‰/10 ms** 斜坡逼近目标——受控起动、换向后从零升速都靠它；
- `STOP` 撤销使能并回到待命；命令流中断 **500 ms**（租约，F01）固件锁存故障停机——串口拔掉不会留下一只转动的电机；
- 方向翻转**必须**走 REVERSING 合同：占空比斜坡降到 0 → 撤销驱动等停稳（|rpm| ≤ 5）→ 保持 100 ms → 才允许换向输出，全程 3 s 超时保护。跳过停稳直接换向是第 29 章说的回流尖峰来源之一。

停止语义的选择权在你：`motor_bridge` 支持滑行与短接制动两种 PWM=0 映射（配置项），待机由 STBY 统一负责。默认配置与各自代价在第 29 章三态表中。

## 命令与遥测（协议 v1 冻结）

| 命令 | 作用 | 关键约束 |
| --- | --- | --- |
| `HELLO` | 握手，分配 8 位十六进制会话号 | 会话内序号单调，乱序/重复按协议丢弃 |
| `ARM` | 释放 STBY，进入待命 | 配置非法（如编码器未标定）时拒绝并给故障码 |
| `SET_DUTY n` | 开环目标（−900…900） | 符号翻转触发 REVERSING，不立即换向 |
| `SET_RPM n` | 闭环目标（±target_limit） | 需反馈有效，详见第 31/32 章 |
| `STOP` | 撤使能回待命 | 豁免会话检查，但总是停使能 |
| `HEARTBEAT` / `CONFIG` / `STATUS` / `CLEAR` | 租约续约 / 参数 / 回读 / 清故障 | CLEAR 仅 DISABLED 态可用 |

遥测帧固定 43 字节（`AA 55` 头 + 类型 + 长度 + 序号 + 时间戳 + 负载 + CRC8），100 Hz 下 4.3 kB/s；按 8N1 每字节 10 bit 计是 43 kbit/s，**占 115200 波特率的 37.3%**。控制指令流量远小于遥测（每秒几帧），余量仍充足；需要更高遥测率时先评估总线占用，必要时降遥测帧率。帧布局逐字段定义在 `examples/motor-dc-speed/README.md`。

## 失败分支与最短排查

| 现象 | 区分证据 | 下一动作 |
| --- | --- | --- |
| 低占空比只响不转 | 提高占空比是否起转；电源电流是否到限流值 | 起转=静摩擦门槛，用斜坡从低往高扫；到限流=负载/卡滞 |
| 反向命令瞬间大电流/尖峰 | 遥测状态字是否经历 REVERSING 各阶段 | 未经历=直翻违约，检查固件版本；经历了仍尖峰=查制动续流与电源吸收 |
| 串口发 STOP 无效 | 会话是否过期（回 NACK 码） | STOP 豁免会话；无效说明不是命令路径问题，查状态机是否已在 FAULT |
| PWM 已归零但电机减速很快 | 当前是短接制动映射 | 要滑行改配置；制动本身是特性不是故障 |

## 迁移边界

- 换驱动：PWM 有效极性、使能端逻辑、PWM=0 的语义（第 29 章迁移条目）全部重查。
- 换电机：20 kHz 下仍适用，但起转门槛、允许连续电流、减速比全变——斜坡步长与限幅要重新定。
- 换 MCU/时钟：重算 ARR/PSC；TIM4 控制时基是本工程的 10 ms 心跳（PSC 7199/ARR 99），**不要用 LED 呼吸灯的软件延时循环当控制时基**——那个周期不保证恒定，斜坡与租约会跟着漂。
- 上 RTOS：控制输出所有权唯一（design §4），命令任务与控制任务之间只过邮箱，不共享输出变量。

## 记忆锚点

**“占空比是踩油门的深度，不是速度表。”**

相似点：深度直接决定发动机出力（平均电压），同一路况（负载）下深踩确实更快。
失效点：路况变了同样深度速度不同；车还有惯性——方向切换必须先刹停（REVERSING），踩油门跨不过去。
