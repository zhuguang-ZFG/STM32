## 2. 采购规格（v1.0 冻结，到货后补实物核验）

| 项 | 冻结规格 | 依据/边界 |
| --- | --- | --- |
| MCU | STM32F103C8T6 最小系统板（已有或随单购买，LQFP48，72 MHz） | DS5319 Rev 20 已核验；Flash/RAM 余量于 MC-102 构建时实测 |
| 电机 | 有刷直流减速电机 + 磁式 A/B 两相正交编码器；额定 6–12 V；减速后额定转速 100–400 rpm；电机轴 PPR ≥ 11（四倍频后 CPR ≥ 44/轴转）；**堵转电流 ≤ 1.0 A**；编码器输出为开集电极或推挽 3.3 V 兼容 | 堵转电流上限对齐驱动连续能力（见下，候选值）；PPR/减速比以供货规格页为准并留档（AC02） |
| 驱动 | TB6612FNG  breakout 模块，VM 5–12 V，**连续电流 ≥ 1.2 A / 峰值 ≥ 3 A**（候选值，官方手册 403 未核验，见 §5 BLK-P0-2）；带 STBY 上拉/下拉可跳线 | 真值表先用候选版（用户已批准，P2 前必须官方核验）；模块需引出 PWMA/AIN1/AIN2/STBY/VM/VCC/GND |

| 仪器 | 现有：万用表。**缺口：示波器、逻辑分析仪** | 波形类独立对照（B 系部分项）保持 BLOCKED；先以主机 golden vectors + DMM 电压/电流完成可做的验收 |

## 3. 资源映射草案（候选）

冻结前仅作布局草案；引脚复用已在 DS5319 Rev 20 p.29 核实存在相应复用功能。

| 功能 | 候选引脚/外设 | 复用核实（DS5319 p.29） |
| --- | --- | --- |
| 编码器 A/B | PA0 / PA1 = TIM2_CH1 / TIM2_CH2（编码器模式，RM0008 p.329/392 SMS=011） | TIM2_CH1 ✓ |
| PWM | PA6 = TIM3_CH1（20 kHz 起点） | TIM3_CH1 ✓ |
| 方向 IN1/IN2 | PB12 / PB13（GPIO 推挽） | 引脚存在 ✓（p.22–23） |
| 待机 STBY | PB14（GPIO，默认低 = 待机） | 引脚存在 ✓ |
| 遥测/命令 UART | PA9/PA10 = USART1_TX/RX | PA9 ✓（p.23/25） |
| 独立看门狗 | IWDG（RM0008 待补节号） | — |

冲突检查：TIM2/TIM3/USART1 互不冲突；PB12–PB14 与 JTAG 复用关系待 MC-102 调试下载时实测（SWD only 下一般可用）。
