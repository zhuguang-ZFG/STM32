## 本轮确定的实施方向

- 正文接在根书 28 章之后，第一期新增 29–32 四章，完成后根书为 00–32 共 33 章；实际对外计数只随已交付章节更新。
- 第一期仅一台带正交编码器的有刷直流减速电机，先开环、再测速、最后 PI 速度闭环。基础工程使用裸机定周期控制与 HAL；RTOS 迁移只解释边界。
- 以 STM32F103C8T6 + TB6612FNG 模块作为待核验候选，电机具体型号、驱动余量、编码器电平和电源必须在 P0 冻结。硬件不满足时更换相应候选，保留变更原因。
- 一个完整固件工程包含三个可独立构建的实验配置；控制核心可以在主机测试。`labs/` 保存实验协议，原始测量与汇总单独归档。
- 默认停止采用经驱动真值表核实的高阻释放策略；短接制动作为明确选项，不能将 PWM=0 直接描述为滑行或机械急停。
- 固件编译、主机算法测试、真实电机性能分开验收。没有真板证据时，只能交付开发候选，不能标记第一期实战完成。
