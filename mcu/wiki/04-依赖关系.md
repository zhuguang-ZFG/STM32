# 04 · 依赖关系

## 4.1 npm 依赖（`package.json`，全部为 devDependencies）

| 依赖 | 版本 | 用途 |
|---|---|---|
| `vitepress` | ^1.6.3 | 站点构建与开发服务器 |
| `@playwright/test` | ^1.63.0 | 浏览器测试 + 整书 PDF 分页渲染 + 视频/投稿自动化 |
| `puppeteer` | ^25.13.0 | 视频产线逐帧渲染舞台、封面截图 |
| `ffmpeg-static` | ^5.3.0 | 视频产线编码/混音（无需系统安装 ffmpeg） |
| `minisearch` | ^7.2.0 | 站内本地搜索（配合自定义中文分词） |
| `pagedjs` | ^0.4.3 | 整书 A4 PDF 分页 |
| `yaml` | ^2.8.3 | 章节 frontmatter 解析 |

运行时无 dependencies —— 站点产物是纯静态文件。

## 4.4 模块间依赖关系

```
package.json scripts
   │
   ├──► docs:dev / docs:build ──► gen-progress.mjs ──► curriculum.mjs
   │        │                            ├──► project-catalog.mjs ──► code/projects.json
   │        │                            └──► content-metadata.mjs ──► docs/** frontmatter
   │        └──► vitepress build docs
   │                 └──► docs/.vitepress/config.mts
   │                        ├──► anim-decorate.mjs（动画内联）
   │                        ├──► code-languages.mjs（语法高亮）
   │                        ├──► ../../scripts/search-render.mjs   ◄── search-check.mjs 也依赖
   │                        └──► ../../scripts/search-tokenize.mjs ◄──（两端必须同一分词函数）
   │
   ├──► firmware:check ──► check-firmware.mjs ──► project-catalog.mjs
   ├──► quality ──► test + projects:check + docs:build + anim:lint + readme:check
   │              + reading:check + links:check + docs:check + nav:check + seo:check
   │              + perf:budget + a11y:check + pages:check + search:check
   │
   ├──► book:html / book:pdf ──► mcu-book/build_html.py ──► manifest.json + docs/** + public/anim
   │                            └──► build_print.py（依赖 build_html 产物 + pagedjs + Chromium）
   │
   └──► video:* ──► video/src/cli.mjs
                        ├──► spec.mjs（episode 解析）
                        ├──► tts.mjs（旁白，按句缓存）
                        ├──► timeline.mjs（渲染计划）
                        ├──► stage.mjs（puppeteer 舞台）◄── calib.mjs（标定其常量）
                        ├──► render.mjs（逐帧 → ffmpeg）
                        ├──► mux.mjs（混音合成）──► audio/sfx.mjs
                        ├──► package.mjs（封面 + 发布包）
                        └──► numbers.mjs ──► video/research/<id>-numbers.json
```

**关键耦合点**：

1. `config.mts` 直接 import `scripts/search-render.mjs` 与 `scripts/search-tokenize.mjs` —— 站点构建与 `search-check.mjs` 共用同一实现，改其中一个文件影响两端。
2. `gen-progress.mjs` 依赖三个共享库（curriculum/project-catalog/content-metadata），是多数内容闸门的上游。
3. 章首题花资产 `mcu-book/book/assets/chapter-art/*.svg` 被站点（`config.mts chapterArt`）与印前（`build_html.py chapter_art_html`）**同源消费**，滤镜硬门两边同口径。
4. 视频上屏数字的唯一事实源是 `video/research/<id>-numbers.json`，`video:numbers` 负责成片对账。

## 4.5 CI 工作流依赖

```
quality.yml ──(workflow_call / 必须全绿)──► deploy.yml ──► GitHub Pages
   │                                            │
   ├─ npm run quality                          └─ 部署前再对 artifact 跑
   ├─ anim:audit                                   pages-check + search-check 对账
   ├─ project-catalog --matrix
   ├─ firmware:check（ARM GCC + FreeRTOS V11.1.0）
   └─ ESP32-S3 矩阵构建（IDF 5.5.2，逐工程干净构建）

book.yml ──► book:html + book:pdf ──► 发布整书产物（/mcu/book/）
links.yml ──► lychee 外链扫描（定期，.lychee.toml 配置）
```

发布纪律：**deploy 必须先通过同一提交的全部质量检查**；整书产物由 book.yml 独立构建发布。
