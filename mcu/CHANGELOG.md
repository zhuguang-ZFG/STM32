# 更新日志

面向**发布**的变更记录：这里按版本记「读者能感知到什么变了」。日期分节的过程记录在站点侧的 [docs/reference/changelog.md](docs/reference/changelog.md)，两者分工不同：

- 本文件：版本号 + 该版本对外承诺的变化；
- 站点侧：按日期记每次改动的来龙去脉（含没改成的、有待回填的）。

`scripts/docs-check.mjs` 会对账：这里的每个版本号都必须能在站点侧更新日志里找到，且最新版本号必须等于 `mcu-book/manifest.json` 的 `version`——防止两处口径各自漂移。

格式沿用 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## v1.0.0 · 2026-10-23

首个整书版本：88 章正文装订成单文件离线书，随站点发布。

### 新增

- **整书离线版**：`mcu-book/` 把 88 章装订为 10 部 + 6 附录的单文件 HTML（图片内嵌、动画即播、断网可读）与 A4 PDF（书签树为「部 → 章 → 节」三级）；站点导航「资料 → 整书离线版」直达 HTML / PDF。
- **本章罗盘**：每章开头给出核心问题、读完交付、论证边界与依据锚点，88 份逐章撰写。
- **配套工程索引**：47 个可构建工程成表；60 项冻结来源成表，正文引用必须被登记表覆盖。
- **出版契约**：章节、罗盘、测验、工程索引四向对账，缺一即构建失败（`mcu-book/tests/` 10 条回归 + `book.yml`）。

### 修复

- **PDF 打印不再丢内容**：344 处 `<details>` 折叠块（多为「参考答案」）此前以收起状态直接打印、整段缺失；现在打印/PDF 前自动展开，抽检两条此前丢失的答案已可全文检索。
- **4 处站内死链**：F5「下一站」少写 `-timer`、P4 越出站点 `base`、B7 与 C7 收官两处 `.md` 原始锚点——由整书构建器的零断链审计反向揪出。

### 已知限制

- 上板实测状态如实标注：未跑过板子的实验标「待实测」，禁止把成稿数说成实测数。
