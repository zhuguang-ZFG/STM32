## 成与不成，各看一个信号

- **成功**只认弹窗「发布成功 / 感谢你的第 N 篇创作」。页面 URL 不变，别拿跳转判成败。
- **失败**的权威信号是 `POST /api/v4/content/publish` 的 **响应体**：`.code` + `.toast_message`。
  HTTP 200 也可能带着 error；上一版只看状态码，把「服务端拒了」读成「前端拦住了」，白跑一轮。
- 点完一个非 GET 请求都没发出去 = 前端拦下，去读表单状态栏；请求发了 = 看响应体。

**被拒的那几次本身就可能刷新窗口，所以窗口没过就别再点。** 这是账号级滚动限制，脚本无法绕过，也不该绕。

所以计时起点不是「上一次我们自己发」，而是**账号上最后一次真实发布成功**，本账号当晚还有别的会话在投【STM32零基础自学】。

## 闸门与留痕

- 闸门 `zh-run/I_HAVE_USER_OK=<ep>`：只来自对话里对这一条投稿的点头，脚本不许自己造。
  `zh-one.mjs` 对它**只读不删**，所以同一条能被反复点；`f5-zh-publish.mjs` 起改成成功即删闸门。
- 留痕 `zh-run/<ep>-published.txt`：内容为落地 pin 链接。缺留痕 = 当作没投。
  片单 18 条里 16 条有留痕；`c3b-volatile` 是设计上只发抖音（`video/out/c3b-volatile/` 只有 douyin 素材），不算缺口。
- 校验清单 8 项：片源 / 标题 / 标题长度 / 介绍非空 / 封面 1920×1080 / 视频标记 / 所属领域 / 原创视频。

## 别在共享浏览器上手搓

所有平台共用 `chromium.launchPersistentContext('D:/Users/mcu/.temp/douyin-profile')` + `--remote-debugging-port=9223`，
