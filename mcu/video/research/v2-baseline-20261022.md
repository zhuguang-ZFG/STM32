### 校验和

- 路径：`.temp/v2-baseline-20261022/masters.sha256`
- 内容：37 行 sha256，条目形如 `./s5-systick/bilibili.mp4`，相对 `masters/` 目录。
- 因条目为相对路径，校验必须在 `masters/` 内执行：

```bash

sha256sum -c ../masters.sha256 --quiet   # 无输出即通过
```

## 复现与验收

```bash
# 1) 校验母版未损坏（在 masters/ 内执行）
cd .temp/v2-baseline-20261022/masters && sha256sum -c ../masters.sha256 --quiet

# 2) 计数
find .temp/v2-baseline-20261022/masters -name '*.mp4' | wc -l   # 37
find .temp/v2-baseline-20261022/stills -name '*.png' | wc -l    # 111
grep -c '排版审计通过' .temp/v2-baseline-20261022/check-before.log      # 37
grep -c '还没有时间轴，跳过' .temp/v2-baseline-20261022/check-before.log # 0

# 3) fixture 非空
test -s video/tests/fixtures/page-v1-s5-bilibili.html
test -s video/tests/fixtures/page-v1-s5-douyin.html
```

注意：`masters.sha256` 内是相对 `masters/` 的路径，在仓库根直接 `sha256sum -c .temp/.../masters.sha256` 会报 `No such file or directory`；请先 `cd` 到 `masters/`（或使用上面的验收片段）。
