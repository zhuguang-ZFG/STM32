# 安全

这是一套教学材料，不是在线服务，也没有账号系统。这里说的"安全"只有两件事：**照着做会不会伤到人**，以及**照抄的数字会不会把人带沟里**。

## 用电与接线

- 动板子之前先断电：SWD/串口线插拔一律在两侧都断电时进行，热插拔 3.3V 与 GND 造成的瞬态足以打坏 IO。
- 别用板载排针直接驱动电机、继电器线圈这类感性负载；要驱动就加驱动级与续流回路。
- 锂电池（ESP32-S3 模组那路电池 ADC）不要做短路、过充、过放实验；阈值一律以电芯规格书与芯片手册为准，正文里的数字是示例。
- 拿不准的接线先画图再上电；烧掉一块板子的代价远高于多问一句。

## 怎么报告

文档或示例代码里如果有下面这类问题，请开 [Issue](https://github.com/zhuguang-ZFG/mcu/issues/new/choose) 并写清**文件、原文、依据**：

- 会让人照着做出危险实验的步骤；
- 把示例阈值/示例工程说成产品限值或实测结论；
- 与芯片手册、头文件或本机实跑输出矛盾的数字。

不要把密钥、板卡序列号或别人的数据提交进仓库。学习问题请走讨论区，不要当成安全漏洞提。
