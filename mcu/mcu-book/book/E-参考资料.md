# 来源、版本与许可

本书的每一句"手册说""标准规定""论文证明过"都必须能翻到原文。这一附录交代三件事：证据纪律、正文引用标签与来源注册表的对应关系、以及许可与再分发边界。下方注册表由构建器从 `mcu-book/manifest.json` 自动渲染，与本附录文字同源。

## 证据纪律

1. **版本号是结论的一部分。** 寄存器位看手册修订版（Rev），行号看代码 tag/commit，API 看文档版本。三样对不上，先怀疑口径，再怀疑教程，最后才怀疑芯片。
2. **代码基准冻结点：** FreeRTOS-Kernel **V11.1.0**（ARM_CM4F 端口）、ESP-IDF **v5.5.2**、CMSIS device_f4 **v2.6.11**、SPL **V1.8.0**、GD32 固件库 V3.3.3 / @7ab0521。RT-Thread 未固定 tag（master 稀疏检出），这是本站已知的可复现性缺口：R 篇行号可能随上游漂移，已在注册表 `f8` 如实标注。
3. **"待上板实测"制度：** 凡是没有接仪器量过的现象，正文与实验页一律标注「待上板实测」，空白记录表不表示验证通过。本书不把这些数字当已验证数据引用。
4. **社区内容只作线索：** 会改变产品行为的结论必须回到目标版本的一手资料（手册/规范/冻结源码）与实测。

## 正文标签对照

章节正文沿用站点的参考文献标签体系（`[D2]` 这类写法），与本附录注册表 ID 的对应关系是**字母区相同、编号相同**：正文 `[A1]` = 注册表 `a1`（RM0090），`[D2]` = `d2`（优先级继承论文），`[F1]` = `f1`（FreeRTOS V11.1.0），以此类推；三个小写 `mcu-*` 条目是本仓库自有的工程/实验/动画资产。每个章节开头的「本章罗盘 · 依据锚点」列出的就是该章结论所依赖的注册表条目。

## 许可与再分发边界

- **书稿正文、版式与机制动画**：Apache-2.0（与仓库 [LICENSE](https://github.com/zhuguang-ZFG/mcu/blob/main/LICENSE) 一致），可自由转载与二次创作，需保留署名与许可声明。
- **被逐行引用的上游代码**（FreeRTOS、ESP-IDF、CMSIS、HAL、SPL、GD32 固件库、RT-Thread）：本书仅链接、引用行号并独立表述，不随书再分发其源码；各归其上游许可。
- **外部手册、规范、论文与书籍**：只作链接与事实引用（文档号/DOI/ISBN 与版本），权利归原权利人；注册表每张卡片都标了许可边界。
- **商标**：STM32 是 ST 的商标，ESP32 是 Espressif 的商标，GD32 是兆易创新的商标，FreeRTOS/RT-Thread 归各自权利人；本书作为独立教学材料使用这些名称仅出于指称目的。
