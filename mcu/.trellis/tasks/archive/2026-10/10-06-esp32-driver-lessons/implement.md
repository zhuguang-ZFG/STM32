   - [ ] 确认 IDF 实际版本；核对 `soc_caps.h` 中 LEDC/UART/GPIO 相关宏。

2. **引脚**
   - [ ] 落实板卡引脚表（功能、可用性、板载占用）。
3. **工程**
   - [ ] `code/esp32/01-gpio-matrix`、`02-uart-events`、`03-ledc-fade`：`idf.py set-target esp32s3` + `build` 通过，`idf.py size` 留证。
   - [ ] 每工程 README：IDF 版本、引脚、构建/烧录命令、观察方式、排查。
4. **章节**
   - [ ] P2 GPIO Matrix 成稿（P-F1）。
   - [ ] P5 UART 驱动成稿（P-F2 + STM32 DMA 对照）。
   - [ ] P7 LEDC 成稿（P-F3 + STM32 TIM 对照）。
   - [ ] E03 ESP32 部分同步。
5. **动画**
   - [ ] 三张新图 + 逐阶段解说；XML/viewBox/字号/SMIL/浏览器目检。

## 门禁

- 每个 API 结论对应本机 v5.5.x 源码位置；路径引用与实际目录一致。
- 三个工程构建通过。
- 无未核实引脚作为板上事实。
- `npm run docs:build` 零错误。

## 失败处理

板卡引脚资料无法取得时：不猜引脚，把示例收敛为“集中配置点 + 明确说明依据缺口”，并在正文显式标注该缺口；不以常见开发板引脚替代。
