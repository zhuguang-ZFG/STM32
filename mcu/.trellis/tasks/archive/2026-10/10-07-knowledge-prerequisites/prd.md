# 高依赖前置章节成稿

## 目标与依赖

依赖 knowledge-fact-corrections 的 F-A1–F-A7；使用其正确的计数、并发、IRAM 和学习关系。父任务 knowledge-closure，用户选择双板完整记录器，因此 ADC 与两平台移植/调试前置必须覆盖。

## 交付范围

- P1：C0/C2/C4/C5/C6、B1 共六篇。C0 可短篇；C5 与 S4 的对照标 parallel，不能人为互相阻断。
- P2：S1/S4/S5/S9/S16 五篇，包含中断接线、时间基准、ADC 实采路径与 HardFault 取证。
- P3：F0/F8 两篇，F0 用失败案例说明需求，F8 基于现有 FreeRTOS 工程完成可复现移植。
- P4：P1/P3/P4 三篇（ESP32 章号），分别讲架构/启动、工程配置、双核/IRAM；避免和父需求 ID 混淆。
- 共 16 篇目标章，均为已有 building 页面。每章完成正文、源码例子、反例、自测、版本与验证边界，不能只补目录再标 done。

## 验收

- P-A1：16 篇满足 docs-site 章节规范；C0/F0 虽短也有具体可验证学习目标。
- P-A2：读者能从 B1 的四步构建、C6 的寄存器/栈帧一路走到 S4 异常和 F8 首任务运行，不依赖未解释的必要步骤。
- P-A3：C4 给宽度/偏移/端序实测；C5 给回调/有限状态机/有界缓冲及明确并发前提；S5 的回绕/周期调度有测试。
- P-A4：S9 有真实 ADC 工程而非只有 SAR 算法探针；解释采样时间、触发周期、参考电压、抗混叠和滤波延迟的边界。
- P-A5：S16 能按有效性位、MSP/PSP/基本或扩展栈帧定位故障；异常注入条件可复现，不声称任意除零/未对齐都会故障。
- P-A6：F8 与 P1/P3/P4 的依赖版本/栈单位/中断 API 分清；示例构建，配置/符号/段位置可核对。
- P-A7：对本批及原成稿的 must 依赖核对无遗留循环或隐藏前置，统计/导航/清单/CI 同步。

## 范围外

本批不完成整条 RT-Thread、S12/P6/P8/P10 等全部后续章；必要背景可在目标章自足说明，选读链接明确标注。上板缺证据时不填假结果。
