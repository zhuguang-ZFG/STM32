gzip 减少 9.4%。调整后还加入了新实验与纠正文案，比较非纯相同语料压缩基准。

完整代码块不再重复进入本地全文索引，正文、标题、行内 API 标识符保留；源码仍完整显示在章节中。没有改动 chunkSizeWarningLimit，raw 超过 500kB 的告警仍保留。理由：实际首屏未请求该索引，仅打开搜索后请求一次；当前 gzip 约 280.1 KiB。继续按警告追踪增长，而不是为消警告牺牲正文搜索。

最终测量：I2C 搜索 16 个结果；动画暂停、播放、减少动效均通过；页面脚本错误 0 个。3 个独立 Playwright 回归验证搜索按需加载及跳转、深色/减少动效、移动实验卡不溢出。

基线脚本最初只等待 800ms 即截取搜索，尚未完成索引加载，故 baseline JSON 的 results=0 不用来断言旧搜索损坏或衡量搜索速度；最终脚本等待实际结果。基线原始文件大小与首屏资源记录有效。

复跑：`npm run site:measure -- current`，先构建；默认 Chromium，本机可设置 PLAYWRIGHT_CHANNEL=msedge。JSON 与截图在本目录及 test-results/performance。
