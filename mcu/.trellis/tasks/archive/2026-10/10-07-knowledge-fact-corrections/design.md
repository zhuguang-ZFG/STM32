# 纠错设计

## TIM 输出与测量分离

保留 TIM3_CH1/PA6 的 PWM，测量迁移到独立 32 位 TIM2 自由计数器，候选 PA0/TIM2_CH1。实施前确认 F407 复用表、计数位宽和输入映射；新接线 PA6→测量脚，不能仍写 PA6→PA7。

计数时钟 1MHz、ARR=0xffffffff；仅在两次有效捕获间隔小于一整圈且未丢边沿时使用 uint32_t 模差。约 4294 秒回绕范围是理论界限，不是本例承诺的测量周期；示例另设更短信号超时。首次捕获仅建立基准，delta=0、过捕获、无信号均有明确无效状态。

ISR 快速读取状态/捕获值并更新可一致读取的快照，主循环不在 20ms 轮询中承担边沿消费。状态位清除遵循实际 rc_w0/读序列语义，不能读改写误清后到事件。抽取的时间戳判定逻辑由固件和宿主共用。

## DMA 消费模型

定义“DMA 写位置”和“软件已消费位置”两个独立量。IDLE 是服务提示，不是应用帧边界；HT/TC 同样触发消费。中断只搬运有界数据并发布，回显在主循环执行。

用半缓冲处理期限和可观测的圈数/事件状态判断覆盖；仅模 N 的位置不足以区分空与完整一圈。事件处理采用同一串行化策略，明确 IDLE 与 TC 同时到达的顺序。无法证明未覆盖时标记丢失、丢弃不可信片段并重建游标，不读旧内存凑帧。

宿主模型先定义生产的字节流、事件和预期消费，再驱动真实消费函数；禁止只针对实现公式自证。

## 并发、IRAM、OTA

- 同步表按任务/ISR/SMP 列出参与者、保护方式、可调用 API 与优先级限制；volatile 只保留对应编译器访问语义。
- IRAM 以 IDF 5.5.2 intr_alloc.rst 的两类路径为准；闭包包括间接调用/常量数据。
- OTA 以 CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE 和实际状态枚举为前提；补开关开启/关闭两组流程，确认 API 给全名。
- 本批用配置/源码证据验证上述前提；后续 P4 成稿再提供完整实验，不伪造缓存崩溃或回滚日志。
