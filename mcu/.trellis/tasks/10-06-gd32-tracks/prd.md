# PRD：GD32 双系路线

## 背景

主站已有 STM32F407 / FreeRTOS / ESP32-S3 三路线共 18 章成稿。用户方向（2026-10-06）：补充 GD32 知识点，**双系并行**（ARM GD32F4xx + RISC-V GD32VF103），**先不定板卡、按芯片写**。

价值：GD32 是国产出货量最大的 MCU 家族之一，寄存器布局与 STM32F4 高度相似又有实质差异（RCU、200/240MHz、外设增强点），是"举一反三"的最佳教材；GD32VF103 则是入门级 RISC-V MCU 名芯，可把读者已会的 ARM 知识平移到 RISC-V。

## 目标

1. **G 篇（GD32F4xx）**：与 S 篇同构的寄存器级对照路线，核心卖点是"同名不同姓"——RCC↔RCU、168MHz↔200/240MHz、Flash 等待表差异、USART 增强点。
2. **V 篇（GD32VF103）**：RISC-V 迁移路线，讲清四件事：启动文件、链接脚本、CLIC 中断、MTIME 定时。
3. 两路线最终各配 ≥1 个可构建裸机工程（G 篇复用 xPack ARM GCC；V 篇需先装 RISC-V 工具链）。

## 非目标

- 不做成"又一条全量外设路线"（不把 S 篇 17 章全部平移）；每系 4-6 章打透差异点即可。
- 不写板卡接线（待用户指定基准板后回填）。
- 不动既有三路线的任何成稿结论。

## 验收标准

- 章节遵守主站结构契约（title=H1、四件套、对照表、短自测）。
- 每个数值有 `.trellis/ref/gd32/` 官方库源码或 UM 出处；UM 未取得处标"待 UM 核验"。
- 动画遵守 SMIL 规范（viewBox 720、values/keyTimes 计数一致），新图登记 CONTRIBUTING.md。
- `npm run docs:build` 零错误（ignoreDeadLinks=false）；/gd32/ 接入导航与侧栏。
- G 篇工程构建通过（xPack ARM GCC）；V 篇工程待工具链安装后构建。

## 里程碑

- M1（本轮）：建档 + 导览页 + 导航接入 + 一手源码入库。✅
- M2：G 篇 G1（RCU 时钟树）成稿 + 动画 + 裸机工程。
- M3：G 篇差异点合集 + V 篇 V0-V1（工具链/启动/CLIC）。
- M4：V 篇 V2-V4（RCU/MTIME/最小系统）+ 工具链安装与工程构建。
