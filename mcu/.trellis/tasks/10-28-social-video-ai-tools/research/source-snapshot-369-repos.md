它内置了 59 种针对 Claude Opus 5.5 深度调优的代码影片风格，每一种都标配风格提示词与纯代码渲染的样片，全程无需调用任何昂贵的 AI 视频生成模型。其代表作“OPUSCAR 98”是一支长达 6 分 31 秒的震撼样片，一次性展现了 98 种奥斯卡级别的 2D、2.5D 与 3D 视觉风格。

二、场景深挖：其他值得重点关注的硬核项目
除了四大天王，我还从 300 多个库中筛选出了一批在垂直领域解决痛点的优秀方案。
1. 自动化剪辑与人机协同
全自动转录剪辑： browser-use/video-use。直接把原始素材扔进文件夹，Agent 依赖逐词转录自动下刀，剔除语气词和停顿，完成字幕与 FFmpeg 调色，动效再交给 HyperFrames 或 Remotion（需自备 ElevenLabs API Key）。注意：模型不直接看画面，它完全基于文本逻辑剪辑。
人机协同微调： 机器剪完后，如果需要人类介入时间线微调，OpenChatCut 和 BaoCut 是最佳选择。
低星前沿探索： 11 星的 fragua 跑在本地，无需 API Key 即可用 FFmpeg 完成竖屏去静音和烧录字幕；而 0 星黑马 cutloupe 极其大胆，它提供 MCP 和可视化时间线，通过 look 命令把真实渲染帧送回给模型，尝试解决“让模型看见自己剪的画面”这一行业难题。
2. 代码直出成片与结构化镜头卡
提示词宝库： awesome-opus5-5-videos 收录了高达 703 条 Opus 5.5 的代码成片提示词。遇到绝佳的特效，直接复制提示词喂给自己的 Agent 即可复刻。
工程化镜头卡： video-shotcraft 专为 Remotion 商业片打造，内含 152 张结构化的镜头配方卡和 209 个动效预览。
动效逆向工程： lovisdotio/motion2code 将现有动效视频逆向重建为内联 SVG 和 GSAP 时间线，支持精确定位到任意帧与原片进行严谨对照。
3. 知识讲解、AI 数字人与音乐 MV
知识讲解： Raven 能读取 GitHub 仓库的 Git 提交历史，自动生成两分钟的高清手绘讲解动画；stickman-video-director 则专为不露脸的火柴人科普频道量身定制。
AI 数字人： lanshu-create-ai-presenter-video 坚持供应商中立，主打使用已有授权图生成合规的数字人；digital-human-koubo 极其敏捷，单图加文本即可通过 Renoise MCP 调取 Grok Video 做口型，并在生成前提供清晰的积分计费预估。
音乐视频： PDoomVideo 公开了极具研究价值的完整 MV 源代码；只有 9 星的 mondo-music-video 正在构建一整套音乐视频工作室的基础设施（早期项目，需自行配置服务密钥）。
