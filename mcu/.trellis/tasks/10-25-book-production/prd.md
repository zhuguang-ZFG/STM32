# 做成一本真正的书：16 开印前 PDF + EPUB3

## Goal

把 88 章正文装订成**两件真书形态的成品**：

1. **印前 PDF**：16 开 185×260 mm、精确裁切尺寸（可选 3 mm 出血 + 裁切标记）、正文衬线 + 标题黑体 + 代码等宽且**全部真字体嵌入**、**印在纸上的目录带页码**、页眉页脚与页码自洽；
2. **EPUB3**：可重排电子书，每章一文档 + 导航 + 封面 + 元数据，`epubcheck` 零错误。

正文 markdown **冻结**（v1.0.0 的 88 章一字不改），本轮只改书稿工艺层。

## 现状基线（2026-10-25 实测，证据见 `research/book-production-evidence.md`）

- 现有 `mcu-deep-book.pdf`：713 页、**A4 210×297 mm**、正文 **Type3 位图字形 7.5–8.2 pt**、末页印着 **`713 / 712`**；目录只有 PDF 书签，没有带页码的纸面目录。
- 根因：书稿 CSS 是屏幕优先（1000 px 栏宽 + `clamp()` 字号），Chromium 默认打印把它整体压进 A4。
- 仓库**没有**任何 EPUB / 出血 / 裁切 / 印前 / ISBN 实现；`manifest.json` 没有版权页、前言、索引字段。
- 可用件已核实：`pagedjs 0.4.3`、`@vivliostyle/cli 11.4.0`、本机 `NotoSerifSC-VF.ttf` / `Noto Sans SC (TrueType).otf` / `Source Han Serif SC`、`fontTools 4.66.1`、本机 JDK 17（`epubcheck` 可跑，CI 用 ubuntu-24.04 的 `epubcheck` 包）。

## 已确认的决定（2026-10-25 对话）

1. 单任务分阶段推进。
2. 两件产物都要：印前 PDF + EPUB3。
3. 开本 **16 开 185×260 mm**。
4. **正文冻结**：只做工艺层（字体/版心/分页/目录/页码/索引/电子书），不动 88 章 markdown。
5. **A4 版退役**：站点只提供 16 开印前 PDF + EPUB3，避免两套版式各自漂移。
6. **精品/经典大典升级**（2026-10-25 追加）：按社区与规范把"像一本书"抬到"能当典藏/工具书用"——
   中文禁则、版心与行长按出版惯例、图文编号统一、索引带页码、勘误与贡献者页、EPUB 无障碍元数据。
   依据见 `research/standards-and-community.md`（W3C clreq、EPUB 3.3、KDP 印前口径、Pro Git / cjk-book-builder 等社区做法）。

## Requirements

### R1 印刷样式层（与屏幕样式分离）

- 新增印刷专用样式：开本与版心（内白边略宽）、正文衬线 9.5–10.5 pt / 行距 1.5–1.7、标题黑体、代码等宽且不溢出（超长行按 CSS 折行规则处理）、章首页样式（章题、罗盘）、分部隔页、表格与图不跨页断裂优先。
- **不得直接复用**屏幕 CSS 的 `clamp()`/固定栏宽/`min(100% - 2rem, 1000px)`。
- 字体一律走 `@font-face` 指向随仓库分发的**子集字体**（SIL OFL 1.1，附许可与来源登记），不依赖机器已装字体 —— 否则 CI 与本机排版不一致。

### R2 分页引擎与开本精度

- 产出 PDF 的 MediaBox 必须**精确**为 185×260 mm（±0.5 mm），且不因内容宽度产生缩放。
- 可选 `--bleed 3`：页面扩到 191×266 mm 并加裁切标记；默认**不带出血、精确裁切尺寸**（按需印刷口径）。
- 原型判据（P1 必须先验证再全量）：2 章样本能产出精确尺寸、目录页码解析成功、字体非 Type3、页数合理；不达标则改用 `@vivliostyle/cli`（同 CSS 思路，替换渲染器）。

### R3 前置页

- 封面（封一）、**版本/版权页**（书名、版本、日期、许可、作者、来源与冻结点摘要、构建方式与可复现说明）、前言（现有前言内容保留）、**目录（带页码）**。
- 目录页码由排版引擎产出（`target-counter()`），不是事后文本匹配。

### R4 后置页

- 保留现有 6 份附录；**新增索引**：从正文自动抽取术语（复用 `docs/reference/glossary` 与正文加粗/代码术语的既有来源）→ 术语 + 页码列表，按拼音/笔画序排序（中文书惯例：按拼音）。

### R5 页码与页眉页脚自洽

- 页码用 `counter(page)/counter(pages)` 生成；封面与前置页不编号（罗马数字或留白需在验证时固定口径），正文从 1 起；**末页必须是 N / N**（现行 `713 / 712` 必须消失）。
- 页眉：偶页书名、奇页当前章名；章首页与分部隔页不盖页眉（保留现有规则，改由 CSS 声明而非事后绘制）。

### R6 EPUB3

- 每章一 XHTML 文档 + `nav.xhtml`（两级：分部/章）+ OPF（标题、作者、语言、版本、封面）+ 封面图；正文内链改为文档内/文档间锚点。
- `epubcheck` **0 error**（warning 需逐条说明）。

### R7 内容同一性契约（"工艺改、内容不改"）

- 新增对账：从印前 PDF 与 EPUB3 抽出的**每章正文文本**（归一化：去页眉页脚/页码/连字符与空白差异）必须与现有单文件 HTML 产物的同章文本一致；任何一章不一致即失败。

### R9 精品排版契约（2026-10-25 追加）

依据：W3C *clreq*（中文排版需求）、中文图书出版惯例、KDP 印前口径、社区项目做法（见 `research/standards-and-community.md`）。

- **中文禁则**：对 PDF 逐行文本检查——行尾不得是 `。，、；：）」』！？` 等收尾类，行首不得是 `「『（【` 等起首类；命中即报错并点名页与行。
- **版心与行长**：订口（内白边）**> 20 mm**（取 22 mm）；正文每行 **34–42 字**、行长 **≤ 150 mm**（许昌学院学报实测口径：>120 mm 阅读速度下降，16 开 143–147 mm 已属偏长）。
- **图文编号**：图/表在书内统一编号（`图 3-1`、`表 3-1`）且可被正文引用；编号与目录/索引一致。
- **索引**：术语 → 页码，统一序（码位序，见 design §7）。
- **勘误与贡献者页**：后置页含勘误入口（指向仓库 Issue）与贡献者名单。
- **出血口径**：无出血版 = 精确裁切尺寸；出血版按 **3.2 mm**（KDP 0.125 in），不是 3 mm。
- **东施效颦要避免**：**标点挤压/中西文自动间距不做**——Chromium 不实现 `text-spacing`/`text-autospace`，文档里写明"本轮做不到"，不用别的手段假装达标。

### R10 社区可参与（精品项目的必备面）

- 仓库侧已有 `CONTRIBUTING.md` / `CODE_OF_CONDUCT.md` / `SECURITY.md` / `CITATION.cff`（前一轮补齐）；
  本轮补：书内的**勘误入口**、**贡献者页**、以及 `docs/reference/book.md` 里"如何参与校对/翻译"的一段。

- `mcu-book/check_pdf.py` 改为印前契约门：开本尺寸、版心边距、**无 Type3 位图字形**（真字体嵌入）、目录页码与正文实际起始页抽检一致（≥10 章）、页码自洽（末页 N/N 且无 分子>分母）、页眉映射一致、结构页无页眉。
- 新增 `mcu-book/check_epub.py`：结构 + `epubcheck` 包装（本机无 Java 时 SKIP 并给安装提示）。
- CI：`book.yml` 与 `quality.yml` 产出/校验两件新产物；`local-gates` 增项；`tests/workflow.test.mjs` 同步；新增 Python 单测（排版样式关键断言、EPUB 结构、两条对账）。

## Non-goals

- 不改 88 章正文 markdown（站点与书仍同源同文）。
- 不做 ISBN/CIP 申请与发行渠道对接（版权页只出"自制版本页"，书号由平台另议）。
- 不做 CMYK 色彩管理与印厂专色（本轮出 RGB 印前 PDF；印厂若要求再单独立项）。
- 不重做站点页面结构与视频线；不动 `.trellis` 之外的其他在途任务。
- 不引入需要人工步骤的排版流程（一切由 `npm run book:*` 一键产出）。

## Acceptance Criteria

- [ ] **P2 全量印前排版**：88 章 + 6 附录全量产出，页数稳定、无溢出/截断（抽检 10 章正文未溢出页面边界）；字体子集覆盖所有用字（缺字即失败）。
- [ ] **P3 前置/后置页**：版权页、前言、**带页码的目录**、**索引**齐备；目录页码抽检 ≥10 章与实际起始页一致。
- [ ] **P4 页码页眉自洽**：末页 N/N；无 `分子 > 分母`；章首页/结构页无页眉；奇偶页眉规则正确。

### 全局

- [ ] **内容同一性**（R7）对 88 章逐章通过。

## Constraints

- 字体许可必须允许随书分发（本轮只用 SIL OFL 1.1 的 Noto/思源系列），并随附 OFL 文本与来源登记。
- 正文冻结：改动只允许落在 `mcu-book/**`（构建器、样式、字体、索引生成）与站点/规范文档，**不改 `docs/**` 正文**（唯一例外：若发现正文事实错误，按既有流程单独立项）。
- 仓库体积：字体子集 + EPUB 合计新增不入库体积过大者（子集目标 ≤ 8 MB/字体族，EPUB ≤ 15 MB）。
- CI 时长：新增构建步骤合计 ≤ 10 分钟（ubuntu-24.04）。
- 不引入 `noqa` 绕过新 lint 门；既有 `sys.path.insert` 模式按仓库既有 `importlib` 载入约定改写（`mcu-book/tests/test_build.py` 已示范）。

## Open Decisions（复核门收口）

1. **A4 版 PDF 是否退役**：默认退役（避免两条书路各自漂移），站点页面改为"PDF（印前/打印）+ EPUB（阅读器）"；若你要保留屏幕版 A4，请说明它的契约由谁负责。
2. **出血默认值**：默认关（精确裁切尺寸）；`--bleed 3` 供胶印。
3. **EPUB 是否内嵌字体**：默认不嵌（多数阅读器用系统字体，体积更小）；需要"字形一致"时可开 `--embed-fonts`。
4. **版权页口径**：自制版本页（书名/版本/日期/许可/来源/构建说明）；书号与出版方信息留待你决定发行渠道后再填。
