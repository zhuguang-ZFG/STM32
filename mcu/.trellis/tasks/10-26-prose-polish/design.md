# 设计：逐章精修流水线

## 1. 风格指南（试点章评审后冻结为正式版）

### 改什么

| 口癖 | 规则 | 试点实证 |
|---|---|---|
| `——` | 解释关系 → 「，」或「：」；补充说明 → 「（…）」；递进 → 拆两句。每章散文区 ≤ 2 处，只留真正有节奏价值的 | 52 → 3（剩 3 处全在受保护的表格/代码注释里，散文区清零） |
| 加粗短语后接 `——` | 「**XX**——说明」 → 「**XX**：说明」 | 常见坑 5 条全部归一 |
| 「一句话：」「记住：」 | 直接删前缀或换成不重复变体；`::: tip 一句话记住` 是全书容器标签，**不动**（见 §3 决定 2） | 试点章 1 处为容器标签，保留 |
| 「✅ 下一站」 | 保留章末块与 emoji 形式（全书惯例），块内措辞逐章新写 | 试点章改 `——` 为 `：` |

### 不改什么（作者声音）

- 直给短句（"会炸。"）、反问与第二人称、证据先行结构、工程口语（翻车/背锅/魔咒/课代表）。
- 反复出现的比喻系统（秒表/电表、骨架/心脏）是书的语言，不许替换。

### 不许碰（`prose_guard.py` 机器断言）

代码围栏块、行内代码、表格行（含表内 `——`）、标题行、frontmatter、链接/图片目标。表格与代码注释里的口癖本轮**不修**——技术内容零风险优先。

另有一层**散文事实 token 多重集合断言**（advisory 提出，已实装并负向验证）：剥离受保护区后，`0x…` 十六进制、`§x.y` 手册引用、`第 N 章/节` 交叉引用、带单位数字（含 格/档/步 等量词）、版本号小数、裸数兜底（≥2 位）的多重集合必须一致。改一个数字即被点名（负向样本 `27000→28000` 已验证捕获）。代理不得增删改任何数字事实，冗余提到也只能改写句式不能丢数。

标题行冻结的硬理由（锚点契约）：`build_html.py:499 cjk_slugify` 把标题文字 slug 成页内锚点，正文里有 `[常见坑](#常见坑)` 这类指向标题的引用（如 `docs/stm32/00-env.md:125`）；改标题措辞会打碎锚点，`:1128` 的 `broken internal fragments` 直接炸构建。链接文字可随散文润色，但 `#锚点` 目标与被指标题文字都不许动。

## 2. 流水线

```
每批（≤10 章）：
  for 每章:
    1. 精修代理读：prd.md + 风格指南 + 原文 → 产出完整改写文件到 .temp/polish/<path>
    2. prose_guard.py 原文 精修稿 → 不可动清单断言 + 口癖计数
    3. 违规 → 代理返工（附违规清单）
  批次报告：计数表 + 每章改动摘要（改了哪几处句式）
  用户抽评 ≥2 章 → 通过才落盘 docs/**，不通过整批返工
```

- 批次划分按 10 个分部 + 附录（~10 批），与书的结构对齐，评审时也按部分读。
- 落盘后重建书：`build_print.py` 全量 + `check_pdf.py` 11 门（页码漂移正常，目录/索引自动跟随）。
- 批次间并行上限 4 个代理；同批内章节互不依赖。

## 3. 试点带出的决定（待你确认）

1. **表格/代码注释里的口癖不修**（受保护区域）：试点章剩 3 处 `——` 全在这两处。若要修，需把表格从"字节不变"降级为"语义不变"人工核——风险与收益不成比例，建议不修。
2. **容器标签不动**：`::: tip 一句话记住`、`## 记忆锚点`、`## 短自测`、`## 你做到了` 等章节骨架是全书一致的阅读节奏，属版式而非口癖。
3. **阈值**：散文区 `——` 每章 ≤ 2、全书总量（含受保护区）预计 2002 → ≤ 700；「一句话/记住」正文出现各 ≤ 40。

## 4. 风险

- **节奏磨平**：批量代理容易把所有章改成同一种"干净但无味"的腔调。对策：风格指南明确"保留声音"清单；抽评重点看这个，不看干不干净。
- **交叉引用**：标题不动 + `第 N 节` 计数断言兜底；正文改写时「第三节会讲」类回指必须保留。
- **页数漂移**：散文变短 → 书变薄几页；11 门里密度/利用率门按现状阈值，若红点再单独立项调阈值（不许为凑绿弱化门）。
