# AI 辅助开发：把大模型当结对工程师

> 🎯 模型写代码很快，错得也快。这一部不教你用哪个 AI，教你怎么当 AI 产出的审计员：提示词给约束、输出对手册、工具化工作流、幻觉有防御，最后用这本书自身的生产线自证。

模型对「最常见写法」的拟合近乎完美，对「你这块板子的具体接法」一无所知：总线归属、位语义、共阳共阴，全是它可以一本正经编错的地方。这一部把你已有的一切变成审计工具——RM0090 是游标卡尺，板卡原理图是判决书，上板现象是终审法官。
