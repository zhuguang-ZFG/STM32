# C 语言精髓：嵌入式 C 是另一种 C

> 🎯 同样一个 `*p = 1`，在电脑上最多段错误，在单片机上可能是一盏灯亮、一个电机转、一块 Flash 被擦。C 篇的任务：让你写的每一行 C，都知道它在硬件上干了什么。
