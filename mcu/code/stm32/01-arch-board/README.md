# S01 位带操作演示（Bit-Band）

> 配套章节：[S1 F407 架构总览](../../docs/stm32/01-arch.md)

## 实验目标

用**位带别名地址**原子翻转 PF6 红灯，对比 BSRR 的原子操作机制。

## 硬件需求

- **板卡**：野火 STM32F407 霸天虎（或同引脚 F407ZGT6 开发板）
- **LED**：板载 RGB 红灯 PF6（低电平点亮）
- **调试器**：ST-Link V2 + OpenOCD

## 核心概念

**位带（Bit-Band）** 是 Cortex-M4 的特性，把外设/SRAM 的每一位映射到一个 32 位别名地址：

```
别名地址 = 0x42000000 + (字节偏移 << 5) + (位号 << 2)
```

对别名地址写 0/1 = 原子清零/置位目标位，不扰邻居。

**GPIOF_ODR bit6 的别名地址**：
- GPIOF_ODR 在 `0x40021414`
- 别名 = `0x42000000 + (0x14 << 5) + (6 << 2)` = **`0x42000298`**

## 构建与烧录

```bash
make            # 构建 build/bitband.elf + .bin + .hex
make flash      # 烧录到板子
make debug      # 启动 OpenOCD GDB 服务（另开终端）
make gdb        # 连接调试
```

## 预期现象

红灯以约 1Hz 频率闪烁（HSI 16MHz 下软件延时，不追求精确）。

## 对比 BSRR

| 方式 | 操作 | 原子性 | 适用场景 |
|---|---|---|---|
| BSRR | 写 1 到 bit N（低 16 位置位，高 16 位复位） | ✅ 原子 | GPIO 专用，最常用 |
| 位带 | 写别名地址 | ✅ 原子 | 通用外设，适合频繁单比特操作 |
| ODR 读-改-写 | `ODR |= (1<<N)` | ❌ 非原子 | 中断可能打断，不推荐 |
