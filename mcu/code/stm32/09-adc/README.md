# 09-adc —— S9 逐次逼近（SAR）取证

配套章节：[S9 ADC](../../../docs/stm32/09-adc.md)（动画 `sar-successive.svg` 里每个数字的出处）。
**不需要开发板，也不需要 make**，宿主机 gcc 一条命令跑完；交叉工具链只用来顺手证明这段算法在 Cortex-M4 上也编得出来。

```bash
sh probe.sh            # 全部：12 轮二分表 + 三个输入电压 + 采样时间表 + 交叉目标文件，结尾 `== 断言通过 5/5 ==`
sh probe.sh sar        # 只跑 2.00 V 那一轮（动画用的就是它）
sh probe.sh vin        # 1.65 / 2.00 / 3.29 V 三个输入各锁定一次
sh probe.sh ts         # 采样时间 vs 源阻抗：RC 推导算最少周期数并选 SMP 档
sh probe.sh clean      # 删掉 build/
```

## 证的是四件事

1. **12 次比较不是口号，是二分**：默认 VREF=3.30 V、Vin=2.00 V，LSB = 3.30/4096 = 0.806 mV = 805.7 µV。第一轮试探 bit11（trial 2048 → 1.6500 V，比 Vin 小，保留），第二轮 3072 → 2.4750 V（大了，清掉），第三轮 2560 → 2.0625 V（还是大了，清掉）……12 行表格逐行打印，候选每轮对半砍：4096 → 2048 → 1024 → … → 1，正好 `log2 4096 = 12`。
2. **锁定值与量化误差**：终码 2482 = 0x9B2 = `1001 1011 0010`，回算 1.9997 V，与真值差 0.3418 mV = **0.42 LSB**。这不是误差超标——逐次逼近按"≤ 就保留"向下取整，量化误差落在 [0, 1) LSB 区间（四舍五入式 ADC 才是 ±0.5 LSB）。1.65 V 那轮直接落 0x800、误差 0.00 LSB；3.29 V 落 0xFF3（离满量程 0xFFF 还差 12 个码），误差 0.59 LSB。每个二进制跑完都自检三条：终码 == floor(Vin/LSB)、量化误差 < 1 LSB、比较轮数 == 位数，失败即非零退出。
3. **采样时间 vs 源阻抗可复算**（`ts_probe.c`）：保持电容经 (R_s+R_ADC)·C_ADC 一阶充电，沉到半 LSB 要 t > (N+1)·ln2·τ ≈ 9.01·τ。在假设常数 R_ADC=2 kΩ、C_ADC=4 pF、f_ADC=21 MHz（PCLK2/4）下实测输出：1 kΩ→最少 2.3 周期（选 3 拍）、10 kΩ→9.1（选 15 拍）、50 kΩ→39.4（选 56 拍）、100 kΩ→77.2（选 84 拍）；而 100 kΩ 源若只给 3 拍，残差高达 2886 LSB——读数基本是垃圾。**R_ADC/C_ADC 是假设值，真实值以 datasheet 为准**；8 档采样时间 {3,15,28,56,84,112,144,480} 来自 ST 官方头文件。
4. **比较次数与位数的关系可复算**：`-DBITS`、`-DVIN`、`-DVREF` 都能换。换 8 位再看，就是 8 轮、表只有 8 行——"分辨率每加一位，候选少一半"这件事在输出里看得见。

## 口径与边界

这是**理想 ADC 的算法仿真**：比较器不飘、DAC 无噪声、`C_H` 充满（ts 模式则反过来，专算"没充满"的账）。
它只回答"码值是谁算出来的""为什么 12 位只要 12 次比较""采样时间为什么要按源阻抗选档"。

真实板上的读数还要被 VDDA 波动、噪声、布局拉走——也就是动画第 ⑤ 阶段那条"没充满就转"的红色曲线。
**那些数字必须接板实测，本仿真不代替**；`sh probe.sh cross` 只产出 `.o`，不烧板。
