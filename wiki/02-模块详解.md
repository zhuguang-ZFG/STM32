## 2.1 教学站点 `docs/` + `docs/.vitepress/`

### 2.1.1 内容层 `docs/`

```
docs/
├── index.md            首页：学习地图 + 按身份分流（数据来自 data/progress.json）
├── guide/              导读：怎么学 / 实物装备 / 手册地图
├── c/ build/ stm32/ rtos/ esp32/ gd32/ ai/   七大板块章节（frontmatter 驱动统计）
├── lab/                实物实验中心（template.md + E01–E08）
├── projects/           双板综合项目（J1 F407 / J2 S3 记录器）
├── reference/          术语速查 / FAQ / 更新日志 / 关于
├── video/              视频索引页
├── public/anim/        110 张 SMIL 机制动画（构建期内联进页面）
└── curriculum.json     课程目录（先修关系事实源，由 curriculum.mjs 校验）
```

章节通过 YAML frontmatter 声明元数据（`status` / `difficulty` / `minutes` 等），是所有统计数字的事实源。

### 2.1.2 站点配置 `docs/.vitepress/config.mts`

核心定制（关键行号）：

- **L46-L83 站点元信息**：`base=/mcu/`、标题、OG/Twitter 卡片、sitemap、`transformHead` 每页 canonical 与分享卡；
- **L62-L66 水合看门人**：注入 inline script，在 `DOMContentLoaded` 时暂停视口外 SMIL 动画，避免水合排队等帧；
- **L85-L138 markdown-it 管线**：
  - `anim-figure-block` 规则：把独占一行的 `![图注](/anim/x.svg)` 从 `<p>` 中取出，替换为 `<AnimFigure>`（SVG 原文转义后走 `v-html`，避免 hydration 抖动）；
  - `chapter-art` 规则：在 H1 后插入章首题花（资产与印前 `build_html.py` 同源，含滤镜的 SVG 硬门拒绝）；
- **L140-L152 本地搜索**：miniSearch + 自定义中文分词 `tokenizeForSearch`（默认分词把整段中文当 1 个 token）与自定义渲染 `renderSearch`；
- **L153+ 导航/侧边栏**：按板块组织章节目录。

### 2.1.3 构建辅助模块

| 文件 | 职责 |
|---|---|
| `anim-decorate.mjs` | 读取 `public/anim/*.svg`，加主题 CSS class、命名空间 id，计算动画时长（`readAnim/decorateAnim/animDuration`） |
| `code-languages.mjs` | 自定义语法高亮：linker script、GDB、ARM 汇编 |
| `data/progress.json` / `updates.json` | 由 `gen-progress.mjs` 生成：全站进度与最近更新（构建产物，勿手改） |
| `data/quizzes/` `data/registers/` | 测验题库与寄存器数据 |

### 2.1.4 自定义主题 `docs/.vitepress/theme/`

`index.ts` 注册全局组件，`Layout.vue` 扩展默认布局。19 个 Vue 组件分四类：

- **首页**：`McuHero/McuFeatures/McuCta/McuFooter/McuUpdates/LearningMap/PathFinder`
- **章节增强**：`AnimFigure`（动画图注+播放控件+深浅主题）、`ChapterCompass`（章首罗盘）、`LabStatus`（实验上板状态）、`QuizBank`（测验）、`AiNotice`、`VideoEmbed`
- **交互工具**：`BaudCalc`（波特率计算）、`ClockCalc`（时钟树计算）、`RegisterExplorer`（寄存器浏览）
- **样式**：`custom.css`

## 2.2 示例工程 `code/`

47 个与章节同构的示例工程，全部逐行注释：

```
code/
├── projects.json   工程登记表（事实源，见 03 节数据契约）
├── common/         跨工程共享代码
├── c/              宿主机取证工程（内存模型/指针/volatile/ABI…，probe.sh 一条命令跑完）
├── toolchain/      无板取证工程（如 02-elf 解剖）
├── stm32/          F407 寄存器版工程（00-blink 起；01-arch、09-adc 各带 probe.sh）
├── esp32/          ESP-IDF 工程（target 固定 esp32s3）
├── rtos/           FreeRTOS / RT-Thread 工程
└── gd32/           GD32F4xx（ARM）与 GD32VF103（RISC-V）工程
```

工程分四类（`kind`）：`arm-make`（ARM GCC + Makefile）、`esp-idf`（CMakeLists.txt）、`host-probe`（probe.sh 取证脚本）、`host-make`（宿主 GCC + Makefile）。登记表由 `scripts/project-catalog.mjs` 校验：**含构建入口但未登记的工程会被发现并报错**。

## 2.3 质量闸门 `scripts/`

按用途分五组（`npm run quality` 串起其中大部分）：

**生成类**
- `gen-progress.mjs` — 扫描章节 frontmatter → `progress.json`/`updates.json`；`--readme` 同步 README 进度块；`--check` 校验漂移
- `gen-og-cover.py` — 生成站点 OG 分享图

**内容检查类**
- `anim-lint.mjs` — SMIL 动画规范闸门（标签闭合、viewBox、title/desc、色板映射、dur 整除、指示点出界）
- `anim-audit.mjs` + `anim-audit.html` + `anim-shot.html` — 动画版式批量审计（出界/压字）
- `links-check.mjs` — 根 README/CONTRIBUTING 相对链接检查
- `docs-check.mjs` / `nav-check.mjs` / `seo-check.mjs` / `a11y-check.mjs` — 文档规范 / 导航一致性 / SEO / 无障碍
- `pages-check.mjs` / `search-check.mjs` — 对构建产物做对账（deploy 前必过）
- `reading-time.mjs` — 阅读时长统计校验
- `content-metadata.mjs`（库）— 章节/实验 frontmatter 校验（`readMetadata/readLabMetadata`）
- `curriculum.mjs`（库）— 课程目录与先修关系校验（`loadCurriculum/validateCurriculum`）

**工程/固件类**
- `project-catalog.mjs` — `code/projects.json` 校验与未登记工程发现；`--matrix` 输出 CI 构建矩阵
- `check-firmware.mjs` — 编译固件工程并断言 ELF/符号表/复位向量/初始栈指针/场景切换回归
- `arm-env.sh` / `local-gates.ps1` / `local-gates.sh` — 工具链环境与本地闸门封装
- `device-console.py` — 串口设备控制台（上板实测辅助）

**站点测量类**
- `perf-budget.mjs` — 性能预算；`measure-site.mjs` — 原始/压缩体积与搜索按需加载记录

**搜索管线（被站点配置复用）**
- `search-render.mjs` / `search-tokenize.mjs` — 自定义搜索渲染与中文分词（config.mts 与 search-check 两端共用）

**维护工具**
- `anim-metadata-codemod.mjs` — 动画元数据批量迁移

## 2.4 视频产线 `video/`

### 2.4.1 目录

```
video/
├── series.json        系列级配置
├── episodes/<id>/     分集 spec（episode.json + 平台文案），15+ 集
├── research/          事实底稿：<id>-factsheet.md 与 <id>-numbers.json（上屏数字事实源）
├── jobs/              发布任务（如 ai4fw、ai4fw-16x9）
├── assets/            素材；audio/ 见 src/audio
├── src/               产线代码（六阶段）
├── publish/           四平台投稿脚本（B站/抖音/知乎/小红书，daemon/queue/verify）
├── tests/             node:test 单测（layout/timeline/spec/stage/mux/numbers/tts…）
└── out/               产物（.gitignore）：video/out/<id>/<platform>/ 成片+封面+发布包
```

### 2.4.2 六阶段产线（`video/src/`）

`cli.mjs` 是唯一入口，阶段顺序固定：**lint → tts → timeline → stage → render → mux → package**。每阶段产物落在 `video/out/<id>/<platform>/`，改旁白只重合成改动句、改画面只重渲染该集。

| 模块 | 职责 |
|---|---|
| `cli.mjs` | CLI 入口与子命令分发：lint / check / build / pack / numbers / calib / cover |
| `spec.mjs` | episode.json 解析与校验；`resolveScenes` 支持平台化重排（`reuseFrom/pick/narration/set`），B站/抖音复用同一集素材 |
| `tts.mjs` | 旁白 TTS 合成，按句缓存（改动句才重合成） |
| `timeline.mjs` | 时间轴 → 渲染计划：场景一致性校验、合并 SMIL 时长/帧起点/播放模式、v2 节拍与审计 |
| `stage.mjs` | puppeteer 舞台：打开浏览器、seek 自测（`openBrowser/openStage/seekSelfTest`） |
| `layout.mjs` | 版式布局（v1/v2 两版，有对应单测） |
| `render.mjs` | 逐帧渲染：静止帧按 `stateKey` 去重减少截图，PNG 流式写 ffmpeg 出 mp4；`captureStills` 出剧照 |
| `mux.mjs` | 音视频合成：旁白/BGM/SFX 混音，copy 视频流 + aac 音频，断言成片时长与音轨参数 |
| `audio/sfx.mjs` + `audio/assemble.py` | 音效事件构建与渲染 |
| `package.mjs` | 封面 HTML 截图（与正片共用字体/配色；竖版/横版布局、标题断行、数字牌、证据卡）+ 发布包重排（`packJobs/writeRelease`） |
| `numbers.mjs` | 上屏数字与 `research/<id>-numbers.json` 对账（`auditNumbers`） |
| `calib.mjs` | seek 门限双向标定（改 stage.mjs 常量后必跑） |
| `util.mjs` | 共享常量与工具：`EPISODES_DIR/OUT_DIR/FFMPEG/VIDEO_ROOT`、`ensureDir/fmtClock/log` |

### 2.4.3 发布 `video/publish/`

四平台脚本族（Playwright 驱动网页投稿，非官方 API）：

## 2.5 整书离线版 `mcu-book/`

```
mcu-book/
├── manifest.json          整书事实源：11 分部 / 94 章罗盘 / 75 项来源注册表
├── build_html.py          单文件 HTML 构建器（--check 契约校验模式）
├── build_print.py         A4 PDF 构建（Playwright/Chromium + paged.js 分页）
├── check_pdf.py           PDF 产物校验（书签/页码）
├── subset_fonts.py        字体子集化
├── publish_downloads.py   打包发布下载产物
├── book/                  附录、章首题花资产（assets/chapter-art 与站点同源）
├── print/                 印前样式
├── tools/                 辅助工具
└── tests/                 pytest 契约测试
```

**构建流程**：manifest 加载校验（`load_manifest/validate_manifest`）→ 章节 md 解析（frontmatter + 站点方言转换：`<QuizBank>/<AnimFigure>/<LabStatus>/视频/Mermaid` → 静态 HTML 或报错）→ 链接/图片/锚点重写（图片内嵌为 data URI、统一 ID 前缀）→ 组装版权/前言/目录/分部隔页 → 构建后审计（章节顺序、罗盘数量、内部 fragment、组件残留、测验答案附录）。`--check` 模式在临时目录验证整书契约（94 章/罗盘/测验/附录/死链零容忍）。

### 2.6.2 浏览器测试 `tests/browser/`

Playwright（`playwright.config.mjs`：CI 可重试，`docs:preview` 起服务）：校验动画总览页列出所有 SVG、本地搜索索引按需加载并返回结果、SMIL 暂停/播放、reduced motion、深色模式、页面错误日志。

### 2.6.3 CI 工作流 `.github/workflows/`

| 工作流 | 触发 | 内容 |
|---|---|---|
| `quality.yml` | PR / 手动 / 被调用 | `npm ci` → `npm run quality` → `anim:audit` → `project-catalog --matrix` → `firmware:check` → ESP32-S3 矩阵构建（IDF 5.5.2） |
| `deploy.yml` | quality 通过后 | 部署前对 artifact 跑 `pages-check` + `search-check` 对账 → 发布 Pages |
| `book.yml` | 整书发布 | `book:html` + `book:pdf` 构建并发布 |
| `links.yml` | 定期 | 外链死链扫描（lychee，`.lychee.toml`） |

发布纪律：**必须先通过同一提交的全部质量检查**。
