# 05 · 运行与开发指南

## 5.1 环境准备

```bash
# 基础（站点 + 全部脚本闸门）
npm install

# 整书构建
pip install -r mcu-book/requirements.txt

# 浏览器测试 / PDF / 视频产线
npx playwright install chromium

# 固件验收（可选，按需）
#   arm-none-eabi-gcc、宿主 GCC、make/sh、FreeRTOS V11.1.0 源码、ESP-IDF 5.5.2
```

## 5.2 npm scripts 全表（统一入口）

### 站点

| 命令 | 作用 |
|---|---|
| `npm run docs:dev` | 开发预览 http://localhost:5173（自动先跑 `docs:gen`） |
| `npm run docs:build` | **验收门禁**：死链检查开启，必须零错误 |
| `npm run docs:preview` | 预览构建产物 |
| `npm run docs:gen` | 只跑统计：成稿/实验/动画/工程数 + 元数据缺项告警 |
| `npm run readme:sync` / `readme:check` | 把扫描结果写回 README 进度块 / 数字漂移检查（CI） |

### 质量闸门

| 命令 | 作用 |
|---|---|
| `npm run quality` | **完整闸门**：单测 + 工程清单 + 站点构建 + 动画 + 数字 + 阅读时长 + 链接 + 文档/导航/SEO/性能/无障碍/页面/搜索 |
| `npm test` | node:test 单元回归（`tests/*.test.mjs`） |
| `npm run anim:lint` | 动画规范闸门（SMIL 槽位、色板、dur 整除、指示点出界） |
| `npm run anim:audit` | 动画版式批量审计 |
| `npm run links:check` | 根 README/CONTRIBUTING 相对链接 |
| `npm run docs:check` / `nav:check` / `seo:check` / `a11y:check` | 文档规范 / 导航 / SEO / 无障碍 |
| `npm run pages:check` / `search:check` | 构建产物对账（deploy 前必过） |
| `npm run reading:check` | 阅读时长校验 |
| `npm run projects:check` | `code/projects.json` 登记完整性 |
| `npm run perf:budget` | 性能预算 |
| `npm run site:measure` | 体积与搜索按需加载记录 |
| `npm run firmware:check` | 固件编译与 ELF 断言（需 ARM GCC 等工具链） |
| `npm run test:browser` | Playwright 浏览器测试（需先 `docs:build`） |

### 整书离线版

| 命令 | 作用 |
|---|---|
| `npm run book:check` | 临时目录验证整书契约（94 章/罗盘/测验/附录/死链零容忍） |
| `npm run book:html` | 产出 `mcu-book/dist/mcu-deep-book.html`（单文件，动画内嵌即播） |
| `npm run book:pdf` | 追加 A4 PDF（需本机 Chrome/Edge） |
| `npm run book:pdfcheck` | PDF 书签/页码校验 |
| `npm run book:pack` | 打包下载产物到 `.temp/book-downloads` |

### 视频产线

| 命令 | 作用 |
|---|---|
| `npm run video:lint -- [id…]` | 分集 spec 与平台文案校验 |
| `npm run video:test` | 产线单测（`video/tests/`） |
| `npm run video:check -- [id…] [--platform …]` | 只跑舞台+排版审计，不渲帧、不配音 |
| `npm run video:build -- [id…] [--platform bilibili\|douyin\|both] [--force-audio] [--stills] [--no-bgm] [--variant vs\|panel]` | 完整构建成片 |
| `npm run video:pack -- [id…]` | 按发布平台复用母版重排发布包 |
| `npm run video:numbers -- [id…]` | 上屏数字与 research 底稿对账 |
| `npm run video:calib` | seek 门限双向标定（改过 `stage.mjs` 常量后必跑） |
| `npm run video:cover` | 封面生成 |

产物在 `video/out/<id>/<platform>/`（gitignore）。投稿脚本在 `video/publish/`，判据见 `.trellis/spec/video/`。

## 5.3 典型工作流

**改章节/动画**：
```bash
npm run docs:gen && npm run docs:dev     # 预览
npm run anim:lint                        # 改了动画就跑
npm run docs:build                       # 提交前验收
```

**写新章节**（照 `.trellis/spec/docs-site/structure.md`）：补 frontmatter → `docs:gen` 校验元数据 → `readme:sync` 同步进度块。

**新增示例工程**：建工程 → 在 `code/projects.json` 登记 → `projects:check` 通过 → 视 kind 跑 `firmware:check` 或 CI 矩阵。

**整书发版**：`book:check` → `book:html` → `book:pdf` → `book:pdfcheck`（CI 由 `book.yml` 执行）。

**完整本地验收**：
```bash
npm run quality
npm run firmware:check        # 需工具链
npx playwright install chromium && npm run test:browser
```

## 5.4 CI 流程

1. **PR**：`quality.yml` 全量检查（含固件与 ESP32-S3 矩阵构建）；
2. **合并发布**：`deploy.yml` 在 quality 全绿后，对 artifact 再跑 `pages-check` + `search-check`，发布到 GitHub Pages；
3. **整书**：`book.yml` 构建 HTML/PDF 并发布到 `/mcu/book/`；
4. **外链**：`links.yml` 定期 lychee 扫描。

## 5.5 Trellis 开发协作（AI 会话）

- 任务生命周期：`python3 .trellis/scripts/task.py create/start/finish/archive`（创建前需用户同意）；
- 规范加载：`python3 .trellis/scripts/get_context.py --mode packages` 查四层规范（docs-site / firmware-stm32 / firmware-esp32 / video）；
- 全局纪律：内容质量最高法是根目录 `CONTRIBUTING.md`；`docs/` 禁占位（`TODO/待补充/placeholder` 零命中）；事实必须有出处。

## 5.6 常见问题速查

- **没有开发板能做什么**：B2 ELF 解剖 / C1 内存模型 / C3 volatile 等章节用 `code/toolchain/`、`code/c/` 的 `probe.sh` 即可复跑；S0 环境搭建编出 `blink.bin` 也无板可做。
- **页面数字不可信？** 全部由 `docs:gen` 扫描产出；正文测量数据可复跑，未实测标「待上板实测」。
- **动画本地单看**：浏览器直接打开 `docs/public/anim/xxx.svg`；批量版式审计用 `scripts/anim-audit.html`。
- **完整 FAQ**：[docs/reference/faq.md](../docs/reference/faq.md)。
