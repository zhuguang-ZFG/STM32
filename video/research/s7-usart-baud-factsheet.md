## 二、量化：一格有多大

- 16MHz 下 BRR 139→140，波特率 115107.9→114285.7：一格 822.2 baud，占目标 0.714%；四舍五入最大误差 = 半格 0.357%。
- 穷举 1..65535 与固件 `+baud/2` 四舍五入对比 9 组场景（1M/8M/16M/42M/84M/168M × 115200 及 16M × 9600/460800/921600），穷举最优 = 四舍五入 = 9/9。
- 1MHz 想要 460800：BRR=2 → 500000.0（+8.507%）；想要 921600：BRR=1 → 1000000.0（+8.507%）。

## 三、OVER8 与帧预算

- 同一颗 16MHz、同一 BRR=139：16 倍过采样 115107.9，8 倍过采样 230215.8（正好翻倍）。
- 921600@16MHz：OVER8=0 只能 BRR=17 → 941176.5（+2.124%）；OVER8=1 等价把时钟当 32MHz → BRR=35 → 457142.9（-50.397%）。
- 帧预算倒推（最后中点在帧尾半位）：
  - 8N1：10 位帧 / 8.5 位 → 合计 5.882%，每端 2.941%；
  - 8E1：11 位帧 / 9.5 位 → 5.263%，每端 2.632%；
  - 8E2：12 位帧 / 10.5 位 → 4.762%，每端 2.381%；
  - 9N1：11 位帧 / 9.5 位 → 5.263%，每端 2.632%。
- 扣掉量化后的每端余量：16M/115200 2.901%；84M/115200 2.930%；8M/115200 2.619%；1M/115200 只剩 1.166%；16M/921600 剩 1.879%；32M/921600（OVER8=1 等效）2.544%。HSI 本身 ±1%。

## 四、时钟树回读（clocks_read）

- ① 复位默认 CFGR=0：HCLK=PCLK2=16000000 → BRR=139 → -0.080%。
- ② PLL（HSE 8M，M=8 N=336 P=2）：SYSCLK 168MHz → APB2 /2 → PCLK2 84MHz → BRR=729 → +0.023%。
- ③ HPRE=1101 = /128（F4 没有 /32）：HCLK=PCLK2=1312500 → BRR=11 → 119318.2（+3.575%）。
- ④ HPRE=1111 = /512：PCLK2=31250 → BRR=0（非法）；PCLK2=57600（半个波特率）→ BRR=1；57599 → BRR=0。
- ⑤ 只配 PLLCFGR、没切 SWS：回读 PCLK2=16MHz、固件算 139；若照 84MHz 写死 729 → 21947.9（-80.9%）。
- ⑥ 宏按 8MHz 配、板上晶振 25MHz：真 PCLK2=262500000 → BRR=729 打出 360082.3（+212.6%）。

## 五、写入动作（假寄存器取证）

- 点灯：AHB1ENR 置 GPIOF bit5 = 0x20；GPIOF_MODER = 0x00011000（PF6/PF8 输出）；点 = BSRR 0x00400000（复位半区 bit22），灭 = 0x40（置位半区 bit6）。
- 引脚：AHB1ENR=0x1（GPIOA）、APB2ENR=0x10（USART1）、MODER=0x00280000（PA9/PA10 复用）、AFRH=0x00000770（AF7）。
- usart1_init(16MHz)：BRR=139、g_brr=139、CR1=0x201C（UE|TE|RE|IDLEIE = 8220；RXNEIE 未开）、CR2/CR3 清零。
- DMA2_Stream5_RX：PAR=0x40011004（USART1->DR）、NDTR=64、FCR=0（直接模式）、CR=0x0800051D（CHSEL=4|CIRC|MINC|HTIE|TCIE|TEIE|EN）、CR3=0x40（DMAR bit6）。

## 六、收发与两级缓冲

- 发 16 字节：DR 正好被写 16 次、末笔 0x0A；0xFF 写入不扩展 = 255（`(uint32_t)(uint8_t)*s` 防的是有符号 char 写成 0xFFFFFFFF）。
- 半传：pos=40 → 取 40 字节，g_rx_bytes=40，g_half_events=1，整传计数未动；清标志写 HIFCR（非只读 HISR）。
- 整传：pos=0 → 跨边界补 24 字节 → 共 64，g_full_events=1，游标回 0。
- TEIF5 错误：整段丢弃 64 字节，g_overruns=1，游标 lost=1。
- IDLE|ORE：先读 SR 再读 DR 握手 1 次；收到 `AT\r\n!` 五字节后空闲 → g_frames=1（名字是 IDLE 通知数，不是协议帧数）；ORE 让 g_overruns+1。

## 七、地址与反汇编

- 25 个地址与 CMSIS 对账全中：USART1_SR 0x40011000 / DR +0x04 / BRR +0x08 / CR1 +0x0C / CR2 +0x10 / CR3 +0x14；GPIOA_MODER 0x40020000 / AFRH +0x24；GPIOF_MODER 0x40021400 / BSRR +0x18；RCC_PLLCFGR 0x40023804 / CFGR +0x08 / AHB1ENR +0x30 / APB2ENR +0x44；DMA2_LISR 0x40026400 / HISR 0x40026404 / HIFCR 0x4002640C / S5_CR 0x40026488 …。
- 位号 33 条与头文件逐位一致（diff 为空）。
- 段大小：-O0 text 1964 B vs -O2 1121 B（同一份源码）。
- `/115200` 编成乘法：`10c add.w r3,r3,#57600`（+baud/2 的立即数 0xe100）；`110 umull` × `0x91a2b3c5`；`114 lsrs #16` 得商；一条 udiv 都没花。HPRE/PPRE2 的分频是运行时查表 → 保留真 `udiv`。
- 时钟回读：RCC_CFGR 编成 [r1,#2056]；SWS [3:2] 先 and 再 cmp；HPRE [7:4]；PPRE2 [15:13]；分频系数查半字表。
- CR1：`movw` 一条写 0x201C 到 +0x0C；IP[37]、IP[68] 各一个字节；ISER1 bit5、ISER2 bit4。
- TXE/TC 自旋：先读 SR(+0x00)；TXE=bit7 左移 24 位、TC=bit6 左移 25 位搬到符号位；`bpl` 自旋；每字节一次 `str` 进 DR(+0x04)。
- DMA：PAR 编成 [r2,#1168]（0x490）；NDTR=64；初值池里躺 0x40026000（DMA1 基址，编译器把 DMA2+0x88 重新锚基址、立即数补回）；中断里 TEIF5|HTIF5|TCIF5 = bit9..11 → 0xe00，写 HIFCR（0x40026000+0x40c）。
- -O0 vs -O2：-O0 时 usart1_init 是独立函数、BRR 先落栈槽 [r7,#12] 再读回；-O2 整个函数被搬进 main，BRR 全程待在寄存器。

## 八、本篇 FM 与 v1 修正

- docs/stm32/07-usart.md:77：139 = 0x8B → DIV_Mantissa 8、DIV_Fraction 11 → USARTDIV 8.6875（RM0090 位域口径）。
- v1 旁白「合计五点八八九」与标题「五八一二」均与 0.5/8.5 = 5.882% 矛盾 → v2 统一改「五点八八二 / 五八八二」。
- v1 拼写 PLLCFR → PLLCFGR；TTS 将 0x8B 读作「零 x 八 B」、0xFF 读作「零 x 两个 F」。
