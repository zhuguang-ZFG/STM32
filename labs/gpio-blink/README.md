# 点灯：从 GPIO 配置到十周期记录

状态：`hardware_status: pending`。2026-11-18 只核对源码与文档，未构建、未烧录、未实测。目标是验证一只脚的真实电平，不凭肉眼判定精确频率。

## 工程、身份与先修

先读 [ch00](../../docs/onramp/00-from-box-to-blink.md) 和 [共同安全/记录](../README.md)，机制看 [ch08](../../docs/v1-drivers/08-architecture-memory-clock.md)、[ch09 E01](../../docs/v1-drivers/09-gpio.md)；构建不熟回 [ch05](../../docs/v0-foundations/05-toolchain-four-steps.md)。

主样板为 [mcu/code/stm32/00-blink](../../mcu/code/stm32/00-blink/README.md)：main.c 声明霸天虎 RGB 共阳灯，**PF6 低亮、高灭**；启动文件目标 STM32F407ZGT6，链接 Flash 1MB / SRAM128KB。实际板型/芯片/LED 网络与容量待核实，不按工程名猜已连接板卡。

代码开启 GPIOF 时钟，配置 MODER6=01、OTYPER6=0、OSPEEDR6=00、PUPDR6=00，再交替写 BSRR BR6/BS6。无PLL配置、无SysTick计时；冷复位 HSI 名义16MHz，须回读RCC确认，不能套F103的72MHz或别的F407工程的168MHz。

## 接线、构建与烧录（后续执行）

1. 断电核对实际原理图 PF6 LED 和板载限流，板载灯不必另接 LED。别的板 PF6 可能无灯；不得短接引脚到电源试灯。按共同清单核对单一供电与 SWD PA13/PA14/GND/参考电压。
2. 测量探头尖端接PF6、地接板GND，避免碰邻针。完成安全与后续写板授权后，才执行现有Makefile步骤；**本轮没有执行**：

   ```powershell
   Set-Location mcu/code/stm32/00-blink
   make
   make flash
   ```

   从仓库根进入，产物 `build/blink.elf/.bin/.hex/.map`。环境、日志、哈希、verify/冷复位及 debug/gdb 会写板的边界见共同说明。构建失败不继续烧录。

## 预期与理论（不是实测）

循环为「PF6拉低→delay(2000000)→拉高→同样延时」，两次翻转才是一个周期。参数是软件计数，不是毫秒。源码「约0.5s、实测校准」未附原始校准证据，不能据此承诺精确1Hz。

若反汇编求得每轮有效周期数C，且时钟为16MHz，粗模型为 `T≈2×2000000×C/16000000 秒+循环外开销`；C尚未核定。优化级别、取指和时钟误差均影响结果。预期只是重复的高低翻转、低亮高灭，同延时使占空比近似对称，没有已验证精确数值。

## 测量、判据与故障定位

1. 先写押注，记录源码SHA/编译选项、冷复位后的RCC与GPIOF模式/使能回读，不改代码迎合预期。
2. 秒表从某同极性边沿数到第11个同极性边沿，即**10个完整周期**，保存原始起止与t10，计算 `Tavg=t10/10`、`f=10/t10`。秒表只判数量级，不是精密时序证据。
3. 示波器/逻辑分析仪另存至少10周期原始波形、倍率/采样率/时基/触发；对照PF6低电平时灯是否亮。只记屏幕频率不够。
4. **功能通过**：构建与verify日志完整、冷复位后连续10周期且低亮高灭与模式一致、无卡死。**记录通过**：十周期原始数据、单位、算法和误差来源可复算；本工程不设伪造的1Hz合格线。需要精准节拍应另选ch11/ch12时基方案。
5. 不启动/不翻转/固件与源码不对应为失败；只有肉眼现象不能判电平或计时精度通过。缺板/仪器则待测，目前所有硬件项均待测。

| 失败信号 | 区分证据 | 下一动作 |
| --- | --- | --- |
| 不亮但PF6翻转 | 板型、极性、LED限流网络和供电 | 查原理图，不盲目加大电流 |
| PF6不变 | PC是否进main、RCC_AHB1ENR bit5、MODER6 | 分启动失败与GPIO配置失败，回ch06/ch09 |
| 闪烁快慢与注释不符 | RCC、反汇编/优化选项、t10 | 忙等不是准确时基，先登记再判原因 |
| 烧录失败 | SWD针序、参考电压、verify日志 | 停止重试，先排供电/连线，不全片擦除碰运气 |

## 独立练习与证据缺口

不改程序预测BR6/BS6与亮灭关系，用十周期原始数据复算频率，并解释为什么delay参数不是毫秒。换灯/改延时属于以后另行确认的代码实验，本轮不实施。

共同表另填：`t10/Tavg/f=待测`、`高低电平时长=待测`、`PF6/灯对应=待测`、`照片/原始采样/日志哈希=待采集`。身份、构建、verify、冷复位、时序和复测均缺硬件证据，不能宣布已可硬件复现。
