**旁白（与字幕、配音同一份稿）**

1. 板子上的丝印会简写，也会印错。引脚以原理图和数据手册为准。上电之前，先在原理图上找到 3.3 伏、地和调试口，不要凭丝印把 5 伏送进 3.3 伏脚。
2. 最小系统不是一块华丽的板子。电源、去耦、复位、时钟、调试口，这几样在，芯片就能活。板子不工作的时候，先量这几样，再怀疑你的程序。
3. BOOT0 拉低，上电进主闪存，跑你的程序。拉高，进系统存储器，方便救砖。悬空时，它可能今天进程序、明天进系统存储器。原理图里这只脚不该飘着。
4. 这一帧是仓库画的 BluePill 引脚图，不是实物照片。板载灯在 PC13，低电平亮。PA13 和 PA14 留给 SWD。对照原理图时，先找这三只，再找你要接的外设。
5. 封装上每一对电源和地都要接上，不能因为「好像内部连着」就空着。去耦电容靠近电源脚。模拟部分的电源脚空着，ADC 会变成噪声发生器。
6. USB 口过来的常常是 5 伏，经过板上的稳压才变成 3.3 伏。模块如果是 5 伏逻辑，进芯片前要想电平。别把稳压器的输入和输出看反，那是最快的毁板方式。
7. 焊接或买板之后，读芯片表面的型号，对上数据手册里的订购信息。同系列不同容量，闪存页的大小和有没有某些外设会变。程序能编译，不代表这颗料有那个外设。
8. 口诀：BOOT0 不要悬空；每一对电源脚都要落地。丝印只是提示，原理图加上数据手册才是依据。
9. 拿你手里的板子，在原理图上圈出复位、调试口、晶振和板载灯。圈不出来，先别加模块。圈得出来，后面的接线才有参照。
10. 合上书，三问。BOOT0 悬空时上电可能进哪里？BluePill 板载灯怎样才会亮？丝印和数据手册冲突时听谁的？

## 🛠️ 硬件与接线

### 如何看懂一张最小系统原理图

最小系统 = 「**主控 + 电源 + 晶振 + 复位 + BOOT + 去耦**」六件套。下面逐项说明。

| 要素 | 器件 | 作用 | 排查要点 |
| --- | --- | --- | --- |
| 主控 | MCU | 核心 | 核对型号/封装与引脚定义 |
| 电源 | LDO + 电容 | 5 V→3.3 V | 测 3.3 V 是否稳定；VDDA 单独滤波 |
| 去耦电容 | 100 nF ×N（每个 VDD 一个）+ 10 µF | 滤高频噪声 | 缺去耦会随机复位/ADC 跳动 |
| 主晶振 | HSE 8 MHz + 2×20 pF | 提供高精度时钟 | 不起振→退回 HSI，波特率错 |
| RTC 晶振 | LSE 32.768 kHz + 2×6 pF | RTC/低功耗 | 电容过大不起振 |
| 复位 | NRST + 10 kΩ 上拉 + 100 nF 到地 + 按键 | 上电/手动复位 | NRST 悬空易误复位 |
| BOOT | BOOT0（10 kΩ 下拉）、BOOT1 | 选择启动模式 | BOOT0=0 从 Flash 启动 |
| SWD | PA13/PA14 + GND + 3V3 | 下载调试 | 保留，勿复用 |
| VBAT | 纽扣电池 | 维持 RTC/备份域 | 不接则断电时间丢失 |

**启动模式（BOOT0/BOOT1）**：

| BOOT0 | BOOT1 | 启动区域 | 用途 |
| --- | --- | --- | --- |
| 0 | x | 主 Flash | 正常运行（默认） |
| 1 | 0 | 系统存储器 | 串口/USB ISP 下载 |
| 1 | 1 | 内嵌 SRAM | 调试/救砖 |

**去耦电容的读图方法**：在原理图上找每个 `VDD`/`VDDA` 引脚，附近应各有一个 100 nF 电容到地，整板再有一个 10 µF 储能电容。**ADC 的 VDDA/VSSA 必须单独滤波**，否则采样噪声大。


## 💻 代码实现

板子认清了，还可以**用代码读出芯片身份**来验证型号、Flash 容量与唯一 ID——这也是识别山寨/缩水板的好方法（F1 系列）。

```c
#include "stm32f1xx_hal.h"
#include <stdio.h>

/* F1 的身份寄存器地址（见 RM0008 第 30 章 Device electronic signature） */
#define DBGMCU_IDCODE_ADDR   0xE0042000UL   /* 设备 ID */
#define FLASH_SIZE_ADDR      0x1FFFF7E0UL   /* Flash 容量（单位 KB，低 16 位） */
#define UNIQUE_ID_ADDR       0x1FFFF7E8UL   /* 96 位唯一 ID */

void Chip_PrintIdentity(void)
{
    uint32_t dev_id  = *(volatile uint32_t *)DBGMCU_IDCODE_ADDR;
    uint16_t dev     = (uint16_t)(dev_id & 0x0FFF);        /* 器件 ID */
    uint16_t rev     = (uint16_t)((dev_id >> 16) & 0xFFFF); /* 版本号 */
    uint16_t flash   = *(volatile uint16_t *)FLASH_SIZE_ADDR;

    uint32_t *uid = (uint32_t *)UNIQUE_ID_ADDR;            /* 唯一 ID 3 个字 */

    printf("Device ID = 0x%03X, Rev = 0x%04X\r\n", dev, rev);
    printf("Flash Size = %u KB\r\n", flash);               /* 64 或 128 等 */
    printf("UID = %08lX-%08lX-%08lX\r\n",
           (unsigned long)uid[0], (unsigned long)uid[1], (unsigned long)uid[2]);

    /* F103C8 应报 0x410（中等容量）；Flash 报 64 KB 才是正品 C8 */
}
```

> 用 `printf` 前请先重定向（见第 06/17 章）。若读到的 **Flash Size 与丝印不符**（如丝印 C8 却报 128 KB），多为兼容芯片或被「扩容」的山寨板；**器件 ID `0x410` 是 F103 中容量**，其它值需查 RM0008 的 Device ID 表。

## ⚠️ 常见坑与排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 买的「F103C8T6」跑不出 72 MHz | 兼容芯片/山寨主频受限 | 读 ID 与 Flash 容量核对；以实际能力为准 |
| RTC 不走时 | 板上未焊 LSE 晶振 | 补焊 32.768 kHz + 6 pF 电容 |
| 上电偶发复位 | 缺去耦/NRST 悬空 | 每个 VDD 加 100 nF；NRST 加 100 nF |
| ADC 读数噪声大 | VDDA/VSSA 未滤波 | VDDA 加磁珠 + 电容单独滤波 |
| 下载后连不上 | 把 PA13/PA14 复用并关 SWD | 保留 SWD；或 BOOT0 拉高救砖 |
| 排针标号与图上对不上 | 板厂丝印错/山寨改版 | 以芯片手册引脚定义为准，别信丝印 |
| 5 V 外设接 3.3 V IO | 电平不匹配 | 加电平转换或用 5V 容忍（FT）引脚 |
| 板子发热 | LDO 劣质/短路 | 量电流，换 LDO，查短路 |
| 引不出某功能 | 该引脚被复用冲突 | 查 pinout 图与 AF 表，换引脚 |
