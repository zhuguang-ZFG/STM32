# 手册对账与幻觉防御

AI 的输出里混着三类话：手册里有的、手册里没有但它编得很像的、以及它自己都不知道是哪类的。对账（把输出逐条按回手册）与幻觉防御（按类型分流、按成本处置）是两项基本手段；最后用这套书自己的生产管线自证。这套书的每一章都由这条管线产出，门禁会自己报警。

这里的事实断言分两代口径。**合并前 mcu 域**（AI05 重测，历史口径）：13 道印前门、27 条 CLAIMS、`check_pdf.py` 的 main 631、测试函数 73、题花 101、动画 111、章数 94。这套 mcu 门禁随 B5 合并退役、git 已删，这些数字只作历史参照，不再可复现。**合并后根书域**（可复现）：PDF 审计 7 项检查（5 项硬门禁）、`book/tests` 124 项（2026-11-25 全量通过）、`book/checks` 契约门、`slop_lint` 文风门、整书渲染 53 页（上手卷 + 46 章 + 6 附录）、静态站 54 页（含 404 noindex，2026-11-25 重测）。这章教的「数字漂移、引用前重测」恰好被合并本身演示了一遍：换了一套门禁，旧数字就失效，引用前必须按当前文件重测。工具红线三句按快照（2026-10-27）转写。「假勘误四件套」是**编造示例，请勿当真**。它在书里就是教你看穿编造的样本。板名统一为霸天虎，旧稿「霸道者」是错名。

## 先做出来

### 1. 对账三问：名、位、序

AI 说「开 GPIOF 时钟要置 `RCC_APB1ENR` bit5」。三问：

1. **名**：寄存器叫对了吗？RM0090 §7.3：`RCC_APB1ENR` bit5 是 **TIM7EN**，不是 GPIOF。位名张冠李戴。
2. **位**：位号对了吗？GPIOFEN 在 `RCC_AHB1ENR` bit5；寄存器名错了，位号倒是延续的。
3. **序**：顺序对了吗？先开 GPIO 时钟再写 GPIO 寄存器，这个序它说对了。

一条输出三问全过才算过；「雷 1 炸出两处伤」的案例就是位号对、寄存器错。单看位号会漏判。**道歉是文体不是修正动作**：模型说「抱歉我错了」不改变任何事实，回喂三元组（实测现象 + 手册出处 + 板卡事实）才算修正。

### 2. 证据回喂

发现错误后的标准动作：把**实测现象**（比如「引脚没翻转」）+ **手册出处**（RM0090 §7.3 的原句）+ **板卡事实**（原理图网络名）三条一起写回对话或文档。只写「你错了」不给证据，下一轮回答的采样分布不会移动。**模型的每次回答**是独立采样，「下次会更正」不是结论。

![对账三关与证据回喂：名/位/序三问，雷 1 是位对名错；修正需回喂实测现象、手册出处、板卡事实三条。原理示意，不是实测记录](/arch/reconcile-gates.png)

### 3. 跨源案例：`HAL_OK` 之后，数组还在用吗

把一次 UART DMA 发送拆成两条时间线：

```text
CPU：建立 tx[64] → 调 HAL_UART_Transmit_DMA() → 得到 HAL_OK → 函数返回
DMA：-------------------------------- 继续读取 tx[64] -------------------------------->
```

第一处分歧在 `HAL_UART_Transmit_DMA()` 的返回边界：调用者预期传输完成，源码只完成启动。锁定的 [STM32F4 HAL 源码（1f6451c）](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/blob/1f6451c3e07728b4c830744de380e56bf5bc0026/Src/stm32f4xx_hal_uart.c#L1377)保存 `pData`、调用 `HAL_DMA_Start_IT()`、置 `DMAT` 后返回 `HAL_OK`，没有等待 DMA 或 USART 完成。自动数组的 C 语言对象存储期却已随函数退出结束。

| 证据层 | 查到什么 | 对账结论 |
| --- | --- | --- |
| [《Mastering STM32》第二版](https://leanpub.com/mastering-stm32-2nd)物理第 269 页（印刷页 239）§9.4 | 局部数组随栈帧退出；全局或 `static` 数组延长存储期 | 书里解释的是存储期，不是 DMA 完成信号 |
| GitHub：STM32F4 HAL `1f6451c` | `HAL_UART_Transmit_DMA()` 保存地址、启动 DMA、置 `DMAT` 后返回 | `HAL_OK` 表示 DMA 启动调用成功，不表示字节已搬完 |
| 本书[第 14 章 §8](../v1-drivers/14-dma.md#八缓冲区的寿命三条时间轴) | TX/RX 的复用条件、回调与循环模式边界 | 普通 TX 至少保留到 DMA 不再读取且后续访问结束；RX 目标数组覆盖 DMA 写入期 |

因此，把发送数组改成 `static` 只延长它的存储期，完成前再次填充仍会改掉尚未搬走的字节。完整条件沿用第 14 章，不在这里再写一套。本节只完成书籍与源码对账，不是上板证据；真板仍需记录 DMA 停止时刻、缓冲区内容与后续访问窗口。

## 机制

### 一、八类幻觉：手册层四类 + 话语层四类

![手绘板：八类幻觉分拣成手册层 / 话语层两排工作台，每格配最低成本动作；先存在后语义，道歉不是修正动作（原理示意，非实拍）](/images/ch44-error-sorting-bench.png)

| 类 | 长相 | 判据 | 最低成本动作 |
| --- | --- | --- | --- |
| 手册·位名张冠李戴 | bit5 说是 GPIOFEN 实为 TIM7EN | 手册位表 | 30 秒 grep 头文件/手册 |
| 手册·地址错位 | 基址/偏移差 0x400 | 存储器映射表 | 章节检索 |
| 手册·修订版差异 | Rev V 才有的特性写成全系列 | errata/ES 文档 | 分钟级勘误检索 |
| 手册·特性编造 | 「硬件 CRC 单元」其实没有 | 特性表 | 特性表核对 |
| 话语·引用幻觉 | 引「§7.3 存储器映射」实际在 §2.3 | 章节检索 | 30 秒 |
| 话语·行号漂移 | `main:619` 实为 631 | 重测 | grep -n |
| 话语·数字陈旧 | 「100 枚题花」实为 101 | 重数 | 重数 |
| 话语·编造示例当真 | 假勘误四件套（**编造示例，请勿当真**） | 原文自带标注 | 看标注 |

八类的成本序（教学口径，不是测量）：30 秒 grep → 1 分钟章节检索 → 分钟级勘误/逐位 → 分钟级跑现象。总原则：**先存在性，后语义**：先查「这东西存在吗」，再查「它是我说的意思吗」。ESP32 侧的能力宏（`soc_caps.h`）是终裁（[第 30 章](../v4-platforms/30-esp32s3-architecture-boot.md) 口径）。

### 二、验证决策树与两条入口纪律

决策树的根是 [第 43 章](./43-ai-pair-programming.md) 的分界线问题：**正确性定义在公共知识，还是在你的板子与责任里？** 公共知识（手册可查）→ 三问对账；板卡事实（原理图/丝印）→ 实测读回；你的责任（安全边界/阈值）→ 不进 AI。两条入口纪律：**30 秒分类**：任何 AI 断言先花 30 秒分类（手册层/话语层/板卡层）；**贴不出证据默认升级**：拿不出出处与判据的断言，按最高成本路径处理。

对账分级表（AI02 口径）：RCC 与模式寄存器**一律逐位**；应用层抽样；纯算法单测。个人幻觉案例库四栏：类型/长相/判据/出处。被坑一次就记一行，案例库会逐渐反映你自己的错误分布。

### 四、生产线自证

这套书自己就是这套方法的产品：**八道工序十几道门**（选题→研究→计划→写作→门禁→评审→修复→证据归档），三起真实事故：滤镜题图被光栅化（art_guard 抓出）、U+2011 幽灵连字符（印前门抓出）、手写数字漂移（docs-check 的 CLAIMS 抓出：任何命中的数字必须等于当前真相）。

AI 在管线里的四个角色：研究代理（只读对账）、写作协作者、评审代理、门禁执行者。file-first 纪律：一切结论落文件，不留在对话里。四条不许碰边界：**终审决定、上板实测、出版决策、阈值只紧不松**。全部留给人。

度量表：每条论断配一条可复现命令。三条复现命令按合并仓库路径写：

```bash
python mcu/mcu-book/check_pdf.py <PDF>            # 13 道印前门
python mcu/mcu-book/tools/prose_guard.py --single <章节文件>
npm run docs:check --prefix mcu                   # 27 条 CLAIMS
```

（`mcu/docs/ai/02-…` 这类旧路径在合并后已不存在，--single 参数改指对应章的文件；命令实跑输出在批次证据里登记。）

## 失败分支

| 症状 | 第一条假设 | 区分实验 |

| AI 断言与手册冲突 | 位名/地址/修订版三类之一 | 三问对账；30 秒 grep 先行 |

## 离开检查

- 三问（名/位/序）能把一条 AI 输出核对完；雷 1 案例能复述。
- 回喂三元组能落地；「道歉是文体」的立场没有被稀释。
- 八类幻觉能分型并给出最低成本动作；「先存在性后语义」是总原则。
- 决策树能走；30 秒分类与「贴不出证据默认升级」两条纪律记得住。
- 两套门禁按域分列不混写；「失败会自己报警」的门禁定义说得清。
- 三起事故与四条不许碰边界能复述；根书数字按本轮重测，mcu 数字按历史快照，二者不混写。
