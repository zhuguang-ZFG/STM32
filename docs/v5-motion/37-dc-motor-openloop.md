# 直流电机开环调速

开环调速的真实含义是**给电压激励，转速电机自己定**：占空比控制的是驱动施加电压的时间比例（近似平均电压），转速由平均电压、电机参数与负载转矩共同决定——空载 50% 可能近半速、带负载明显偏低、低速还有静摩擦门槛。这一章把 PWM 的端点语义（CCR=ARR 差一格）拆到寄存器账，把带符号占空比、斜坡、租约与换向合同立成安全边界，最后把协议 v1 的带宽账算到 37.3%——这三组数由新增的数值断言测试钉死。

证据先说清：本章零板级实测。PWM 表（72 MHz/PSC 0/ARR 3599/20 kHz）与 CCR 映射、带宽账全部是算术复算；「三档转速单调上升」是预期不是结论；波形确认（M30-A）待执行；租约/斜坡/REVERSING 参数是**项目常量**（固件冻结默认，无外部可比）。M30-A/B/C 全部「待执行（实物未到）」。「高于可闻频段」的说法沿 [v1 第 12 章](../v1-drivers/12-timers-pwm.md) 的诚实口径：把开关声移出主要可听范围，仍要实测电机与驱动的噪声。

> 版本口径：冻结配置 v1.2——TIM1 PWM 72 MHz/PSC 0/ARR 3599（20 kHz）、TIM4 时基 PSC 7199/ARR 99（10 ms）、协议 v1（43 B 帧 × 100 Hz）、输出限幅 900‰、积分限幅 500‰、斜坡 ±50‰/10 ms、租约 500 ms。PWM 表与 [v1 第 12 章](../v1-drivers/12-timers-pwm.md) 的 20 kHz 表行是同一组数。

## 先做出来

### 1. PWM 四数一笔复算

```text
TIM1: 72 MHz / PSC 0 / ARR 3599 → 计数 3600 格 → PWM 频率 72 MHz/3600 = 20 kHz
TIM4: 72 MHz / PSC 7199 / ARR 99 → 10 ms 控制心跳
CCR = duty‰ × 3600 / 1000  → 50%→1800、25%→900、100%→3600
```

选 20 kHz 的三条理由：远低于 TB6612 的 100 kHz 上限；ARR 3599 仍在 16 位内；把开关噪声移出主要可听范围（沿 ch12 口径：仍要实测电机与驱动器）。**换时钟树，三条全重算**——PSC/ARR/CCR 映射没有一条能沿用。

### 2. 端点语义：差一格的 100%

PWM1 是「CNT<CCR 有效」：CCR=0 恒无效；**CCR=ARR 时有效格数 3599/3600≈99.97%**——差一格；CCR>ARR（=3600）才恒有效。满压写 **CCR=3600**。0% 端点与「撤销驱动」不是一件事：CCR=0 是恒无效（桥在但不出力），撤销驱动是 IN1=IN2=L 的滑行（[第 36 章](./36-motor-driver-power.md) 的停止语义）——软件语义绝不直接叫「滑行」，映射由 `motor_bridge.c` 配置项决定。

## 机制

### 一、带符号占空比：单点映射

控制量统一表示为 **−1000…+1000 ‰**：符号是方向、绝对值是幅值；映射到 AIN1/AIN2/PWM 引脚只有 `motor_bridge.c` 一处。好处：方向寄存器与幅值寄存器不在两处维护——两处状态漂移（方向翻过来、幅值没翻）这类 bug 在结构上不可能发生。占空比进桥之前先过双限幅：

- **输出限幅** |u| ≤ 900‰：`params_valid` 拒绝 ≥1000 的配置（限幅与满压端点天然对齐——900‰→CCR 3240 < 3599，永远够不到 CCR=ARR 的差一格区，更到不了 CCR>ARR）。
- **积分限幅** |I| ≤ 500‰：给第 39 章的抗饱和埋线。

![手绘板：带符号占空比到引脚的单点映射——符号是方向、幅值进桥（原理示意）](/images/ch30-signed-duty.png)

### 二、斜坡：±50‰/10 ms

开环模式下输出以 ±50‰/10 ms 逼近目标——受控起动与换向恢复共用同一条斜坡。为什么不能命令一到就跳变：占空比阶跃 = 电压阶跃 = 电流冲击（[第 36 章](./36-motor-driver-power.md) 的堵转电流机理），限流电源会打嗝、机械会顿挫。斜坡速率是**项目常量**，不是调优结论。

### 三、租约：断串口必停机

命令流中断 **500 ms**（故障位 F01）锁存故障停机——串口拔掉不会留下一只转动的电机。心跳由上位机的 100 Hz 帧流维持；租约到期即锁存，恢复须重新 ARM。**STOP 豁免会话检查**：无论租约状态，STOP 命令永远执行——安全命令不能因为「会话已失效」被拒。

![手绘板：PWM 数学与限幅——ARR 3599、CCR=ARR 差一格、900‰→CCR 3240（原理示意）](/images/ch30-pwm-math.png)

### 四、REVERSING 合同：四阶段与 3 s 超时

直接翻转方向 = 回流尖峰来源（[第 36 章](./36-motor-driver-power.md) 的再生段）——桥在换向瞬间同时承受两个方向的电流。换向走四阶段合同，全程 **3 s 超时**：

1. 占空比斜坡降到 0；
2. 撤销驱动（IN1=IN2=L），等停稳（|rpm| ≤ 5，判据由 第 38 章 的量化口径支持）；
3. 保持 100 ms；
4. 才允许反向。

![手绘板：换向四阶段——斜坡归零、撤销驱动、等停稳、再反向（原理示意）](/images/ch30-stop-triage.png)

### 五、协议 v1 与带宽账

43 B 帧 × 100 Hz，8N1 每字节 10 bit（1 起始+8 数据+1 停止）：

```text
4300 B/s × 10 bit = 43 000 bit/s = 43 kbit/s
43 000 / 115 200 ≈ 37.3%
```

（不是 4%——旧稿的口误，数值断言测试钉死。）控制指令流量很小；**扩遥测先算总线占用**——每加一个字段先过这条 37.3%，再加帧长重算。

### 六、控制时基：硬件心跳，不是软件延时

控制节拍是 TIM4 的 10 ms 硬件中断（PSC 7199/ARR 99）——不得用主循环里的软件延时或「顺便计数」当时基：周期不保证恒定，斜坡速率与租约计时都会漂。所有权边界：**ISR 只写桥**（motor_bridge 的输出函数），**主循环只收发**（UART 解析与遥测）——打印和协议解析拖慢主循环，不拉长控制周期。上 RTOS 后的同一纪律：控制任务唯一拥有输出、截止期 10 ms 进任务配置（回链 [v3-rtos 22/24](../v3-rtos/22-tasks-tcb-scheduler.md)，不重教）。

![手绘板：电机不转的排查阶梯——STBY/VM/方向/占空比四查（原理示意）](/images/ch30-no-spin-triage.png)

### 七、数值断言测试

本章两组可复算数值由 `book/tests/test_motor_numbers.py` 钉死（随本章提交加入，全四章落位后按批次收口把旧草稿路径的测试退役）：

1. **PWM 端点**：`arr = 72_000_000 // 20_000 - 1 == 3599`、`counts == 3600`、`arr/counts ≈ 0.99972`；文案锚点「| ARR | 3599 |」「须大于 ARR」「CCR>ARR」；负向哨兵：三种错误写法（把 3600 与 ARR 写成相等、把 CCR 写成不小于 ARR、把差一格的满值写成 100% 端点）不得出现在文案里。
2. **串口带宽**：`43 × 100 = 4300 B/s`、`×10 = 43 000 bit/s`、`/115200 ≈ 37.3%`（±0.05）；正向锚点「37.3%」「43 kbit/s」；负向哨兵：把 43 kbit/s 误写成占带宽 4% 的旧说法不得出现。

## 失败分支

| 症状 | 第一条假设 | 区分实验 |
| --- | --- | --- |
| 占空比 100% 仍比预期慢 | 写了 CCR=ARR（99.97%）；或负载/静摩擦门槛 | 检查 CCR 值；改 CCR=3600 对照 |
| 换时钟后 PWM 频率漂 | 只改了 PSC 没重算 ARR/CCR | 四数重算；测试断言随新时钟改 |
| 断串口后电机不停 | 租约没启用或 STOP 被会话检查挡住 | 查 F01 锁存逻辑与 STOP 豁免 |
| 换向瞬间电流尖峰、电源打嗝 | 直翻换向 | 走 REVERSING 四阶段 |
| 控制周期抖动 | 用了软件延时当时基 | 换 TIM4 中断；读 DWT 计时 |
| 串口偶发丢帧 | 带宽逼近（帧加长后） | 重算 37.3%；降帧率或缩帧 |
| 方向对了幅值反了 | 方向与幅值在两处维护 | 收敛到带符号占空比单点映射 |
