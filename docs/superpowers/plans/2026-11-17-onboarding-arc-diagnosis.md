# 「从入门到精通」弧线诊断：对照两本参考书

用户判断：「感觉总体不是从入门到精通」。参照物：蒙博宇《STM32自学笔记》
（北航社，F103+固件库，自学向经典）、李延鹏《轻松学：ARM嵌入式开发》
（教材向，S3C2440）。两本 EPUB 已解包到 `.temp/ref-meng`、`.temp/ref-li`。

## 一、参考书的「入门→精通感」由什么构成

### 蒙书（自学书，最接近我们的读者画像）

叙事弧（目录实测）：

```
第1章 什么是STM32          ← 欢迎+全景：行业、性价比口号、能做出什么
第2章 Cortex-M3 内核架构    ← 深度层（读者此时已有动机）
第3章 欢迎来到STM32的世界   ← 最小系统/时钟/启动/调试端口（硬件上手前奏）
第4章 开发工具              ← 装好 Keil、建立第一个工程（环境闭环）
第5章 基础实验              ← 十个实验，每个 9 小节固定节拍
第6章 进阶应用              ← 10 个进阶
第7章 综合实例：IAP 方案    ← 全书收口的大项目
```

三个可复用的手法：

1. **九节实验节拍**（5.1.1–5.1.9 实测）：概述 → 实验设计 → 硬件电路 →
   程序设计 → 程序清单 → 注意事项 → 库函数一览 → **实验结果** → 小结。
   第 3 个实验起读者已经会读第 10 个——可预测性产生信心。
2. **里程碑密度**：前 100 页里读者亲手完成 ≥5 个看得见的结果
   （灯闪 / SysTick / 按键 / 串口 Hello / 外部中断）。
3. **引导性语气**：「先用 GPIO 来点个灯吧」「通过串口和 PC 说声 Hello」
   ——章节标题本身就是邀请。

### 李书（教材）：概念→体系→指令→汇编→流程→外设逐章，每章「本章小结」。
它的「精通感」弱于蒙书（实验闭环少），价值在每章收口的小结纪律——我们已有等价物（离开检查）。

## 二、我们这本书为什么「感觉不是」——四个缺口（均有实测证据）

1. **第 1 页不是欢迎，是审计**。v0 第 1 章 = 《嵌入式 C 的内存模型与指针》，
   开篇即 `nm`/段归属/VMA-LMA 对账。入门读者没有拿到蒙书第 1 章那样的
   「这是什么、你能做出什么、买哪块板」。欢迎与全景层缺失。
2. **第一个「你做出来了」延迟太久**。v0 的先做出来是宿主机押数字；
   第一次点灯在 ch09 正文深处；ch46 的三阶段表（4/6/8 周）没有绑定
   「周 × 章 × 可展示物」的自学排期，读者无法感知阶梯在被攀登。
3. **章节按知识分层组织（v0–v7），不是按旅程组织**。分层对精通者是对的，
   但缺少一个把「卷 → 旅程」翻译过来的导航层；蒙书的目录本身就是旅程。
4. **成就环节缺位**。我们的证据纪律要求「实验结果」标注未实测——
   这是诚实契约，不能伪造；但多数章没有把「预期现象」写成一个读者
   自己动手后可以对照的「你应该看到」清单，成就感环节被略过。

结论：**46 章的知识结构不需要动，缺的是一个入门坡道 + 一层旅程导航。**

## 三、候选改法（均为新增层，不动现有 46 章契约与证据纪律）

- **A. 上手卷开篇**（1 章）：什么是嵌入式/STM32（欢迎全景）→ 买什么
  （两线采购）→ 装环境 → 第一次下载与点灯（`examples/gpio-blink`）→
  串口 Hello → 按 L0 证据收口、接 v0 第 1 章。即蒙书第 1+4 章合体，
  落位为全书第 0 章（站点与 PDF 卷首）。
- **B. 旅程导航行**：每章罗盘加一行「上一章你手里有什么 / 本章结束
  多了什么」（可脚本生成草稿 + 人工润色）。
- **C. 16 周自学排期**：ch46 三阶段表升级为「周 × 章 × 里程碑物」，
  每周一个可展示物（周 1 点灯、周 2 串口……），替换纯周数。
- **D. 「你应该看到」**：有板实验的章节在先做出来末尾加「预期现象」
  清单（不标实测，只给判读口径），补成就环节。
