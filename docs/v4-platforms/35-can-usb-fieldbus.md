# 现场总线与 USB

CAN 与 USB 是 MCU 对外通信的两种「重协议」：CAN 是差分总线，靠位时序与过滤器吃饭，波特率算错一步整条总线瘫痪；USB 是主机轮询的枚举式协议，48 MHz 时钟偏一点就是「未知设备」。这一章把两平台（F103 与 F407）的 CAN 位时序表并排放——**分母不同，数字不能互抄**——再把 USB 的 48 MHz 来源、描述符账与枚举七步拆开，最后把 F103 上 CAN/USB 抢脚抢向量的历史包袱讲清。

证据先说清：本章零板级实测。CAN 位时序全部是算术复算（公式与每档数字逐行可验）；F407@42 MHz 的位时序表是本章**新增**（源章只有 F103 账，检索计算器口径一致，落笔前按 RM0090 §32 复核编码）；过滤器组数按 RM0008（F103 14 组）与 RM0090 §32（F407 **28 组**）——源章「F4 也是 14 组」与手册冲突，本章修正；RM0008 的 bxCAN 是 **§24**（USB §23），源章「第 21 章」错。USB 描述符账按例程逐字节实读（`cdc:47-53`）与规范口径；VID/PID 是占位号。收发器电平、向量表页码等保留待核标签。

> 版本口径：CAN 按 RM0008 §24（bxCAN）/RM0090 §32；USB 按 RM0008 §23 / RM0090 §30（OTG_FS）与 USB 2.0 规范第 9 章；F407 的 OTG_FS 专用 48 MHz 按数据手册（dm00037051）口径。收发器器件（SN65HVD230/TJA1050）参数属器件手册级，标待核。

## 本章罗盘

- **问题**：CAN 位时间三段式怎么拆，采样点公式是什么？同一波特率为什么先验算预分频是不是整数（7.2 反例）？F103@36 MHz 五档表怎么复算，F407@42 MHz 的 500k 两解是什么，把 F103 数字抄到 F407 会得多少？过滤器组数两平台各是多少，「F4 也是 14 组」错在哪？32 位掩码模式下标准 ID 为什么左移 5 位？TEC/REC 的错误阶梯（128/256/128×11 隐性位）与 ABOM 两条恢复路是什么？回环模式证明了什么、不证明什么？USB 的 48 MHz 两平台各从哪来，F103 的 USBPRE 两条路是什么？设备 18 B、配置集合 67 B 的账怎么拆，1023 与 64 的边界在哪？枚举七步的卡点分诊表是什么？F103 上 CAN 与 USB 为什么不能同工程？
- **交付**：能复算两平台的 500k 工作点（F103 P9×8Tq@75%；F407 P6×14Tq@85.7% 或 P7×12Tq@83.3%）与五档表；能用 450 kbit/s 反例讲清整除验算；能写两平台过滤器组数（14/28）与左移 5 位的算式；能画 TEC 阶梯与两条恢复路径；能把回环与双节点的证明边界说清；能算 F1 的 72/1.5=48 与 F4 的 PLLQ 账；能拆 67 B 配置集合的十项并纠正「1023 是批量上限」的误记；能按枚举七步给出卡点分诊。
- **边界**：单讲 bxCAN 与全速设备 USB；H7 的 FDCAN 是另一外设（寄存器/位时序/引脚都不同），归 [第 28 章](./28-chip-migration-differences.md) 的 H7 场；CAN 总线的协议语义（仲裁/帧类型）与 USB 的类协议细节以源章与规范为准，本章收「迁移与复算」视角；UART/RS485 类串行现场总线不在本章。
- **依据锚点**：D13《CAN 总线》（`docs/13-CAN总线.md`）、D14《USB》（`docs/14-USB.md`）、例程描述符 `cdc:47-53`。上游对账：RM0008 §23/§24、RM0090 §30/§32；USB 2.0 规范第 9 章（设备框架）；ISO 11898-1 错误限制口径。F103 的 CAN/USB 引脚冲突两书互证（D13:44-46 与 D14:53,306）。

## 先做出来

### 1. 500 kbit/s，两个分母两条账

CAN 位时间三段式：SYNC（1 Tq）+ BS1 + BS2；采样点在 `(1+BS1)/(1+BS1+BS2)`；波特率 = `f_APB1 / (Prescaler × (1+BS1+BS2))`。同一个 500 kbit/s：

| 平台 | APB1 | 工作点 | 位时间 | 采样点 |
| --- | --- | --- | --- | --- |
| F103 | 36 MHz | P=9、BS1=5、BS2=2（8 Tq） | 9/36M=250 ns → 2 µs | (1+5)/8 = **75%** |
| F407 | 42 MHz | P=6、BS1=11、BS2=2（14 Tq） | 42M/(6×14)=500k | (1+11)/14 ≈ **85.7%** |
| F407 | 42 MHz | P=7、BS1=9、BS2=2（12 Tq） | 42M/(7×12)=500k | (1+9)/12 ≈ **83.3%** |

**分母不同，数字不能互抄**：把 F103 的 (P9,5,2) 抄到 F407，得 42M/(9×8)=**583.3 kbit/s**——整条总线跟着错；把 F407 的 (6,11,2) 抄回 F103，得 333.3 kbit/s。

### 2. 整除验算：450 kbit/s 反例

想要 450 kbit/s@36 MHz：P=8、10 Tq → 36M/(8×10)=450k，恰好成立；而 500 kbit/s@10 Tq 需要 P=**7.2**——非整数，写 7 就是 514.3 kbit/s。先验算整除，再挑档位；450k 的完整推理链（错在哪一步、现象是什么）是源章的教学招牌，保留。

## 机制

### 一、五档波特率表（F103@36 MHz，逐行复算）

| 波特率 | 工作点 | 采样点 | 复算 |
| --- | --- | --- | --- |
| 1M | P=3 × 12 Tq | 75% | 36M/(3×12)=1M |
| 500k | P=9 × 8 Tq | 75% | 36M/72=500k |
| 250k | P=18 × 8 Tq | 75% | 36M/144=250k |
| 125k | P=36 × 8 Tq | 75% | 36M/288=125k |
| 100k | P=45 × 8 Tq | 75% | 36M/360=100k |

F407@42 MHz 的对应表本章新增（500k 两解见先做出来；其余档位同法复算），TS1/TS2 的寄存器编码按 RM0090 §32 复核后落表。

### 二、过滤器：14 与 28，左移 5 位

| 平台 | 过滤器组 | 归属 |
| --- | --- | --- |
| F103 | **14 组**（Bank 0–13）+ 2 个接收 FIFO | RM0008 |
| F407 | **28 组**（CAN1/CAN2 共享） | RM0090 §32 |

源章「F4 也是 14 组」与手册冲突，本章按 28 组修正。掩码/列表两种模式、32/16 位宽、FIFO 分配的语义同源章。**标准 ID 左移 5 位**：32 位掩码模式下 `FilterIdHigh = ID << 5`（STID[10:0] 落在寄存器高半的 bit[15:5]）——不左移，邮箱永远空；复算 0x123<<5=0x2460、掩码 0x7FF<<5=0xFFE0。

### 三、错误阶梯与恢复：128 / 256 / 128×11

错误计数阶梯（ISO 11898-1 口径）：节点发不出（无 ACK）时 TEC 每次加 8；累计到 **128** 进 error-passive 且单节点无 ACK 时停在此不再涨；**TEC>255 才 Bus-Off**；恢复需要 **128 次 × 11 个连续隐性位**（总线空闲检测）。两条恢复路：`ABOM=1` 由硬件自动恢复；`=0` 软件在 128×11 后手动重启——产品选哪种要写进设计，不是编译时顺手。发送重试 `NART=0` 自动重发、`=1` 只发一次（RM0008 §24.9.1 口径，小节号落笔前复核）。

### 四、回环的证明边界

回环模式只证明 bxCAN 的收发路径、位时序与过滤器配置；**不证明**收发器（TJA1050/SN65HVD230）、120 Ω 终端电阻、差分总线布线。上真总线的验收清单：两端各 120 Ω（并联 60 Ω 是直流负载，**60 Ω 不是电缆特性阻抗**）、共地、收发器电平（3.3 V 与 5 V 器件混接要查）。回环→双节点→多节点的递进是源章的教学设计，逐级扩权。

### 五、USB 48 MHz：两个分母两种来路

| 平台 | 48 MHz 来源 | 算术 | 错了会怎样 |
| --- | --- | --- | --- |
| F103 | PLL ÷1.5：`USBPRE=0` | 72/1.5=48 | `USBPRE=1` → 72 MHz 直进，枚举直接失败 |
| F407 | OTG_FS **专用 48 MHz**（PLLQ） | 8M HSE → PLLN 336 / PLLQ 7 = 48 | 时钟偏差 → 主机读描述符失败，报「未知设备」 |

F407 侧是**专用时钟线**（PLL48CLK），不随 SYSCLK 走——与时钟树解耦的独立档位。

### 六、描述符账：18 + 67 与占位号

例程描述符逐字节实读（`cdc:47-53`）的账：

- **设备描述符 18 B**（首字节 0x12）：含 `bMaxPacketSize0`=64。
- **配置集合 `wTotalLength` = 67 B**（0x0043）= 9(配置)+9(接口类)+5+5+4+5(功能)+7(端点)+9(接口数据)+7+7 十项之和——**67 是配置集合总长，不是「配置描述符」本体（9 B）**。
- 端点包长：全速**批量/中断 ≤64 B**；**1023 只属于全速等时**；CDC 的通知端点 8 B。
- VID/PID：本仓库例程是 **0x1209/0x0001**（pid.codes 厂商号+未注册占位）；ST 例程的 0x0483/0x5740 是**人家的**——占位号别印进量产叙述。

PMA 与端点（RM0008 §23）：F1 全速设备 **8 个双向端点**（EP0–EP7）共享 **512 B PMA**，BTABLE 手工分配；F103 USB 是纯设备，做不了主机。

### 七、枚举七步与卡点分诊

枚举顺序（USB 2.0 规范第 9 章口径）：复位 → 地址 0 取**设备描述符前 8 字节**（拿 EP0 包长）→ Set Address → 全设备描述符 → 配置集合（校验 `wTotalLength`）→ Set Configuration → 就绪。卡点分诊：第一步失败查 48 MHz 时钟；`wTotalLength` 不对查描述符链拼接；配置后不工作查端点是否就绪与 `bMaxPower`（例程 0x32=100 mA）。CDC 与 HID 一句话选型：CDC=字节流（批量 IN/OUT + 通知中断 IN），HID=固定格式报告（系统原生驱动，免驱动安装）。

![USB 48 MHz 手绘板：F1 的 USBPRE 与 F4 的 PLLQ 两条来路（原理示意）](/images/ch14-usbpre-48.png)

### 八、PA11/PA12：一条向量两个主人（F103 历史包袱）

F103 上 CAN1 与 USB 共用 PA11/PA12，**还共用一条向量**（中容量 `USB_LP_CAN_RX0`，互联型 `USB_LP_CAN1_RX0`）——两个例程不能编进同一个工程。解法：CAN 重映射到 PB8/PB9（小封装另有约束：PD0/PD1 在 LQFP48 上是 HSE 脚，36/48/64 脚封装禁止重映射到端口 D）；或者干脆换 F411（无 CAN，无此冲突）。F407 上 OTG_FS 与 bxCAN 是独立外设，冲突消失。[第 28 章](./28-chip-migration-differences.md) 的抢脚表把三家族的解法收在同一页。

## 失败分支

| 症状 | 第一条假设 | 区分实验 |
| --- | --- | --- |
| 整条总线无 ACK | 位时序算错（分母抄错平台） | 复算波特率；示波器量位时间 |
| 邮箱永远空 | 标准 ID 没左移 5 位 | 核对 `FilterIdHigh = ID<<5` |
| F407 只收到 1/2 的帧 | 过滤器组数按 14 组配 | F407 是 28 组（CAN1/CAN2 共享） |
| 单节点发送一直重试 | 进 error-passive 停在 128 | 读 TEC；确认 ABOM 配置与恢复条件 |
| 回环通了真总线不通 | 收发器/终端/布线在回环里验证不了 | 上双节点逐项查 120 Ω、共地、收发器 |
| USB 报「未知设备」 | 48 MHz 时钟偏差 | 复算 USBPRE/PLLQ；量时钟 |
| 枚举停在第一步 | EP0 包长/时钟问题 | 换地址 0 的 8 字节请求验证 EP0 |
| 配置后不工作 | `wTotalLength` 拼接错 | 十项分解逐项对账（9+9+5+5+4+5+7+9+7+7） |
| CAN 例程与 USB 例程同工程编译炸 | F103 同向量 | 拆工程或 CAN 重映射 PB8/PB9；或换 F411 |

## 跨平台边界

- FDCAN（H7）是另一外设：寄存器、位时序编码、引脚都不同，归 [第 28 章](./28-chip-migration-differences.md) 的 H7 场。
- CAN 的协议语义深水区（帧类型、仲裁细节、错误帧格式）：源章已覆盖，本章收迁移与复算视角。
- USB 高速（OTG_HS）与类协议完整描述符：不在本章（F103/F407 全速口径）。
- CAN/USB 的应用层协议设计（车载帧/自定义批量协议）：按项目需求另立，本章给边界。

## 离开检查

- 两平台 500k 工作点能当场复算，「分母不同数字不能互抄」能举 583.3 kbit/s 的反例。
- 五档表逐行复算；450k 反例的整除验算能讲全。
- 14/28 组过滤器与左移 5 位的算式能写对。
- TEC 阶梯（128/256/128×11）与 ABOM 两条恢复路能画。
- 回环的证明边界（不证明收发器/终端/布线）说得清。
- 48 MHz 两来路（USBPRE ÷1.5 / PLLQ）能复算；「未知设备」的第一假设是时钟。
- 18+67 的描述符账能拆十项；1023 vs 64 的边界不混。
- F103 的 CAN/USB 冲突（引脚+向量）与三条出路能列。
