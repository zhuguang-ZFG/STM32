# B46：打印版图高上限与页底留白基线

日期：2026-11-08。基线 `df89879`（B45 合并）。计划见
`docs/superpowers/plans/2026-11-08-book-visual-experience.md`。

## 发现

现有 `tools/audit_pdf_layout.py` 已覆盖孤行标题、图注拆页、右边距溢出、近空白页，
四项在中英文 PDF 中均为 0。唯一成规模的版式缺陷是页底留白：
不可拆分的高图块被推到下一页，上一页底部空出 150–400pt。
抽查留白页的下一页，起始内容几乎都是一张竖向较高的图（或其上方图注）。

## 改动

- `book.css` 打印样式：`img { max-height }` 由 165mm 改为 120mm。
  横向图仍受宽度约束，不受影响；只压缩竖长图。
- `audit_pdf_layout.py`：分档标签按实际判定改正为 `250-399pt` / `>=400pt`；
  新增 `--max-large-gap-pages`，单独约束 ≥250pt 的大块留白。
- CI：`--max-gap-pages 145 --max-large-gap-pages 15`（两种语言）。

中等留白（150–249pt）略增，来自相邻两张图之间放不下第二张；
这类缺口要靠 B48/B49 的图文重排解决，而不是继续压图。
