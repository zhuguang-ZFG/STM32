# 学习路线收束

这一页只出现在书稿里，用来把七个分部收成一条可以继续走的路。它不改 `docs/` 里的第 28 章。下面的数字都是前面各章已经给出的账，收在这里方便对照实测。

## 七段各留下什么证据

| 分部 | 读完时应能拿出 |
| --- | --- |
| 起步 | 可重复的工程：能编译、下载、断点，并写明芯片和时钟假设 |
| 引脚与时间 | 一只脚的真实电平，或一张定时器周期的计算和实测 |
| 搬运 | 一帧 UART、I2C 或 SPI，或一次 ADC/DMA 的缓冲区归属 |
| 可靠性 | 看门狗、低功耗或升级失败时的状态，而不是只在演示路径上通过 |
| 交付 | 一个小项目的复现记录，并分清手册、例程和社区说法 |
| 迁移与联网 | 换系列时重核电源、复用、时钟和内存；网络按链路、地址、传输、应用分层排错 |
| 系统 | 一张有主人、截止时间和恢复证据的系统图，而不是只换了一个 RTOS 的名字 |

## 第一块板先记这四行

默认板是 BluePill，丝印 STM32F103C8T6，LQFP48。还没换芯片之前，实验记录里先有这四行，再谈跑起来了。算法和手册路径在[附录 D](#appendix-glossary)文末的第一张账。换芯片用后面那一张。

| 要写下来的 | 这本书里的期望 | 你要填的实测 |
| --- | --- | --- |
| 容量 | 读 `0x1FFFF7E0`，正品 C8 为 64 KB；中容量 DevID 为 `0x410` | 读数，以及它和丝印是否一致 |
| 时钟 | HSE 8 MHz ×9 = 72 MHz。APB1 为 36 MHz，TIM2–TIM7 仍按 72 MHz 算；Flash 等待写 2 | `HAL_RCC_GetPCLK1Freq()`，再加一次 PWM 周期 |
| 一帧串口 | USART1、115200、8N1，BRR `0x271`，一位约 8.68 µs，一帧约 86.8 µs | 逻辑分析仪上的位宽 |
| 一条失败边界 | IWDG：预分频 64、Reload 624 才是按 40 kHz 算出的 1 秒。LSI 大约在 30–60 kHz，秒数不是保证值 | 故意不喂狗时的复位旗和秒表 |

## 换芯片时再写的三行

第一块板的四行对上之后才换系列。期望值在[附录 D](#appendix-glossary)的第二张账里。实测仍由你填。

| 要写下来的 | 这本书里的期望 | 你要填的实测 |
| --- | --- | --- |
| G0 的启动锁存 | 第四个 SYSCLK 上升沿锁存。PA14 同时是启动输入和 SWCLK。`DBG_SWEN` 的复位值是 0 | 采样窗口里 PA14 的电平，以及调试器能否连上 |
| L4 醒来的时钟 | Stop 2 之后的临时时钟是 MSI 或 HSI16。封面 1.1 µA、带 RTC 1.4 µA、唤醒 4 µs 是芯片典型值 | 醒后第一帧的位宽；拔掉调试器和 LED 之后的电流 |
| H7 的硅片和 VOS | Rev Y/W 停在 VOS1 和 400 MHz。Rev V 从已经就绪的 VOS1 进入 VOS0，再到 480 MHz。MCO2÷5 在 400 MHz 时期望 80 MHz，在 480 MHz 时期望 96 MHz | `REV_ID`、两次 `VOSRDY`、MCO 的仪器读数 |

## 怎样算这本书读完

三条就够：

1. 工具链能在你自己的板上重做一遍，而不是只在截图里成功。
2. 至少一个结论同时写着期望值、实测值和测量条件。
3. 这个结论能指回文档号或冻结的代码版本。指不回去的数字，先不要写进设计。

## 下一步怎么选

按你真正要交付的约束选一条，做深，而不是把 29 章再扫一遍。

- 还在打通最小闭环：回到第 00–05 章，把点灯、中断和 PWM 做成可测量的记录。
- 数据要进单片机再出去：第 06–10 章加 [附录 A](#appendix-engineering)，把缓冲区和帧边界写清楚。
- 设备要在掉电、升级或低功耗之后还在：第 11、12、16 章，把失败路径和唤醒后的时钟写成表。
- 要上网：第 27 章。链路、地址、TCP、MQTT 和 TLS 分开证明。
- 要选 RTOS：第 15 章和第 28 章。先有栈、队列和中断优先级预算，再比较内核名字。

术语回查用 [附录 D](#appendix-glossary)。什么算数、什么只是线索，用 [附录 E](#appendix-references)。

## 先不要做的事

- 不要把 F1 的寄存器地址抄到 G0、L4 或 H7。
- 不要把 F103 的 1 KB 页、预分频 9 或 BRR `0x271` 抄到时钟不同的系列上。
- 不要把仿真通过当成板级电气已经正确。
- 不要把公众号或社区文章里的参数当成手册。
- 中文整书和英文整书是两次构建。英文用 `docs/en/` 和 `stm32-book/book/en/`。不要把中文页里的一句叙述，当成英文版里已经核对过的寄存器事实。

收束之后如果只做一件事：选一个你要交付的行为，写下它的期望、测量和下一次会失败的边界。
