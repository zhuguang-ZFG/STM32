# 来源、版本与许可

本书把来源分成四层，使用时不能互相替代：

1. **规范与芯片手册**：数据手册回答引脚/电气，参考手册回答寄存器/外设，编程手册回答内核，协议规范回答线上语义。
2. **官方代码与应用笔记**：展示一个版本上的实现方法；它们仍有具体芯片、固件包和例程配置边界。
3. **官方社区与开源实现**：用于发现坑、比较写法和构造验证；社区结论不是规范，必须回查目标版本源码或手册。
4. **本项目原创内容**：章节、例程、图和构建器。事实性参数尽量指向前三层；教学组织和实验步骤由本项目负责。

## 快照规则

- 手册引用至少写文档号；对引脚、典型电流等修订敏感事实再写 Rev、Figure、Table 或章节。
- GitHub 参考实现冻结 tag 或完整 commit，不用“main 现在看起来一样”作为证据。
- 社区文章记录访问日期和用途，只作经验线索。
- 例程复现记录同时冻结芯片订货号、板卡丝印、Cube 固件包、编译器和时钟配置。

## 本书与原仓库

本书正文来自同仓库 `docs/00–28`，构建时移除视频、字幕和重复旁白，但不修改原章节。每章前增加“问题/交付/边界/来源锚点”；五份附录把例程、答案、术语和来源连成整书。第 26 章的 SPL API 以 STSW-STM32054、RM0008 和冻结源码镜像交叉核对；第 27 章的网络边界以 RM0433、UM2407/UM1713、冻结 STM32CubeH7/lwIP/Mbed TLS 源码及 IETF/OASIS 规范交叉核对；第 28 章的系统边界以 FreeRTOS V11.3.2、RT-Thread v5.3.0、Zephyr v4.4.2、CMSIS 6.4.0/CMSIS-RTOS2 2.3.0 和 PM0056 交叉核对。

组织方法参考同一工作区的 BMS-Z 书籍构建经验：分部目标、章节罗盘、离线 HTML/PDF 与答案附录。这里只借鉴方法，未复制 BMS-Z 正文；两者许可和技术主题分别处理。
