# 来源、版本与许可

本书把来源分成四层，使用时不能互相替代：

1. **规范与芯片手册**：数据手册回答引脚/电气，参考手册回答寄存器/外设，编程手册回答内核，协议规范回答线上语义。
2. **官方代码与应用笔记**：展示一个版本上的实现方法；它们仍有具体芯片、固件包和例程配置边界。
3. **官方社区与开源实现**：用于发现坑、比较写法和构造验证；社区结论不是规范，必须回查目标版本源码或手册。
4. **本项目原创内容**：章节、例程、图和构建器。事实性参数尽量指向前三层；教学组织和实验步骤由本项目负责。

## 快照规则

- 手册引用至少写文档号；对引脚、典型电流等修订敏感事实再写 Rev、Figure、Table 或章节。
- GitHub 参考实现冻结 tag 或完整 commit，不用“main 现在看起来一样”作为证据。
- 社区文章记录访问日期和用途，只作经验线索。
- 例程复现记录同时冻结芯片订货号、板卡丝印、Cube 固件包、编译器和时钟配置。

## 本书与原仓库

本书正文来自同仓库 `docs/00–28`，构建时移除视频、字幕和重复旁白，但不修改原章节。每章前增加“问题/交付/边界/来源锚点”；第 28 章之后有一页只存在于书稿的「学习路线收束」。五份附录把例程、答案、术语和来源连成整书。第 23 章的 G071 启动真值表、共脚硬件和恢复边界以 DS12232、RM0444、AN5096、AN2606 与 ST 官方启动 FAQ 交叉核对；第 25 章的 H743 供电、revision 与 400/480 MHz 路径以 DS12110、RM0433、ES0392、AN4938、ST 官方 480 MHz 指引及冻结 STM32CubeH7 时钟示例交叉核对；第 26 章的 SPL API 以 STSW-STM32054、RM0008 和冻结源码镜像交叉核对；第 27 章的网络边界以 RM0433、UM2407/UM1713、冻结 STM32CubeH7/lwIP/Mbed TLS 源码及 IETF/OASIS 规范交叉核对；第 28 章的系统边界以 FreeRTOS V11.3.2、RT-Thread v5.3.0、Zephyr v4.4.2、CMSIS 6.4.0/CMSIS-RTOS2 2.3.0 和 PM0056 交叉核对，H745 双核边界另以 RM0399 与冻结的官方 `stm32h745xx.h` 核对。

## 一笔数字怎样才算钉住

[附录 D](#appendix-glossary)文末的前两张账用同一套四格：订货号、文档号或章节、寄存器或公式、算式结果。缺一格，就还只是线索。第二张账把订货号换成 G0、L4 或 H7 时，时钟和寄存器整行重写。第三张账钉 DMA 通道、USB 描述符长度和 `CFSR`/`HFSR` 地址；换请求表或换描述符时，这几行同样整行重写。

115200 这一格可以当样子。订货号是 STM32F103C8T6，USART1 的时钟走 APB2，不是 APB1。文档号是 [RM0008](#source-rm0008) 的 USART 波特率寄存器，算式正文在第 06 章。公式是 `fPCLK / (16 × 波特率)`。72 MHz 代入得到 39.0625，BRR 低 4 位是 1，结果是 `0x271`，分频误差是 0。记录里如果只有「误差 0.16%」而没有 USART 编号和 BRR，这一格还没钉住：0.16% 是 36 MHz 那一行，或是把 72 MHz 的小数位丢掉之后的数。

## 把一格填满

换一个数之前，先按这个空表抄一行。右边是 500 kbit/s 已经填过的样子，对应[附录 D](#appendix-glossary)第二张账。

| 格子 | 填什么 | 500 kbit/s 这一格 |
| --- | --- | --- |
| 订货号 | 丝印上的完整订货号。H7 还要有 revision | STM32F103C8T6 的 bxCAN。FDCAN 另开一格 |
| 时钟 | 写进公式的那一路，带数值 | APB1 = 36 MHz。72 MHz 是 APB2 和定时器那一路 |
| 寄存器 | 名字和将要写入的字段 | 预分频 9，BS1 = 5，BS2 = 2，SJW = 1 个 Tq |
| 算式 | 一行除法。除不尽就写出小数 | `36e6 / (9 × 8) = 500000`。采样点 `(1+5)/8 = 75%` |
| 证伪 | 哪个仪器读数会推翻这一格 | 位速率若是 450 kbit/s，对应 10 个时间份额和预分频 8：`36e6 / 80 = 450000`。那一格的预分频本来是 7.2 |
| 不写进设计的数 | 这一格证明不了什么 | 回环收到自己的帧，证明控制器接受了这组位时间。两端 120 Ω、ACK 和错误计数另记 |

> ⚠️ 7.2 写不进预分频字段。写成相邻的整数 8 之后，总线速率是 450 kbit/s，回环仍然可能是绿的。
