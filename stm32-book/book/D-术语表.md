# 术语表

| 术语 | 本书中的含义 | 常见误解 |
| --- | --- | --- |
| AHB / APB | STM32 内部总线层级，决定外设挂载与时钟路径 | APB 分频后，所有定时器时钟都简单等于 PCLK |
| ARR | 定时器自动重装值，定义计数周期上界 | ARR 就是频率，不需要输入时钟和 PSC |
| bxCAN | 传统 STM32 CAN 控制器家族 | 与 H7 的 FDCAN 寄存器兼容 |
| Cache coherency | CPU Cache 与 DMA/外设看到的内存副本一致 | DMA 完成中断自动刷新 D-Cache |
| CCR | 定时器捕获/比较寄存器 | 只用于 PWM，不能做输入捕获 |
| CMSIS | Arm Cortex 微控制器软件接口标准及设备头文件约定 | CMSIS 等于某一家 HAL |
| CPHA / CPOL | SPI 的采样相位与空闲极性 | 只要频率一样，模式可以随便选 |
| CRC | 检测传输错误的循环冗余校验 | CRC 能证明来源身份或抵抗恶意篡改 |
| DMA | 在外设与内存/内存之间搬运数据的硬件控制器 | DMA 不占 CPU 就等于不会丢数据 |
| DTCM | 与 Cortex-M7 紧耦合的数据内存 | 所有 DMA 都能访问 DTCM |
| EXTI | 外部/内部事件到中断线的控制模块 | 每个 GPIO 都有独立 EXTI 编号 |
| FDCAN | 支持 CAN FD 的新一代 CAN 控制器 | 只是 bxCAN 改名 |
| Flash wait state | CPU 读取 Flash 时为满足访问时间插入的等待周期 | 主频提高后不需要调整 |
| HAL | ST 的硬件抽象层驱动 | HAL 消除了型号、电气和时序差异 |
| HSE / HSI | 外部/内部高速时钟源 | HSE 必然比 HSI 准，且板上一定焊了晶振 |
| HT / TC | DMA 半传输/传输完成事件 | HT/TC 在所有模式下都代表一帧业务数据 |
| IAP | 应用内编程/在线升级 | 能写 Flash 并跳转就等于安全升级 |
| IDLE | UART 接收线保持一个帧时间空闲的事件 | IDLE 天然等于协议帧结束 |
| ISR | 中断服务例程 | ISR 中可以阻塞等待，只要平均时间不长 |
| LSE / LSI | 外部/内部低速时钟源 | LSI 精度足以直接当高精度 RTC |
| MPU | 内存保护单元，也可配置 Cache 属性 | MPU 是 MMU，能做虚拟内存分页 |
| MSP / PSP | Cortex-M 主栈/进程栈指针 | RTOS 任务和异常始终共用同一个栈 |
| NDTR / CNDTR | DMA 剩余传输项数 | 存的是剩余字节数，与数据宽度无关 |
| NVIC | Cortex-M 嵌套向量中断控制器 | 数值越大，逻辑优先级越高 |
| ORE | UART 接收溢出标志 | 只要 DMA 开着就不可能出现 ORE |
| Open-drain | 只能主动拉低、释放后靠上拉变高的输出 | 写 1 会主动输出高电平 |
| PLL | 对参考时钟倍频/分频的锁相环 | 任意倍频组合都满足芯片和 USB 约束 |
| PWM | 用脉冲占空比表达平均能量或控制量 | 占空比与所有负载的物理输出都线性 |
| RDP | Flash 读保护级别/选项 | 提高级别不影响 Flash 内容，也总能恢复 |
| Ring buffer | 读写位置绕回的有界队列 | 加了 `volatile` 就自动线程安全且不会溢出 |
| RTOS tick | 内核时间基准与调度节拍 | tick 越快实时性必然越好且没有成本 |
| SAR ADC | 逐次逼近型模数转换器 | 转换位数越高，实际精度必然等同位数 |
| SCB | Cortex-M 系统控制块，含故障状态等寄存器 | HardFault 只看 HFSR 就能找到根因 |
| SWD / SWO | 两线调试接口 / 单线跟踪输出 | SWO 是所有封装默认可用且不占复用脚 |
| TC / TXE | UART 发送完成 / 发送数据寄存器空 | TXE=1 表示线上最后一位已经发送完 |
| TRGO | 定时器向 ADC/DAC 等外设发出的触发输出 | 任何更新事件都会自动连接到任何 ADC |
| UART 8N1 | 8 数据位、无校验、1 停止位的异步帧 | 8N1 包含起始位在“8”里 |
| USB CDC / HID | 虚拟串口类 / 人机接口类 | 类枚举成功就代表所有主机均兼容 |
| `volatile` | 要求编译器按抽象机规则保留易变对象访问 | 提供原子性、互斥、内存屏障和队列容量 |
| Watchdog | 由独立或窗口计数器监督软件健康 | 在固定中断里无条件喂狗就能证明系统健康 |
| WCET | 最坏执行时间 | 多次平均运行时间可以替代 WCET 边界 |

术语只给本书语境下的工作定义。寄存器位、地址、时间和电气参数始终以目标型号对应修订版手册为准。
