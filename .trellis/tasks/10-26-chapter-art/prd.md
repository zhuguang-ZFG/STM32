# 10-26-chapter-art：88 章手绘题图

## 目标

每章章首配一枚手绘风线稿小图（题图），主题取自本章核心机制，提升阅读趣味与辨识度。
风格与封面统一：单色墨线（`--cover-ink` / 打印 #123b33）+ `hw-wobble` 抖动滤镜，无外部素材。

## 已定决策（用户拍板 2026-10-26）

- 封面 = 手绘开发板（已集成 `art.py cover_art()`，打印米白底墨绿线，站点随主题 var）
- 手绘示波器稿（UART 0x55 帧）入素材池，可作隔页/章内插图
- 范围 = **88 章每章一枚题图**（用户明确选"每章题图"档）
- 配色 = 米白纸感墨线
- **参考项目调研（非拍板）**：`research/reference-yuyu-style.md` 记录御舆书的无滤镜曲线路线（其理由是带滤镜子树印前会光栅化）。**本轮仍执行已评审冻结的滤镜手绘路线**（用户两次视觉确认过；题图文字在滤镜组外，搜索性不受影响）。若后续要迁移，属整批重画决策，须用户明确拍板。`art_guard.py --yuyu` 保留为可选模式。

## 形态约束

- 画布 viewBox `0 0 320 88`（横幅小图，章首 header 区，不抢正文）
- 元素 1-3 个，一眼认出本章主题；标签 ≤3 个，font-size ≥ 7（96mm 宽下 7 单位 ≈ 6pt，印刷地板；封面 84mm 同理），sans-serif
- 线条 stroke-width 主干 2 / 细节 1.1，与封面一致
- 颜色一律 `var(--cover-ink, #123b33)`，不写死色值（站点暗色主题靠变量翻浅；打印由 book-print.css 定墨绿）
- 全部套 `hw-<章id>` 抖动滤镜（文字除外）
- 交付物：`mcu-book/book/assets/chapter-art/<章id>.svg`（注意 BOOK_DIR=mcu-book/book），构建器存在即内联，缺失静默跳过（不阻塞构建）

## 验收

1. 试点 3 枚（c/02-pointer、c/03-volatile、c/06-abi-stack）用户评审通过 → 风格冻结
2. 分批生产（与精修批同节奏，每批 ≤10 枚），每批渲染 contact sheet 给用户抽评
3. 机器断言（结构式）：每枚 SVG 必须 `viewBox="0 0 320 88"`；含 `<filter id="hw-<章id>">` 且全图有 `filter="url(#hw-<章id>)"` 引用配对，id 全文档唯一（88 枚内联进同一 HTML，`prefix_local_ids` 不改 `filter="url(#…)"`，重名只能靠定义相同侥幸过关）；无 `<image>`/外链/`<script>`
4. 集成后重建书：11 门全过 + 题图在章首页可见（截图抽验）

## 流水线

```
每批：代理读对应章 → 提炼一个机制意象 → 手绘 SVG 到 assets/chapter-art/
  → 渲染 contact sheet（本章图 + 章标题）→ 用户抽评 → 下一批
```
