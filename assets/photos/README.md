`stlink-v2-swd-connector.jpg` 是 ST-Link/V2 与 48-pin STM32F103C8T6 开发板的 SWD 四线接线实拍，只作接线形态参考，不证明驱动枚举或烧录成功。`logic-analyzer-8ch.jpg`、`oscilloscope-ds1054z.jpg`、`multimeter-dt830d.jpg` 与 `eeprom-24c02.jpg` 都是仪器/器件形态照片，不是测量截图或上板证据。工具照片的站点镜像位于 `docs/public/images/tools/`，字节与源文件一致；板卡照片镜像位于 `docs/public/images/boards/`。

`bluepill-stm32f103c8t6-tardate-usb.jpg` 只证明“USB 供电下有一颗板载 LED 点亮”；图中丝印不可辨，**不能据此判定该灯是 PC13 用户灯还是电源灯**，因此不当作 PC13 LED 特写。MIT 许可要求随副本保留上方版权声明与许可链接。

Nucleo 两张照片用于识别 Nucleo-64 家族的 ST-LINK 上半区、目标 MCU 下半区和排针布局，**都不是 NUCLEO-L476RG**。L476RG 的确切板卡照片、原理图和最新硬件版本以 [ST 官方产品页](https://www.st.com/en/evaluation-tools/nucleo-l476rg.html) 与 UM1724 为准。四张 Blue Pill 照片均为**硬件参照照**（Avandalen + Popolon 两张俯视板卡全貌，均为 CC BY-SA 4.0；Paul Gallagher 两张分别为 USB 供电灯态与面包板/USB-TTL 接线，均为 MIT）：只用于识别板卡整体外观、引脚排布与接线形态；板载 PC13 LED 位于 USB 座一侧（据板卡原理图/丝印，图中过小难以分辨，MIT 点亮灯照片也无法判定是否为 PC13）。**PC13 LED 特写、万用表/逻辑分析仪测量截图仍缺**——不得用 AI 生成图冒充。上述实拍不含测量画面，不能当作实验测量证据。PC13 电流路径见章内 Handraw/stack（知识轨，标注「原理示意/非实拍」），不得登记为真证轨。
