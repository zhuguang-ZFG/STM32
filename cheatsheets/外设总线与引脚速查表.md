## 1. 外设挂载总线表（F103）

> F103 系统：SYSCLK=72MHz，HCLK(AHB)=72MHz，PCLK1(APB1)=36MHz，PCLK2(APB2)=72MHz。
> **APB1 最高 36MHz，APB2 最高 72MHz**；挂 APB1 的定时器若 APB1 分频≠1，定时器时钟 = PCLK1×2。

| 总线 | 最高频率 | 挂载外设 |
| --- | --- | --- |
| **AHB** | 72MHz | DMA1、DMA2、SRAM、Flash 接口(FLITF)、CRC、FSMC |
| **APB1** | 36MHz | TIM2/3/4/5/6/7、USART2/3、UART4/5、SPI2/I2S2、I2C1/2、USB、CAN、BKP、PWR、WWDG、IWDG(*) |
| **APB2** | 72MHz | AFIO、GPIOA~G、EXTI(*)、TIM1/8/9/10/11、USART1、SPI1、ADC1/2/3、ADC 温度 |

> (*) IWDG 时钟源是独立的 LSI；EXTI 经 AFIO 配置。TIM1/TIM8 是高级定时器（APB2）。

## 2. 外设挂载总线表（F411）

> F411 系统：SYSCLK 最高 100MHz，HCLK=100MHz，PCLK1(APB1)=50MHz，PCLK2(APB2)=100MHz。

| 总线 | 最高频率 | 挂载外设 |
| --- | --- | --- |
| **AHB1** | 100MHz | GPIOA~H、DMA1、DMA2、RCC、FLASH 接口、CRC |
| **AHB2** | 100MHz | USB OTG FS |
| **APB1** | 50MHz | TIM2/3/4/5、USART2、SPI2/I2S2、I2C1/2/3、I2C、WWDG、PWR、UART/SPI3(部分) |
| **APB2** | 100MHz | TIM1/9/10/11、USART1/6、SPI1/4/5、ADC1、SYSCFG、EXTI、SDIO |

> 与 F103 的最大区别：F4 的 GPIO 挂 **AHB1**（F1 挂 APB2）；F4 外设时钟使能宏是
> `__HAL_RCC_GPIOx_CLK_ENABLE()`（内部访问 AHB1ENR），F1 访问 APB2ENR。

## 3. 常用外设默认引脚表

> 以 LQFP48（BluePill F103C8 / BlackPill F411CE）为主。**同引脚可能复用多个外设，注意冲突。**

| 外设 | 功能 | F103 引脚 | F411 引脚 |
| --- | --- | --- | --- |
| USART1 | TX / RX | PA9 / PA10 | PA9 / PA10（或 PB6/PB7） |
| USART2 | TX / RX | PA2 / PA3 | PA2 / PA3 |
| USART3 | TX / RX | PB10 / PB11 | PB10 / PB11 |
| SPI1 | SCK/MISO/MOSI/NSS | PA5/PA6/PA7/PA4 | PA5/PA6/PA7/PA4 |
| SPI2 | SCK/MISO/MOSI/NSS | PB13/PB14/PB15/PB12 | PB13/PB14/PB15/PB12 |
| I2C1 | SCL / SDA | PB6 / PB7 | PB6 / PB7（或 PB8/PB9） |
| I2C2 | SCL / SDA | PB10 / PB11 | PB10 / PB11 |
| TIM1 | CH1/CH2/CH3/CH4 | PA8/PA9/PA10/PA11 | PA8/PA9/PA10/PA11 |
| TIM2 | CH1/CH2/CH3/CH4 | PA0/PA1/PA2/PA3 | PA0/PA1/PA2/PA3 |
| TIM3 | CH1/CH2/CH3/CH4 | PA6/PA7/PB0/PB1 | PA6/PA7/PB0/PB1 |
| TIM4 | CH1/CH2/CH3/CH4 | PB6/PB7/PB8/PB9 | PB6/PB7/PB8/PB9 |
| ADC1 | IN0~IN3 | PA0/PA1/PA2/PA3 | PA0/PA1/PA2/PA3 |
| ADC1 | IN4~IN7 | PA4/PA5/PA6/PA7 | PA4/PA5/PA6/PA7 |
| CAN1 | TX / RX | PA12 / PA11（或 PB9/PB8） | PA12 / PA11（或 PB9/PB8） |
| USB FS | DM / DP | PA11 / PA12 | PA11 / PA12 |
| SWD | SWDIO / SWCLK | PA13 / PA14 | PA13 / PA14 |
| LSE | OSC32_IN/OUT | PC14 / PC15 | PC14 / PC15 |
| HSE | OSC_IN/OUT | PD0 / PD1（或 PF0/PF1） | PH0 / PH1 |

> ⚠️ **引脚冲突**：如 `adc-dma` 用 PA4(ADC_IN4) 会与 `spi-flash` 的 SPI1_NSS(PA4) 冲突；
> `TIM3_CH1=PA6` 与 `SPI1_MISO=PA6` 冲突。规划外设时先画一张「引脚占用表」。

## 4. F4 复用功能 AF 编号表

> F4 的复用功能用 **AF0~AF15** 编号选择（写 `GPIOx_AFRL/AFRH`）。
> 配置步骤：`GPIO_MODE_AF_PP` + `io.Alternate = GPIO_AFx_yyy;`。
> **F1 没有 AF 编号**（直接用 `AF_PP` 外设自动接管），这是 F1/F4 最大的配置差异。

| AF 编号 | 主要复用功能 |
| --- | --- |
| AF0 | SYS（JTAG/SWD、MCO、RTC 等） |
| AF1 | TIM1 / TIM2 |
| AF2 | TIM3 / TIM4 / TIM5 |
| AF3 | TIM8 / TIM9 / TIM10 / TIM11 |
| AF4 | I2C1 / I2C2 / I2C3 |
| AF5 | SPI1 / SPI2 / SPI3 / SPI4 / SPI5 / SPI6 |
| AF6 | SPI2 / SPI3 / I2S2 / I2S3 |
| AF7 | USART1 / USART2 / USART3 |
| AF8 | UART4 / UART5 / USART6 / UART7 / UART8 |
| AF9 | CAN1 / CAN2 / TIM12 / TIM13 / TIM14 |
| AF10 | OTG_FS / OTG_HS / SDIO |
| AF11 | ETH / FMC / DCMI |
| AF12 | SDIO / FMC / OTG_FS / OTG_HS |
| AF13 | DCMI / SDIO / FMC |
| AF14 | FMC / SDIO / LTDC |
| AF15 | EVENTOUT（事件输出） |

> 例：F411 上把 PA9 配成 USART1_TX → `GPIO_AF7_USART1`；PB6 配成 I2C1_SCL → `GPIO_AF4_I2C1`。

## 5. 5V 容忍引脚说明

| 类型 | 说明 | 能否接 5V |
| --- | --- | --- |
| **FT（Five-volt Tolerant）** | 数据手册标注为 FT 的引脚 | ✅ 可接 5V 数字输入 |
| **TC（TTa with Analog）** | 模拟引脚，FT 且当模拟输入时不能超 VDDA | ⚠️ 作数字输入可 5V，作 ADC 只能 ≤VDDA |
| **非 FT（普通 IO）** | 未标注 FT | ❌ 只能 ≤ VDDA（3.3V） |
| **电源/特殊脚** | VBAT、VDDA、VREF+、BOOT0 等 | ❌ 按数据手册规定电压 |
| **开漏 + 上拉** | 任何引脚配开漏后外接 5V 上拉 | ⚠️ 仅在器件支持 FT 时安全 |

**查法**：在数据手册（DS）的「Pinouts and pin description」表里看每脚的类型列：
标 `FT` 即可 5V 输入，标 `FTf` 表示 I²C 引脚（可 FT），无标注则是普通 3.3V 脚。

> 重要结论：**5V 容忍只针对「输入」**；输出高电平永远是 VDD（3.3V），不可能输出 5V。
> 若需 5V 电平输出，用开漏 + 5V 上拉（仅 FT 脚）或加电平转换芯片。

## 6. 外设时钟使能宏对照（F1 vs F4）

> 写寄存器/调 HAL 前，必须先使能外设时钟。F1 与 F4 的宏名相同，但内部访问的寄存器不同。

| 外设类别 | 使能宏（HAL 通用写法） | F1 实际寄存器 | F4 实际寄存器 |
| --- | --- | --- | --- |
| GPIO | `__HAL_RCC_GPIOA_CLK_ENABLE()` | `APB2ENR` | `AHB1ENR` |
| DMA1 | `__HAL_RCC_DMA1_CLK_ENABLE()` | `AHBENR` | `AHB1ENR` |
| USART1 | `__HAL_RCC_USART1_CLK_ENABLE()` | `APB2ENR` | `APB2ENR` |
| USART2 | `__HAL_RCC_USART2_CLK_ENABLE()` | `APB1ENR` | `APB1ENR` |
| SPI1 | `__HAL_RCC_SPI1_CLK_ENABLE()` | `APB2ENR` | `APB2ENR` |
| SPI2 | `__HAL_RCC_SPI2_CLK_ENABLE()` | `APB1ENR` | `APB1ENR` |
| I2C1 | `__HAL_RCC_I2C1_CLK_ENABLE()` | `APB1ENR` | `APB1ENR` |
| TIM2 | `__HAL_RCC_TIM2_CLK_ENABLE()` | `APB1ENR` | `APB1ENR` |
| TIM1 | `__HAL_RCC_TIM1_CLK_ENABLE()` | `APB2ENR` | `APB2ENR` |
| ADC1 | `__HAL_RCC_ADC1_CLK_ENABLE()` | `APB2ENR` | `APB2ENR` |
| AFIO/SYSCFG | `__HAL_RCC_AFIO_CLK_ENABLE()` / `__HAL_RCC_SYSCFG_CLK_ENABLE()` | `APB2ENR` | `APB2ENR` |
| PWR | `__HAL_RCC_PWR_CLK_ENABLE()` | `APB1ENR` | `APB1ENR` |

> **结论**：宏名统一，不用记寄存器；但要知道 F4 的 GPIO 在 AHB1，所以 F4 的 GPIO 时钟更快、
> 且 `HAL_RCC_GetHCLKFreq()` 才是 GPIO 的时钟频率。F1 的 AFIO 在 F4 里改叫 SYSCFG。

## 7. 启动模式与调试引脚

| BOOT1 | BOOT0 | 启动位置 | 说明 |
| --- | --- | --- | --- |
| x | 0 | 主 Flash（`0x0800 0000`） | 正常运行用户程序 |
| 0 | 1 | 系统存储器（Bootloader） | 内置串口/USB DFU 下载程序 |
| 1 | 1 | 内置 SRAM | 调试用，掉电即失 |

| 引脚 | 功能 | 备注 |
| --- | --- | --- |
| PA13 | SWDIO | 调试数据线，**保留**，勿配普通 IO |
| PA14 | SWCLK | 调试时钟线，**保留** |
| PA15 / PB3 / PB4 | JTDI / JTDO / NJTRST | 默认 JTAG 复用，用作普通 IO 需关 JTAG 重映射 |
| NRST | 复位 | 低电平复位，可接调试器复位线 |
| BOOT0 | 启动选择 | 板上一般有跳线/按键 |

## 8. 常见外设组合与引脚占用示例

> 规划项目时先画「引脚占用表」，避免复用冲突。

| 组合场景 | 占用引脚 | 潜在冲突 |
| --- | --- | --- |
| 点灯 + 按键 | PC13、PA0 | 无 |
| 串口调试 + PWM 调光 | PA9/PA10、PA6 | PA6 与 SPI1_MISO 冲突 |
| I2C OLED + SPI Flash | PB6/PB7、PA5/PA6/PA7/PA4 | PA6 同时是 SPI1_MISO 与 TIM3_CH1 |
| ADC 采集 + 串口 DMA | PA0/PA1/PA4、PA9/PA10 | PA4 与 SPI1_NSS 冲突 |
| CAN + 串口 | PA11/PA12、PA9/PA10 | PA11/PA12 与 USB 冲突 |
| USB + 串口 | PA11/PA12、PA9/PA10 | PA11/PA12 与 CAN 冲突 |

> 记忆法：**PA11/PA12 = CAN 或 USB（二选一）**；**PA6 = SPI1_MISO / TIM3_CH1**；
> **PA4 = SPI1_NSS / ADC_IN4 / DAC_OUT1**。多用「引脚复用表（DS 数据手册）」核对。

## 9. 总线仲裁与时钟关系速记

| 关系 | 说明 |
| --- | --- |
| 定时器时钟 | APB 分频 ≠1 时，定时器时钟 = PCLK ×2（F1/F4 通用） |
| ADCCLK | F1 = PCLK2/2/4/6/8（≤14MHz）；F4 = PCLK2/2/4/6/8（≤36MHz） |
| USB 时钟 | F1：PLL/1.5 必须精确 48MHz；F4：PLL48CLK = 48MHz |
| SysTick | 属于内核，时钟来自 HCLK/8 或 HCLK，与 APB 无关 |
| DMA 与 CPU | 共享总线矩阵，DMA 搬运会占用总线带宽（F4 有 FIFO 缓解） |
