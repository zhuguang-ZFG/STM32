## 1. HAL 返回值含义

`HAL_StatusTypeDef` 是所有 HAL 函数的统一返回值（部分函数返回 void 或具体数值）。

| 返回值 | 值 | 含义 | 典型触发场景 |
| --- | --- | --- | --- |
| `HAL_OK` | 0x00 | 操作成功 | 正常完成 |
| `HAL_ERROR` | 0x01 | 一般错误 | 参数非法、外设配置失败、HSE 不起振、硬件应答异常 |
| `HAL_BUSY` | 0x02 | 外设忙 | 上一次传输未完成又发起新传输；DMA/中断模式未结束 |
| `HAL_TIMEOUT` | 0x03 | 超时 | 等待标志位超时（如等 TXE/BSY/RXNE 超过 timeout） |

**处理建议**：

| 返回值 | 建议动作 |
| --- | --- |
| `HAL_OK` | 继续 |
| `HAL_BUSY` | 等待/重试；检查是否漏了等前一次完成或状态未复位 |
| `HAL_TIMEOUT` | 检查时钟、接线、从机是否应答、timeout 是否太短 |
| `HAL_ERROR` | 检查参数合法性、外设时钟是否使能、硬件是否在位 |

## 2. HAL 状态枚举

`HAL_StateTypeDef` 描述外设句柄当前状态（`hxxx.State`），调试时看它最直接。

| 状态 | 值 | 含义 |
| --- | --- | --- |
| `HAL_STATE_RESET` | 0x00 | 外设未初始化（复位后默认） |
| `HAL_STATE_READY` | 0x01 | 已初始化，空闲可发起操作 |
| `HAL_STATE_BUSY` | 0x02 | 正在执行某操作（通用） |
| `HAL_STATE_BUSY_TX` | 0x21 | 正在发送 |
| `HAL_STATE_BUSY_RX` | 0x22 | 正在接收 |
| `HAL_STATE_BUSY_TX_RX` | 0x23 | 正在全双工收发 |
| `HAL_STATE_TIMEOUT` | 0x03 | 上次操作超时 |
| `HAL_STATE_ERROR` | 0x04 | 上次操作出错 |

> 典型坑：`HAL_UART_Transmit_IT` 返回 `HAL_BUSY`，说明上一次发送还没完成（`State` 仍为 `BUSY_TX`）。

## 3. 模块错误标志

### 3.1 FLASH（`HAL_FLASH_GetError()`）

| 标志 | 含义 |
| --- | --- |
| `HAL_FLASH_ERROR_NONE` | 无错误 |
| `HAL_FLASH_ERROR_PG` | 编程错误（未擦除就写、地址不对齐） |
| `HAL_FLASH_ERROR_WRP` | 写保护错误（目标页被写保护） |
| `HAL_FLASH_ERROR_OPERATION` | 操作错误（BSY 未清零就发起新操作） |

### 3.2 I2C（`HAL_I2C_GetError()`）

| 标志 | 含义 |
| --- | --- |
| `HAL_I2C_ERROR_NONE` | 无错误 |
| `HAL_I2C_ERROR_BERR` | 总线错误（非法起止条件） |
| `HAL_I2C_ERROR_ARLO` | 仲裁丢失（多主竞争） |
| `HAL_I2C_ERROR_AF` | 应答失败（从机没 ACK：地址错/不在位/上拉缺失） |
| `HAL_I2C_ERROR_OVR` | 溢出 |
| `HAL_I2C_ERROR_TIMEOUT` | 超时 |

### 3.3 UART（`HAL_UART_GetError()`）

| 标志 | 含义 |
| --- | --- |
| `HAL_UART_ERROR_NONE` | 无错误 |
| `HAL_UART_ERROR_PE` | 校验错误 |
| `HAL_UART_ERROR_NE` | 噪声错误（波特率/线长） |
| `HAL_UART_ERROR_FE` | 帧错误（停止位/波特率不匹配） |
| `HAL_UART_ERROR_ORE` | 溢出（接收太快没及时读） |
| `HAL_UART_ERROR_DMA` | DMA 传输错误 |

## 4. 常见现象 → 原因 → 定位手段

| # | 现象 | 原因 | 定位手段 |
| --- | --- | --- | --- |
| 1 | 程序一上电就停在 `Error_Handler` | 时钟配置失败（HSE 不起振） | 示波器测 OSC_IN；改 HSI 或换晶振/负载电容 |
| 2 | LED 完全不亮 | 没使能 GPIO 时钟 | 检查 `__HAL_RCC_GPIOx_CLK_ENABLE()` |
| 3 | 外设寄存器写了没反应 | 外设时钟未使能 | 查 `RCC->APBxENR` 对应位 |
| 4 | 烧录后再也连不上 | SWD 引脚 PA13/PA14 被复用为 GPIO | CubeMX 里 SYS 选 Serial Wire；BOOT0 拉高进系统存储器 |
| 5 | 中断进不去 | 没使能 NVIC / 没配 EXTI | 查 `HAL_NVIC_EnableIRQ`、`GPIO_MODE_IT_xxx` |
| 6 | 一直反复进中断 | 忘记清中断标志 | ISR 里调 `__HAL_GPIO_EXTI_CLEAR_IT` 或 HAL 处理函数 |
| 7 | 按一次按键触发多次 | 机械抖动 | 加 10~20ms 软件消抖或 RC 滤波 |
| 8 | 中断里程序卡死 | 中断里调用 `HAL_Delay`/`printf` | 中断只置标志，耗时操作放主循环 |
| 9 | 定时器没波形输出 | 高级定时器没开 MOE | `HAL_TIM_PWM_Start` 或 `__HAL_TIM_MOE_ENABLE` |
| 10 | PWM 频率不对 | PSC/ARR 算错或时钟树不对 | 用 `f=fCK/((ARR+1)(PSC+1))` 复核；测实际频率 |
| 11 | PWM 调占空比时抖动 | 未开预装载 | 使能 `AutoReloadPreload`/`OCxPE` |
| 12 | 串口输出乱码 | 波特率不符/时钟不对/未共地 | 双方统一波特率；确认 PCLK；接 GND |
| 13 | 串口只收到一次就停 | DMA 接收未在回调里重启 | 回调内再次 `ReceiveToIdle_DMA` |
| 14 | 串口溢出后卡死 | 没处理 ORE 标志 | 在 `HAL_UART_ErrorCallback` 清标志并重启 |
| 15 | I2C 从机不应答（AF） | 地址错/上拉缺失/从机不在位 | `HAL_I2C_IsDeviceReady` 探测；查上拉 4.7kΩ |
| 16 | I2C 通信偶发失败后彻底死 | 从机拉低 SDA 造成总线死锁 | 手动 9 时钟脉冲解锁（见 i2c-oled 示例） |
| 17 | SPI 读回全 0xFF | MISO 没接 / 从机没供电 | 检查 DO/DI 接线与供电 |
| 18 | SPI 读回全 0x00 | CS 没拉低 / 模式错 | 查片选；核对 CPOL/CPHA |
| 19 | SPI 数据错位 | MSB/LSB 顺序或数据宽度错 | 设 `SPI_FIRSTBIT_MSB`、核对位宽 |
| 20 | ADC 读数恒为 0 | 引脚没配成 Analog / 没接信号 | GPIO 设 `GPIO_MODE_ANALOG` |
| 21 | ADC 读数抖动大 | 采样时间太短 / 源阻抗高 | 加大采样时间，加滤波 |
| 22 | ADC 精度差 | VDDA 不是精确 3.3V | 读 Vrefint 反推真实 VDDA 校准 |
| 23 | DMA 完全不搬数据 | 通道/流映射选错 | 查请求映射表；F4 还要对 `CHSEL` |
| 24 | DMA 只搬一次就停 | 该用循环却配了普通模式 | 改 `DMA_CIRCULAR` |
| 25 | DMA 数据错位 | 地址未递增或宽度不匹配 | 检查 `MINC`/`PINC`、`PSIZE`/`MSIZE` |
| 26 | RTC 时间不走 | LSE 未起振 / VBAT 未接 | 换 6pF 电容；接纽扣电池 |
| 27 | 看门狗频繁复位 | 喂狗间隔 > 超时 | 算清超时时间；循环里定期喂狗 |
| 28 | 跳转 APP 后死机 | 未设 MSP / 未设 VTOR | `__set_MSP` + `SCB->VTOR = APP_ADDR` |
| 29 | Flash 编程返回 ERROR | 未擦除 / 未对齐 / 未解锁 | 先擦整页；半字对齐；`HAL_FLASH_Unlock` |
| 30 | FreeRTOS 卡在调度器启动 | HAL 时基与 RTOS 抢 SysTick | CubeMX 时基源改 TIMx |
| 31 | FreeRTOS `configASSERT` 死循环 | 中断优先级数值太小 | 中断优先级 ≥ `configMAX_SYSCALL_INTERRUPT_PRIORITY` |
| 32 | 进 HardFault | 空指针/数组越界/栈溢出/除零 | 查 `CFSR/HFSR`；开 `HardFault_Handler` 打印；加大任务栈 |
| 33 | 低功耗唤醒后串口乱码 | STOP 后时钟回 HSI | 唤醒后重新 `SystemClock_Config()` |
| 34 | 程序跑一段时间后死机 | 堆栈溢出 / 看门狗未喂 / 中断风暴 | 加大栈；开看门狗；统计中断频率 |

## 5. 快速排错流程（口诀）

| 步骤 | 检查项 |
| --- | --- |
| 1. 电源与地 | 3.3V 稳定？共地？VDDA 接了吗？ |
| 2. 时钟 | HSE/LSE 起振？SYSCLK 频率对？外设时钟使能？ |
| 3. 引脚 | 复用对不对？冲突吗？上下拉需要吗？ |
| 4. 配置 | 模式/参数对不对？预分频/分频对？ |
| 5. 时序 | 波特率/CPOL-CPHA/采样时间/超时对？ |
| 6. 中断 | NVIC 使能？优先级？清标志？ |
| 7. 工具 | 用调试器看寄存器、用逻辑分析仪看波形、用 SWO 打印 |

## 5. 常见编译/链接错误

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `undefined reference to 'HAL_XXX'` | 没把对应 `stm32f1xx_hal_xxx.c` 加进工程 | 在 IDE 里勾选对应 HAL 模块，或补源文件 |
| `multiple definition of 'XXX_IRQHandler'` | 自己写了中断函数又保留了生成代码的 | 删掉重复定义（保留一处） |
| `'XXX' undeclared` | 缺头文件 / 拼写错 / 未包含模块 | `#include` 对应头；核对大小写 |
| `implicit declaration of function` | 函数没声明（缺头或忘原型） | 补 `#include` 或函数原型 |
| `region RAM/FLASH overflowed` | 程序超出容量 | 优化体积；检查是否误加大数组；改链接脚本 |
| `cannot open source input file "xxx.h"` | 头文件搜索路径没配 | 在工程里加 Include Paths |
| `call to non-static member...`（C++） | 在 .c 里用了 C++ 写法 | 用纯 C；或用 `extern "C"` 包裹 |
| `use of undeclared identifier 'GPIO_PIN_13'` | 没包含 `stm32f1xx_hal.h` 或器件头 | 确认器件宏（如 `STM32F103xB`）已定义 |

## 6. HardFault 定位寄存器

> 进入 `HardFault_Handler` 后，先看 `SCB->CFSR`，再回看 `SCB->BFAR`/`MMFAR`。

| 寄存器 | 位/字段 | 含义 |
| --- | --- | --- |
| `SCB->CFSR` | `[7:0]` MMFSR | 存储器管理错误（越权访问） |
| `SCB->CFSR` | `[15:8]` BFSR | 总线错误（如访问未使能时钟的外设） |
| `SCB->CFSR` | `[31:16]` UFSR | 用法错误（未对齐、除零、非法指令） |
| `SCB->HFSR` | bit30 `FORCED` | 由其它错误升级而来的 HardFault |
| `SCB->BFAR` | 地址 | 触发总线错误的地址（`BFSR.BFARVALID` 有效时） |
| `SCB->MMFAR` | 地址 | 触发存储器管理错误的地址 |
| 栈帧 | `R0~R3,R12,LR,PC,xPSR` | 从 MSP/PSP 取出的出错现场（PC=出错指令） |

**定位步骤**：① 读出栈帧里的 `PC`；② 用 `addr2line` 或 IDE 反汇编找到对应源码行；
③ 常见根因：外设时钟没使能就访问寄存器（BFSR）、数组越界（MMFSR）、除零/未对齐（UFSR）。

## 7. 调试工具与手段速查

| 手段 | 用途 | 适用场景 |
| --- | --- | --- |
| SWD + 断点/单步 | 看变量、单步执行 | 逻辑错误、流程问题 |
| 调试器看寄存器/外设窗口 | 直接看 RCC/GPIO/TIM 寄存器 | 怀疑时钟/配置没生效 |
| 逻辑分析仪 | 抓 SPI/I2C/UART 时序波形 | 通信不上的终极手段 |
| 示波器 | 测时钟、PWM、电源纹波 | 不起振、频率不对、干扰 |
| SWO/ITM printf | 不占串口的打印跟踪 | 实时性要求高、串口被占用 |
| 串口 printf | 打印运行状态 | 一般调试（注意重定向 `fputc`） |
| GPIO 翻转 + 示波器 | 测函数耗时 | 性能分析（配合 DWT） |
| `__NOP()` + 单步 | 精确时序观察 | 微秒级时序 |

## 8. 断言与常见宏开关

| 宏/机制 | 作用 | 说明 |
| --- | --- | --- |
| `assert_param(expr)` | HAL 参数检查 | `USE_FULL_ASSERT` 打开时生效 |
| `USE_FULL_ASSERT` | 启用 HAL 断言 | 出错进 `assert_failed()`，便于发现参数错 |
| `configASSERT(x)` | FreeRTOS 断言 | 优先级/参数错误时进死循环 |
| `Error_Handler()` | 用户错误处理 | 时钟/外设初始化失败时停留，便于调试 |
| `__disable_irq()` | 关中断 | 临界区；注意别在里面长时间停留 |
| `NVIC_SystemReset()` | 软件复位 | 看门狗/异常恢复 |
