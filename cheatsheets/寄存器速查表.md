# 寄存器速查表

> STM32F1 关键外设寄存器位速查。列含义：**位 / 名称 / 含义**。
> 写寄存器前务必先使能对应外设时钟（`RCC->APBxENR` / `AHBENR`），否则写入无效。
> 复位值 R=只读、W=只写、RW=读写。

## 1. GPIO

### 1.1 GPIOx_CRL（配置低 8 位：Px0~Px7，偏移 0x00）

每 4 位配置一个引脚：`[1:0]=MODE`，`[3:2]=CNF`。

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `MODEy[1:0]` | 模式位 | `00`=输入；`01`=输出 10MHz；`10`=输出 2MHz；`11`=输出 50MHz |
| `CNFy[1:0]` | 输入时 | `00`=模拟；`01`=浮空；`10`=上/下拉；`11`=保留 |
| `CNFy[1:0]` | 输出时 | `00`=通用推挽；`01`=通用开漏；`10`=复用推挽；`11`=复用开漏 |

### 1.2 GPIOx_CRH（配置高 8 位：Px8~Px15，偏移 0x04）

格式与 CRL 相同，位段对应 Px8~Px15。

### 1.3 GPIOx_IDR / ODR（偏移 0x08 / 0x0C）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `IDR[15:0]` | 输入数据 | R，读引脚当前电平（每脚 1 位） |
| `ODR[15:0]` | 输出数据 | RW，写引脚输出电平（读回为最近写入值） |

### 1.4 GPIOx_BSRR / BRR（偏移 0x10 / 0x14）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `BSRR[15:0]` | BSy | W，写 1 置位对应引脚为高（原子） |
| `BSRR[31:16]` | BRy | W，写 1 复位对应引脚为低（原子） |
| `BRR[15:0]` | BRy | W，写 1 复位对应引脚为低（F4 合并进 BSRR 高 16 位） |

> **BSRR 一次写入即完成置位/复位，天然原子**，优于 `ODR` 的读改写。写 0 无任何影响。

### 1.5 GPIOx_LCKR（偏移 0x18）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `LCKy[15:0]` | 锁定 | 配合 `LCKK` 写序列锁定引脚配置，防止误改 |

## 2. RCC

### 2.1 RCC_CR（时钟控制，偏移 0x00）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | HSION | 内部 8MHz 使能（复位=1） |
| `1` | HSIRDY | HSI 就绪（只读） |
| `16` | HSEON | 外部晶振使能 |
| `17` | HSERDY | HSE 就绪（只读，超时说明不起振） |
| `24` | PLLON | PLL 使能 |
| `25` | PLLRDY | PLL 就绪 |
| `26` | CSSON | 时钟安全系统使能 |

### 2.2 RCC_CFGR（时钟配置，偏移 0x04）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `[1:0]` | SW | 系统时钟源：`00`HSI `01`HSE `10`PLL |
| `[3:2]` | SWS | 当前时钟源（只读） |
| `[7:4]` | HPRE | AHB 分频：`0xxx`=÷1 … `1111`=÷512 |
| `[10:8]` | PPRE1 | APB1 分频：`0xx`=÷1，`100`=÷2 … |
| `[13:11]` | PPRE2 | APB2 分频 |
| `[15:14]` | ADCPRE | ADC 分频：`00`=÷2 `01`=÷4 `10`=÷6 `11`=÷8 |
| `[21:18]` | PLLMUL | PLL 倍频：`0000`=×2 … `0111`=×9 … `1110`=×16 |
| `16` | PLLSRC | PLL 源：0=HSI/2，1=HSE |
| `24` | MCO | 时钟输出选择 |

### 2.3 RCC_APB1ENR / APB2ENR / AHBENR（时钟使能）

| 寄存器 | 典型位（置 1 使能） |
| --- | --- |
| `APB1ENR` | `0`TIM2 `1`TIM3 `2`TIM4 `17`USART2 `21`I2C1 `22`I2C2 `23`USB `28`PWR `27`BKP |
| `APB2ENR` | `0`AFIO `2`GPIOA `3`GPIOB `4`GPIOC `9`ADC1 `11`TIM1 `12`SPI1 `14`USART1 |
| `AHBENR` | `0`DMA1 `1`DMA2 `2`SRAM `4`FLITF `6`CRC |

### 2.4 RCC_BDCR（备份域控制）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | LSEON | LSE 使能 |
| `1` | LSERDY | LSE 就绪 |
| `8` | RTCSEL | RTC 源：`01`=LSE `10`=LSI `11`=HSE/128 |
| `15` | RTCEN | RTC 时钟使能 |
| `16` | BDRST | 备份域复位 |

## 3. TIM

### 3.1 TIMx_CR1（控制，偏移 0x00）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | CEN | 计数器使能 |
| `3` | OPM | 单脉冲模式 |
| `4` | URS | 更新请求源 |
| `7` | ARPE | ARR 自动重装载预装载使能 |
| `[6:5]` | CMS | 中央对齐模式选择 |
| `[9:8]` | CKD | 时钟分频（tdts） |
| `4` | DIR | 计数方向：0=向上，1=向下 |

### 3.2 TIMx_DIER（DMA/中断使能，偏移 0x0C）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | UIE | 更新中断使能 |
| `1` | CC1IE | 捕获/比较 1 中断 |
| `6` | TIE | 触发中断 |
| `8` | UDE | 更新 DMA 请求 |
| `9` | CC1DE | CC1 DMA 请求 |

### 3.3 TIMx_SR（状态，偏移 0x10）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | UIF | 更新中断标志（需软件清 0） |
| `1` | CC1IF | 捕获/比较 1 标志 |
| `6` | TIF | 触发标志 |

### 3.4 TIMx_EGR（事件生成，偏移 0x14）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | UG | 软件产生更新事件（写 1 重装 PSC/ARR 影子寄存器） |
| `1` | CC1G | 产生捕获/比较 1 事件 |

### 3.5 TIMx_CCMR1（捕获/比较模式，偏移 0x18）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `[6:4]` | OC1M | 输出模式：`110`=PWM 模式 1，`111`=PWM 模式 2 |
| `3` | OC1PE | CC1 预装载使能 |
| `[1:0]` | CC1S | 通道方向：`00`=输出，`01`=输入 |

### 3.6 TIMx_CCER（捕获/比较使能，偏移 0x20）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `0` | CC1E | 通道 1 输出/捕获使能 |
| `1` | CC1P | 通道 1 极性：0=高有效，1=低有效 |

### 3.7 TIMx_PSC / ARR / CCRx

| 寄存器 | 含义 |
| --- | --- |
| `PSC` | 预分频：`fCK_CNT = fCK_PSC / (PSC+1)` |
| `ARR` | 自动重装载：决定周期 `T=(ARR+1)(PSC+1)/fCK_PSC` |
| `CCRx` | 捕获/比较值：PWM 占空比 `Duty=CCR/(ARR+1)` |

> 高级定时器 TIM1/TIM8 还有 `BDTR`（bit15=MOE 主输出使能），不置 MOE 则无波形输出。

## 4. USART

### 4.1 USART_SR（状态，偏移 0x00）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `5` | RXNE | 接收数据寄存器非空（有数据可读） |
| `6` | TC | 发送完成（整帧发完） |
| `7` | TXE | 发送数据寄存器空（可写下一个字节） |
| `3` | ORE | 溢出错误（读 SR 再读 DR 清） |
| `2` | NE | 噪声错误 |
| `1` | FE | 帧错误（停止位不对） |
| `0` | PE | 校验错误 |

### 4.2 USART_DR（数据，偏移 0x04）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `[8:0]` | DR | 读写收发数据（低 8 位数据，第 9 位为校验/地址） |

### 4.3 USART_BRR（波特率，偏移 0x08）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `[15:4]` | DIV_Mantissa | 波特率分频整数部分 |
| `[3:0]` | DIV_Fraction | 小数部分（÷16） |

> 计算：`USARTDIV = fCK / (16 × Baud)`；`BRR = (整数 << 4) | round(小数×16)`。

### 4.4 USART_CR1（控制 1，偏移 0x0C）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `13` | UE | USART 使能 |
| `3` | TE | 发送使能 |
| `2` | RE | 接收使能 |
| `5` | RXNEIE | 接收中断使能 |
| `6` | TCIE | 发送完成中断使能 |
| `7` | TXEIE | 发送寄存器空中断使能 |
| `12` | M | 字长：0=8 位，1=9 位 |
| `10` | PCE | 校验使能 |
| `9` | PS | 校验选择：0=偶，1=奇 |
| `4` | IDLEIE | 空闲中断使能（配合 DMA 判帧尾） |

### 4.5 USART_CR2 / CR3（偏移 0x10 / 0x14）

| 寄存器/位 | 名称 | 含义 |
| --- | --- | --- |
| `CR2[13:12]` | STOP | 停止位：`00`=1 `01`=0.5 `10`=2 `11`=1.5 |
| `CR3[7]` | DMAR | 接收 DMA 使能 |
| `CR3[6]` | DMAT | 发送 DMA 使能 |

## 5. NVIC

> Cortex-M 内核寄存器，位于系统控制空间 `0xE000E100` 起。HAL 用 `HAL_NVIC_*` 封装。

### 5.1 NVIC_ISER / ICER（中断使能，偏移 0x100 / 0x180）

| 寄存器 | 含义 |
| --- | --- |
| `ISERn` | 写 1 使能对应中断号（Set Enable） |
| `ICERn` | 写 1 关闭对应中断号（Clear Enable） |
| `ISPRn` | 置挂起位 |
| `IABR` | 读当前活动中断 |

`n = IRQn / 32`，位 = `IRQn % 32`。例：EXTI0(6) → `ISER0` 的 bit6。

### 5.2 NVIC_IPR（优先级，偏移 0x400）

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `IPR[7:4]` | 优先级 | F1 高 4 位有效；**数值越小优先级越高** |

优先级分组（`SCB->AIRCR.PRIGROUP`）决定抢占位/子优先级位的划分，见 HAL 的 `NVIC_PRIORITYGROUP_x`。

## 6. EXTI

| 寄存器 | 偏移 | 含义 |
| --- | --- | --- |
| `IMR` | 0x00 | 中断屏蔽：写 1 允许中断请求 |
| `EMR` | 0x04 | 事件屏蔽：写 1 允许事件请求 |
| `RTSR` | 0x08 | 上升沿触发使能 |
| `FTSR` | 0x0C | 下降沿触发使能 |
| `SWIER` | 0x10 | 软件中断事件（写 1 触发） |
| `PR` | 0x14 | 挂起寄存器（**写 1 清标志**） |

> F1 上 EXTI 引脚映射由 `AFIO_EXTICR1~4` 决定（选择 PAx/PBx/PCx…），配置前必须开 AFIO 时钟。

## 7. FLASH

| 寄存器 | 偏移 | 关键位 |
| --- | --- | --- |
| `FLASH_ACR` | 0x00 | `[2:0]`LATENCY 等待周期（72MHz 需 2）；`4`PRFTBE 预取 |
| `FLASH_KEYR` | 0x04 | 写 `0x45670123`、`0xCDEF89AB` 解锁 |
| `FLASH_SR` | 0x0C | `0`BSY 忙；`5`EOP 操作完成；`4`WRPRTERR；`2`PGERR |
| `FLASH_CR` | 0x10 | `0`PG 编程；`1`PER 页擦除；`6`STRT 开始；`7`LOCK 锁 |

> F4 差异：擦除用 `CR.SER` + `SNB[3:0]` 选扇区；编程用 `CR.PSIZE` 选位宽；`KEYR` 序列相同。
